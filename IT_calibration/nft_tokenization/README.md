- **Рынок:** OpenSea дневной объём пик $2.7 млрд (01.05.2022) → $9.34 млн (28.08.2022), **−99%**; WSJ (05.2022):

  dappGambl (09.2023): **95% NFT = нулевая монетарная стоимость**. OpenSea 2025 — перестройка в
  крипто-агрегатор (OS2, Forbes 10.2025); Reddit свернул NFT-аватары (2024–25).
- **Внимание:** 113 (2023) → 41 (2024) → 18 (2025) → 11 (2026) — **−97% от пика**, стабильно низко.
- **Инженерия:** nft_marketplace 6188 (2022) → 3825 (2023) → 2679 (2024) → 3005 (2025) → 1441 (2026 неполн.) —
  спад ~−75% от пика, НО не коллапс: осталась реальная инфраструктура (OpenSea seaport, Solana-экосистема,
  utility-NFT-проекты, ERC-6551/7432, лицензионные/документы-NFT ниши).
- **Наука:** плато 2024–25 (1028/941), мягкий спад 2026 (557 за 8.5 мес) — наука не «умерла», но и не растёт.

| Слой | Форма кривой | Диагноз |

| Внимание (HN) | **V-пик 2021–22 → −97%** | маркер хайпа: «внимание ≫ содержание» (внешняя методология: намерения без значимости) |

**ML-урок:** метка «провал» для consumer-hype NFT ставится по **рынку и вниманию**, а не по науке.
Для фич: `attention/content ratio`, V-форма внимания, «рынок-без-конверсии». В таблице фич — только
данные ДО 2023 (окно), рыночный исход — метка (look-ahead запрещён, по решению 2026-09-09).

## Методы и оговорки

- **HN:** `search_by_date`, tag=story, `restrictSearchableAttributes=title`, `advancedSyntax=true` +
  `typoTolerance=false`, точная фраза `"nft"` (иначе «Not» матчится как опечатка и «information» как подстрока).
  Проверено на сэмплах заголовков. Методика воспроизводимая; числа — счёт историй (сюжетов), не комментариев.
- **GitHub:** Search API (без ключа, 10 req/min), `created:YYYY-01-01..YYYY-12-31`, репо по 3 запросам
  (erc721 / "non-fungible token" / nft marketplace). 2 пропуска (2020–21 для phrase) дозаполнены.
  ⚠️ Год создания репо ≠ год активности; «репо» включает форки/шаблоны.
- **OpenAlex:** `works/filter=title_and_abstract.search:"non-fungible token",group_by=publication_year` —
  канонический воспроизводимый ряд. Ряд fulltext (`search=`) — больше по абсолюту (полнотекстовый шум),
  форма та же. 2026 — неполный год (данные по 15.09.2026).
- **Рынок:** вторичные источники с цитатами (Wikipedia → WSJ/TechCrunch; dappGambl/DappRadar отчёты).
  Дособор первичных отчётов (DappRadar годовые, CryptoSlam) — по желанию.
