# Сигнал: инженерия (GitHub) — NFT

**Данные:** `raw/github_engineering_nft.json` · **График:** `plots/github_engineering_nft.png`

## Методика
- GitHub Search API (без ключа, 10 req/min, 60/час). Счёт = число репозиториев, созданных в год.
- 3 запроса (по слоям экосистемы):
  1. `erc721 in:name,description,topics` — реализации стандарта (технический точный термин);
  2. `"non-fungible token" in:name,description,topics` — точная фраза;
  3. `"nft" marketplace in:name,description,topics` — маркетплейс-приложения.
- Валидация: топ-репо по звёздам — все реально NFT-тематические (OpenSea seaport, decentraland/marketplace,
  solady, WTF-Solidity, awesome-nft, flow-nft...).
- ⚠️ Ограничения: год создания ≠ год активности; включает форки/шаблоны; 2026 неполный (на 15.09.2026).

## Анализ
- **Форма: взрыв 2021–22 → спад до ~−75% → устойчивый нижний ярус.** Коллапса как у внимания нет:
  nft-marketplace 6188 (2022) → 3825 (2023) → 2679 (2024) → 3005 (2025) → 1441 (2026, неполн.)
  ≈ полный год ~2030 — ярус ~2-3× выше докриптозимы (2021: 1492).
- **Код пережил рынок.** Инфраструктурный пласт остался: OpenSea seaport (эталонная библиотека),
  Solana/Flow-экосистемы, utility-NFT (лицензии, документы, ERC-6551/7432), торговые агрегаторы.
- erc721 — вторая волна 2024 (2145, после спада 2023): вероятно форки-шаблоны + новые стандарты;
  к 2025–26 устойчивый спад.
- **Диагноз:** инженерия — «запаздывающее затухание»: строительство продолжается ~1–2 года после
  рыночного пика и сохраняет остаточный ярус. Это важный маркер: **инженерия ≠ рыночная значимость**
  (могут строить «на будущее», на хайпе и по инерции).

## ML-след
- GitHub-слой для consumer-hype трендов: рост репо = намерения/имплементации, НЕ продажи.
  Использовать как фичу (динамика создания репо), но не как доказательство значимости.
