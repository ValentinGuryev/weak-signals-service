## 2. Что показывает патентный слой — ГЛАВНОЕ открытие

**Патентная активность США по NFT НЕ коллапсировала (в отличие от внимания и рынка!):**
- Рынок: пик $2.7 млрд/день → кризис −99% (08.2022), 95% коллекций = $0;
- Внимание HN: пик 717 (2021) → −97%;
- **Патенты US: рост 0 → 4 → 6 → 9 → 10 (2022→2026), сдвиг состава:**

**Сдвиг состава (2022-23 → 2025-26) = «терминологическая миграция»:**
1. **Коллекционные NFT (хайп-слой):** Tulip (2022, цифровые активы как собственность), VLINDER (2022,
   маркетплейс NFT-активов), Keller (2022, генерация NFT-ассетов из UGC) — **трио 2022 года, ровно
   в пик хайпа**, потом новых коллекционных патентов почти нет.
2. **Институциональная токенизация активов (RWA/переход банков):** Wells Fargo (2025, node-based
   access/resource protection — хранение и контроль цифровых активов), Visa (2023, fiat↔digital assets),
   Coinbase (2025, non-custodial escrow криптодепозитов), LG (2025, NFT-posting + proof of ownership;
   2025, блокчейн-транзакции), SoftBank (2026, реестр транзакций искусства), Schwartz (2025, L3-блокчейн
   микротранзакций Iot/M2M), 2BC (2026, условный токен-эскроу), Istari (2026, доверие в digital-engineering).
3. **Ядро «цифровые токены как юр. объект»:** Templum (2018-19, security-токены — первая семья),
   TULIP-семья (2022 + переподача 2025), BIGtoken (2025, мульти-share NFT + приватность), Web3 DAO (2025).

**Вывод для гипотезы кейса («NFT = ложный тренд»):**
- **Потребительские/коллекционные NFT — да, ложный тренд:** патентная активность по ним существует,
  но точечная (13 core-изобретений за 8 лет по ВСЕЙ стране — это ни о чём для US-масштаба, сравните
  с SPF: сотни патентов), и новые перестали появляться после 2023.
- **НО терминология мигрировала в финансовую токенизацию активов (RWA)** — это отдельный живой
  тренд 2024+ (банки/эмитенты), который PPUBS ловит по тем же словам. **Урок терминологической
  путаницы (§7.2 правило):** «NFT» в 2021-22 = коллекционный токен, в 2025-26 = компонент
  стратегии «токенизации активов» крупных банков. Без ценза по assignee/смыслу патентный ряд
  выглядел бы «растущим», хотя предмет мигрировал.

## 3. Что это меняет для кейса IT-NFT (и для модели)

1. **Фича `conversion` для IT-ложных трендов становится измеримой** (ранее `deferred_until_lens`):
   мерять НЕ только «есть патенты/нет», а **(а) число изобретений на год до года окна** и
   **(б) состав заявителей** (ТНК/банки vs стартапы-маркетплейсы). Для NFT: к году окна (2023)
   патентов 4-6/год, заявители — стартапы обменники (не ТНК-конверсия) → согласуется с
   ❌ «рынок без конверсии в масштабе».
2. **Патентный коллапс НЕ обязателен для «ложного тренда»** — это различие с СП-кейсами
   (SMES: патенты были всегда, но 0 конверсий в рынок). Для IT-хайпа патентная кривая может
   даже расти за счёт терминологической миграции — нужен **смысловой ценз** (assignee +
   класс заявителя + предмет), а не только частота термина.
3. **Кандидат-правило для ML:** «рост патентов в ОКОННОМ году окон + доля коллекционных/стартап-
   заявителей высока + рыночный коллапс → ложный тренд с миграцией термина» (анти-«ТНК-конверсия»).
   Согласуется с правилом (а) «гранты/программы без патентной конверсии ТНК и рынка = хайп».
4. **ИТ-кейс №1 (NFT) получает недостающий 5-й слой** → метка «не_состоялся (миграция термина)»
   предлагается к подтверждению автором (обновление `features_table_IT.csv`).

## 4. Ограничения

- Только US-юрисдикция (USPTO PPUBS — полнотекстовый US). KR/CN/JP/EP-слой не добирался
  (в IT-кейсе это допустимо: технология US-центрична; EP доступен через EPO OPS, KR — KIPRIS,
  если понадобится).
- PPUBS полнотекстовый → 9/32 = шум (неточное совпадение фразы в тексте); в core/infra взяты
  только смыслово подтверждённые по титулу.
- 2026 неполный год (выкатка до 17.09.2026), ряд по filing-годам честный; L2-дедуп по семьям
  (assignee+смысл): Tulip ×3, HIWAVE ×2×2, Templum ×2 схлопнуты.
- Один кейс (n=1) — вывод «патенты не коллапсируют при хайпе» требует пар (метавселенная,
  промпт-маркетплейсы, Web3) — очередь GP #2-4 может быть закрыта тем же каналом.
