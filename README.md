# Weak Signals Service — Сервис выявления зарождающихся технологических трендов

> ИТ-сервис на базе ML с возможностью ввода технологического направления и получением
> списка **зарождающихся научно-технологических трендов** с детальной аналитикой
> (мотивация → какую проблему решает тренд, кейс-пример, источник).
> Проект хакатона «Лидеры цифровой трансформации 2026» (Газпромбанк.Тех).

**Прототип (работающий стенд):** http://85.137.95.74/
Ввод технологического направления → топ-15 «Зарождающиеся технологии» с оценкой
(новизна × рост × воздействие), релевантностью запросу и разделом «Решаемая проблема»,
+ крупные темы OpenAlex как второй слой контекста.

## Научное ядро (что мы сделали и проверили)

1. **Диагноз данных** — протокол документальной проверки предоставленного датасета
   (`docs/01`): заметная доля строк не является слабыми сигналами; «+» неоднородна.
2. **Эталон-бэктест** — 30+ кейсов «сигнал 2018 → исход 2026» в `case_studies/`
   (документированные исходы: состоялся / провал / ниша), сквозной реестр —
   `results/calibration/CASE_REGISTRY.md`, таблица фич — `results/features_table.csv`.
3. **90+ бейзлайнов и гипотезы H1–H29** — почему «простые» правила ≈ «сложные» модели
   при малых данных (`docs/03`, отчёты в `methodology/hypotheses/`).
4. **Синтез метода** — двухэтапный конвейер (`docs/04`, `docs/06`):
   *скрининг* `novelty × growth × impact` (только данные до года окна, без look-ahead)
   → *верификация* (проблема → класс-проблема → нормированный рост → патенты/игроки →
   конференции → гранты → IPO/M&A → вердикт `impact × adoption × conversion`).
5. **Перекрёстная проверка** на строках заказчика (`docs/05`): отсев зрелого, хайпа,
   шумов и стандартов.
6. **Работающий сервис** — код в `webapp/`, стенд по ссылке выше; приёмка выдачи
   (покрытие/мусор/наличие эталонных сигналов) — скриптами в `scripts/`.

## Запуск прототипа

```bash
python3 -m venv .venv && .venv/bin/pip install -r requirements.txt

# самопроверка кода сервиса (без данных):
.venv/bin/python webapp/app.py --selftest   # ожидаемо: SELFTEST OK

# полный запуск (нужны артефакты данных: индексы тем, NGI-кэши, вектора карточек —
# они НЕ входят в репозиторий из-за объёма; готовый стенд развёрнут по ссылке):
WEBAPP_CARDS=1 WEBAPP_GATE=1 WEBAPP_TAU=0.84 WEBAPP_LLM_GATE=1 WEBAPP_RELAX_TOK=1 \
  .venv/bin/uvicorn app:app --host 0.0.0.0 --port 8000   # из каталога webapp/
```

Приёмочные скрипты (метрики выдачи): `scripts/qa_two_problems.py`,
`scripts/presence100.py`, `scripts/stage0_capture.py`, `scripts/qa_demo_accept.py`.

## Данные и источники

- **OpenAlex** — снапшот базы (публикации, цитаты, темы); мульти-база сигналов:
  арXив, патенты (Google Patents), гранты (NSF/NIH/KAKEN/NSFC/CORDIS/РНФ),
  конференции (IEEE TAS, EUCAS/TASC), GitHub, рынок (гелий, РЗЭ).
- **`data/official_docs/100_слабых_технологических_сигналов_сентябрь_2026.xlsx`** —
  100 сигналов заказчика (эталон метрики presence@15).
- Сырые базы и тяжёлые артефакты в репозиторий не включены (вес); паспорты
  воспроизводимости — рядом с данными в кейсах (`signals/data_passports/`).

## Не входит в репозиторий

PDF-оригиналы литературы (вместо них — выжимки), сырые данные и индексы (~ГБ),
внутренние рабочие журналы, ключи/токены. Лицензия не указана (согласно решению автора).
