# Дискриминация статей: фундаментальные vs прикладные (лексика)

> **Дата:** . **Папка:** `case_studies/001_ibad_mgo/literature/Discrimination/`
> **Метод:** семантический классификатор v2 (`src/semantic_shift_v2.py`, F1=0.91 на золотом
> стандарте) + коррекция по заголовку/аннотации. Пороги: eng%≥15% → applied;
> eff%>eng%×1.5 и eff%≥5% → fundamental; иначе mixed → решается по заголовку.
> **Данные:** `results/case_signals/discrimination_verdicts.json`

## Интерпретация (для кейса IBAD-MgO)

**Хронологический паттерн идеально совпадает с S2-гипотезой «открытие → инжиниринг»:**

- **1991-1997 (фундамент метода):** все статьи фундаментальные/смешанные — первая
  демонстрация IBAD-YSZ (Iijima 1991), рост текстурированных плёнок (Iijima 1992),
  механизм текстурирования MgO и сравнение с YSZ (Wang 1997), влияние параметров
  осаждения (Knierim 1997). Это фаза «мы показали, что работает».
- **2018 (обзор):** смешанная — подведение итогов фундамента + прикладных методов.
- **2023-2026 (производство/оптимизация):** все прикладные — подготовка буферных слоёв
  для длинных лент (Yu 2023), оптимизация CeO₂-буфера (Wu 2025), пилотное производство
  30-мм лент KC4 (Baruah 2026). Это фаза «мы оптимизировали производство».

**Это прямое подтверждение сигнала S2 на уровне статей** (не только SNF-докладов):
лексика статей по IBAD смещается от «открытие/механизм» к «производство/оптимизация».
В отличие от SNF-агрегата (где сдвиг оказался глобальным для всех тегов), здесь —
**специфичная хронология IBAD**: фундамент 1991-1997 → производство 2023-2026.

⚠️ **Оговорка:** выборка мала (9 статей, подобраны как «дискриминационные»). Это
качественная иллюстрация, а не статистика. Смешанные (1992 ISS, 2018 обзор) — реально
гибридные (фунд. работа с прикладной мотивацией).

## Метод (кратко)

1. `pdftotext` → чистка (`clean_text`: ESNF/TAS-шапки, references, DOI, license).
2. Абзацы → `classify_paragraph` (стеммированные токены ∩ ENG/EFF-словари + многословные
   паттерны + «достижение в производственном контексте»).
3. `classify_document`: eng% / eff% по абзацам; пороги → вердикт.
4. Коррекция mixed по заголовку/аннотации (производственная vs научная цель авторов).
5. Пороги настроены на золотом стандарте (100 абзацев, F1=0.91).
