# Открытие: ссылки детектируют зарождающийся тренд РАНЬШЕ, чем количество работ

> **Дата:** . **Кейс:** IBAD-MgO. **Статус:** гипотеза (проверить на др. кейсах).
> Скрипт: `src/trend_phases.py`. Данные: `results/case_signals/trend_phases.json`.

---

## 1. Суть открытия

**По метрике «ссылки на ядра кластера» зарождающийся тренд детектируется раньше,
чем по метрике «количество работ» (публикаций).**

### Данные по IBAD-MgO:

| Год | Публикации (работ/год) | Ссылки на ядра (раз/год) | Что происходит |
|---|---|---|---|
| 1997 | 1 (Wang) | 0 | **Зарождение**: выход ключевой статьи |
| 1999 | 14 | **2** | Первые работы ссылаются на Wang |
| 2000 | 17 | 4 | Рост ссылок |
| 2001 | 22 | **10** | Рост ссылок ускоряется |
| 2002 | 21 | 6 | |
| 2003 | 26 | 11 | |
| 2004 | 34 | 14 | |
| 2005 | 29 | 14 | |
| 2006 | 27 | **21** | **Пик ссылок на ядра** |
| 2007-2015 | 8-27 | 2-13 | Спад ссылок на ядра (тема устоялась) |
| 2013+ | 2-13 | — | Зрелость |

### Ключевое сравнение:

- **Зарождение по ссылкам: 1999** (первая работа ссылается на Wang) — через **2 года** после Wang
- **Зарождение по работам: 1997** (выход Wang) — по определению

**Но важнее:** *ускоренный рост ссылок* (Δ²>0, по методике автора) виден в **2001-2005**,
когда число ссылок на ядра выросло 2→21 (×10). А по *числу работ* рост (17→34) был
плавным, без резкого ускорения — пик работ 2004 (34), тогда как пик ссылок 2006 (21).

**Вывод-гипотеза: ссылки на ключевые работы (ядра) — более чувствительный ранний
индикатор зарождающегося тренда, чем объём публикаций.** Причина: когда тема
зарождается, первыми её «подхватывают» цитирующие работы (ссылки на ядро), и только
потом растёт общий поток публикаций.

## 2. Методика определения фаз (как это работает)

### Ядро кластера = работы с макс. числом входящих ссылок внутри корпуса

```
incoming[work] = число работ корпуса, которые ссылаются на work
ядро = топ по incoming
```

Результат для IBAD: Wang 1997 (40), Arendt 2004 (25), Foltyn 1999 (17), ISD 2002 (17).

### Фазы тренда (по решению автора: развитие = ускоренный рост):

```
1. Зарождение = год выхода ключевой статьи (Wang 1997)
   + год первой ссылки на неё (1999)
2. Развитие = годы, где Δ(y) > 0 И Δ²(y) > 0
   (Δ = рост числа ссылок, Δ² = рост роста = ускорение)
   На главной фазе роста (до пика): 2002-2005
3. Состоялся = год пика ссылок на ядра (~2006)
   + кросс-проверка counts_by_year: плато 250-430 (2012-2026) — зрелость
```

### Ограничения:
- OpenAlex counts_by_year покрывает только 2012-2026 (ускоренный рост 1999-2006
  виден только в references).
- Ссылки на ядра падают в зрелости (на ядро ссылаются как на факт, а не новость) —
  поэтому «состоялся» определяем по пику ссылок, а зрелость — по плато counts_by_year.

## 3. Что проверить на других кейсах

Для верификации гипотезы «ссылки раньше работ»:
1. Взять другой кейс (corc, smes, mgb2, fusion) с известной историей.
2. Посчитать: когда ссылки на ядра начали ускоряться vs когда начался рост работ.
3. Если ссылки систематически опережают работы на 2-5 лет — гипотеза подтверждается.

**Это потенциально новый индикатор S3** («кластер цитирований») — ранний детектор
зарождающегося тренда, более чувствительный, чем объём публикаций.
