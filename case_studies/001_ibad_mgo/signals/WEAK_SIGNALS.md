## 1. Хронология слабых сигналов (термин → год первого появления)

| Год | Сигнал (термин) | Интерпретация |
|---|---|---|
| **1997** | IBAD-YSZ буфер (ysz buffer) | Рождение метода IBAD на YSZ |
| **2000** | Кубическая текстура (cube texture) | RABiTS-линия (никелевые ленты) |
| **2001** | Сид-слои буферов (seed layers) | Развитие многослойных буферов |
| **2004** | Само-эпитаксия MgO (self-epitaxial) | Ключ IBAD-MgO (быстрый рост) |
| **2004** | Скорость производства (fabrication rate) | Переход к производительности |
| **2006** | Искусственный пиннинг (artificial pinning) | Начало улучшения Jc |
| **2006** | MgO буфер (mgo buffer) | IBAD-MgO становится основным |
| **2012** | Легированный YBCO (doped ybco) | Легирование (BZO и др.) |
| **2012** | La2Zr2O7 буфер (lanthanum zirconate) | LZO-буферы (CSD) |
| **2014** | BSO-легированный GdBCO (bso-doped gdbco) | Нанодобавки в REBCO |
| **2014** | Планаризация (planarization layer) | CSD-планаризация (удешевление) |
| **2016** | Магнитный пиннинг (magnetic pinning) | Новый тип пиннинга |
| **2016** | Fe(Se,Te) плёнки (fesexte thin) | Железосодержащие сверхпроводники |
| **2021** | BZO наноструктуры (bzo nanostructure) | Нанопиннинг |
| **2023** | Эпитаксиальный MgO слой (epi-mgo) | Само-эпитаксия зрелая |
| **2023** | IBAD-MgO слой (ibad-mgo layer) | Технология — рутина |
| **2026** | Джозефсоновские переходы (josephson) | Новое применение (квант) |

## 2. Что это даёт (чтение динамики)

**Три волны слабых сигналов:**

1. **1997-2004 (рождение метода):** IBAD-YSZ → cube texture → seed layers → **self-epitaxial MgO**.
   Это фаза «как сделать текстуру» — фундамент технологии.

2. **2006-2016 (улучшение свойств):** artificial pinning → doped YBCO → BSO-GdBCO →
   magnetic pinning → Fe(Se,Te). Фаза «как поднять Jc» — научный бум (пиннинг).

3. **2014-2026 (производство + новые применения):** planarization (удешевление) →
   BZO nanostructures → epi-MgO (зрелость) → **Josephson junctions (квантовые
   применения — новый слабый сигнал!)**.

**Ключевой слабый сигнал СЕЙЧАС:** «Джозефсоновские переходы» (2026) — IBAD-MgO
ленты начинают применяться в квантовых технологиях. Это потенциально **новый
зарождающийся тренд** (аналогично тому, как artificial pinning в 2006 предвещал
бум 2010-х).

## 3. Методика (кратко)

- Биграммы из абстрактов → частотность по годам (нормировано на число работ).
- Слабый сигнал = термин впервые появился в год Y и рос далее.
- Вручную отобраны 17 СМЫСЛОВЫХ терминов (без мусора: "have been", "the other").
- Ограничение: малые выборки поздних лет (2018: 1 работа, 2025: 1) — сигналы
  2023-2026 могут быть шумными, но Josephson (5 вхождений в 2026 из 4 работ) — заметен.
