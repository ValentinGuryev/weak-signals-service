> **Итог после 3 итераций.** Грантов по IBAD **есть много**, но они скрыты под терминами «coated conductor» / «2G-HTS» / «YBCO/REBCO tape» (правило синонимов, KNOWHOW §7).

### Почему 3 из 4 начаты в 2017? (вопрос автора)
**Это не случайность, а H2020-окно.** EASITrain, FASTGRID, SynFoNY стартовали в январе 2017 — это результаты **конкурсов H2020 2016 года** (MSCA ITN/Innovation Actions). Европа тогда **консолидированно закладывала финансирование coated conductor** (все 3 — про REBCO/YBCO ленты). IMPACT (ERC PoC 2020) — позднее «коммерциализация» той же темы. Патентный пик IBAD (2009-2011) предшествует грантам на 6-8 лет — **гранты догоняли уже зрелую технологию**.

## 5. Вывод для кейса

**Прямых грантов именно на «переход промышленного производства на IBAD-MgO» НЕТ ни в одной открытой базе** (проверено: CORDIS 0 по узким запросам, NSF 0 прямых, KAKEN 0 прямых, РНФ 0). Это ожидаемо: IBAD-MgO — **индустриальная технология** (разработана LANL в 1990-х, внедрена Fujikura/SuperPower), финансировалась через национальные лаборатории и корпоративные R&D, не через открытые гранты.

**Что есть вместо прямых грантов — косвенные, по всей цепочке coated conductor:**
- **EASITrain** (CERN, €3.84M) — единственный с прямым отношением (через Bruker ABAD-публикацию)
- **SBIR Metal Oxide Technologies** (NSF, $256k, 2023) — «reactor enhancements for HTS wire production on textured metal base tape» — косвенно про производство на IBAD-подложке
- **NSFC 2G-ленты** (Китай, 3 гранта)
- **KAKEN** (Япония, 232 гранта по coated conductor/REBCO/YBCO — но не по IBAD-подложкам как таковым)

**Методологический вывод:** отсутствие грантов по конкретной технологии-инструменту (IBAD-MgO) ≠ отсутствие тренда. Гранты финансируют **продукт** (coated conductor / 2G HTS), а не инструмент. Для IBAD-MgO единственный сильный сигнал — патенты (пик 2009-2011) + SNF (476 докладов) + индустрия.

**Грантовый сигнал для кейса IBAD-MgO: СЛАБЫЙ (косвенный).** Основные сигналы — патенты и индустрия.
