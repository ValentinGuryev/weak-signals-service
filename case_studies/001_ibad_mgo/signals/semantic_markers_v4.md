## 1. Главный вывод (документируется как интересный результат)

**Разделение «фундаментальное vs прикладное» по лексике НЕ работает для IBAD** —
и это сам по себе научный результат (не провал метода).

| Что пробовали | Результат |
|---|---|
| V1: regex appl/lab лексика (2008-2025) | Δ −19→+23 — **артефакт багов** (подстроки, дисбаланс словарей) |
| V2: чистые границы + стемминг + бутстрап | Сдвиг есть, но **глобальный** (все теги SNF, не IBAD) |
| V3: дискриминатор по абстрактам OpenAlex (426 работ) | Доля applied **стабильна 8-28%**, монотонного роста нет |
| V4 (этот): поиск других монотонных маркеров | **Найдены другие маркеры** (см. §3) |

**Почему деление не работает для IBAD:**
1. Научные статьи по IBAD остаются материаловедческими во все годы — производство
   ушло в патенты/SNF, а не в журналы.
2. Прикладная нота в конце абстрактов («for applications») завышает applied у
   фундаментальных работ — верхняя граница.
3. Ранние «applied» — это обзоры/программы (реально прикладные), не фундамент.
4. Валидация: 8/9 на экспертных статьях (89%), но Foltyn/Kreiskott (демонстрация
   лент) — корректно applied, а не «фундаментальные» (я их изначально неверно пометил).

**Проверка на других кейсах:** это надо повторить (тот же wordshift-анализ) на
других кейсах (corc, smes, fusion, mgb2) — понять, является ли «невозможность
деления» общей чертой или спецификой IBAD.

## 2. Новые семантические маркеры (найдены)

Несмотря на невозможность деления на «фундамент/прикладное», **есть другие
монотонные маркеры**, меняющиеся со временем:

### 2.1 Убывание лексики «текстура/IBAD/ориентация» (OpenAlex) — ОСНОВНОЙ

| Слово | 1997-2001 → 2022-2026 |
|---|---|
| `ysz` | 10.7 → **0** |
| `textur` | 19.1 → 12.2 |
| `biaxial` | 8.6 → 4.8 |
| `ibad` | 6.5 → 3.0 |
| `assist` (ion-beam assisted) | 5.5 → **0.4** |
| `orient` | 6.5 → 3.9 |

**Интерпретация:** лексика «как сделать текстуру» (технология шаблона) монотонно
убывает — тема ушла из фокуса статей (стала рутиной). Это **маркер зрелости**: технология
IBAD-шаблона перестала быть предметом исследований. Это IBAD-специфичный маркер.

### 2.2 Экстремумы (пик 2012-2016)

| Слово | Траектория (OpenAlex) |
|---|---|
| `pin` (пиннинг) | 0.6 → 1.7 → 1.8 → **6.5** → 1.1 → 1.3 (пик 2012-2016) |
| `transport` | 1.9 → 2.3 → 2.7 → **4.9** → 1.1 → 2.6 (пик 2012-2016) |

**Интерпретация:** бум исследований пиннинга/транспорта в 2012-2016 (нанодобавки
BZO/BHO для Jc) — пик научной активности, затем спад (зрелость). Это **экстремум**, а не
монотонный тренд — маркер фазы «перегрева» темы.

### 2.3 Растущая лексика (SNF, оба тега)

`fusion` (0.6→5.1 у IBAD, 0.8→9.8 у cables), `energi`, `china`, `univers`, `termin`
(терминалы кабелей) — **глобальный тренд** прикладной сверхпроводимости (термояд,
энергетика, Китай), не специфичен для IBAD.

## 3. Что это даёт для кейса IBAD-MgO

| Сигнал | Тип | Значение для кейса |
|---|---|---|
| Текстура-лексика падает | монотонное падение | IBAD-шаблон стал рутиной (зрелость) |
| pin/transport пик 2012-16 | экстремум | Пик научного интереса прошёл, тема созрела |
| «фунд vs прикл» деление | НЕ работает | S2 «открытие→инжиниринг» — глобальный фильтр, не дискриминатор |

**Для S2-гипотезы:** вместо «открытие→инжиниринг» (который не подтвердился) —
работает **«технология-специфичная лексика убывает»** (зрелость). Это переопределение S2:
не «фундаментальное vs прикладное», а «**исследовательский фокус уходит из технологии**».

## 6. Визуализация маркера (график 5)

**Тренд «исследовательский фокус уходит из технологии»** — убывание текстура-лексики
(textur, biaxial, ibad, ysz, assist, orient, align, epitaxi) в абстрактах OpenAlex.

### Пер-документная сумма текстура-лексики (‰) с 95% ДИ (бутстрап)

| Период | Работ | Сумма ‰ | 95% ДИ |
|---|---|---|---|
| 1997-2001 | 51 | **64.7** | [53.6, 78.2] |
| 2002-2006 | 116 | **51.6** | [45.2, 58.4] |
| 2007-2011 | 87 | **45.2** | [37.2, 53.0] |
| 2012-2016 | 58 | **34.4** | [25.8, 41.7] |
| 2017-2021 | 28 | **23.4** | [15.0, 32.8] |
| 2022-2026 | 19 | 29.0 | [16.0, 44.1] |

**Монотонное падение 64.7 → 23.4‰ (×2.8) с 1997 по 2021 — статистически значимое**
(ДИ соседних периодов не пересекаются до 2017). Отскок 2022-2026 (29.0‰) — в пределах
шума (ДИ [16, 44] перекрывается с 2017-2021), частично реален (работы по Fe(Se,Te)
и широким лентам возродили интерес к текстуре).

**Интерпретация:** тема «как сделать текстуру/шаблон» монотонно уходит из фокуса научных
статей — технология IBAD-шаблона стала рутиной (зрелость). Это маркер S2 v4:
«исследовательский фокус уходит из технологии».

⚠️ Докачка 4 якорей (Matias 2009, Hühne 2005, Yamada 2004, Usoskin) отложена — OpenAlex
держит 429 (rate limit после больших поисковых прогонов). Единичные работы из 426,
не влияют на тренд.
