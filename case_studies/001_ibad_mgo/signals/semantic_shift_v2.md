## 2. Валидация классификатора (тренировочный сет)

**Прокси-метка (идея автора):** статьи IBAD до 2005 — «фундаментальные», SNF-доклады
с производственной лексикой — «прикладные». Это не ручная разметка, но даёт
контрастные пулы для отладки.

- **Фундаментальный пул:** 101 статья OpenAlex ≤2005 (Wang 1997, Arendt 2004, Foltyn 1999...)
- **Прикладной пул:** 161 SNF-доклад с производственной лексикой (Fujikura, SuperPower, R2R, mass production)

**Метрики (документный уровень, eng>eff → applied):**
- Precision(applied) = **0.70**, Recall = **0.87**, **F1 = 0.78**

### Золотой стандарт (ручная разметка по смыслу, 100 абзацев)

**Прокси-метка «по году» неточна** (~25% работ 2000-х по механике/AC-loss — фактически
прикладные). Поэтому собраны 100 абзацев, размеченных по СМЫСЛУ:
- 29 «фундаментальных» (открытие/механизм/теория)
- 71 «прикладной» (производство/масштаб/коммерциализация)

| Метод | Accuracy | Precision | Recall | F1 |
|---|---|---|---|---|
| **Rule-based (semantic_shift_v2)** | **0.91** | **0.96** | **0.92** | **0.94** |
| ML (TF-IDF + LogisticRegression, 5-fold CV) | 0.86 | 0.84 | 1.00 | 0.91 |

Rule-based на малой выборке (100 абзацев) не хуже ML и интерпретируем. ML-фичи
подтверждают словари: applied ← production, cable, commercial, technology, tape;
fundamental ← films, YBCO, revealed, demonstrated, pole figure, MgO.

**Анализ ошибок (важно для интерпретации):**
- «fundamental→applied» ошибки: «Tensile fracture», «strain effect», «AC loss», «residual stress»
  (2000-е) — это **реально прикладные** работы (механика лент, испытания), прокси-метка
  «по году» ошибочна. Классификатор ПРАВ.
- «applied→fundamental»: «High Performance 2G wires: R&D to Pilot», «Computation of Losses»
  — **смешанные** доклады (R&D+производство, физика потерь).

## 4. ГЛАВНЫЙ ВЫВОД (пересмотр вердикта v1)

**V1 показал монотонный сдвиг −18.7 → +27.4 (кроссовер ≈2017-2019) — это АРТЕФАКТ
багов:** подстроки (`magnet`→`magnetic`, `tape`→`tapered`), дисбаланс словарей,
отсутствие чистки текста. V2 с исправленными границами слов показывает:

1. **Сдвиг к «прикладному» ЕСТЬ** — eng% у IBAD растёт 18.6% → 29.5% (2008-2010 → 2023-2025),
   Δappl−lab +14.9 → +16.5. Но этот сдвиг **ГЛОБАЛЬНЫЙ** — все теги SNF (cables, fusion,
   mri, mgb2) сдвигаются одинаково. Это тренд всей прикладной сверхпроводимости
   (конференции с 2020 стали системнее/прикладнее), а не IBAD.
2. **Разница IBAD vs контроль по eng% ≈ 0-3 п.п.** (IBAD 2023-2025: 29.5% vs контроль
   25-31%) — S2-сигнал **слабо специфичен для IBAD-MgO**.
3. **IBAD-специфика — в S1/S4:** патенты (пик 50/год 2011), SNF-присутствие
   (476 докладов), скорость IBAD-MgO (секунды vs часы IBAD-YSZ).
4. **eff% у IBAD остаётся высоким** (16.0% в 2020-2022, 13.0% в 2023-2025) — живой
   научный фронт даже в зрелой технологии. Это отличает IBAD от «мёртвых» тем.

**Для кейса 001_ibad_mgo:** сигнал S2 «открытие→инжиниринг» — **глобальный фильтр
зрелости области, слабо дискриминативен внутри области**. Вердикт «тренд состоялся»
опирается на S1 (мульти-база) + S4 (снятие предела скорости), а S2 подтверждает
зрелость области, но не уникальность IBAD. Это УТОЧНЕНИЕ методологии: S2 применим
как глобальный фильтр зрелости, для сравнения КОНКУРЕНТОВ внутри области — слаб.

### Главный вывод (v3, по абстрактам)

**Доля прикладных абстрактов СТАБИЛЬНА (11-23%) без монотонного роста** — научные
статьи по IBAD во все годы остаются в основном материаловедческими/фундаментальными
(«magnetic granularity», «microstructure», «structural analysis», «epitaxial growth»,
«oxygen diffusion»). Даже в 2021-2024 (56% фундаментальных) — это исследования свойств
на зрелой технологии.

**Это методологически важно:** производственный сдвиг IBAD виден в **SNF-докладах**
(полные тексты: eng% 18.6→29.5) и **патентах** (пик 50/год 2011), а НЕ в научных
статьях. Журнальная наука по IBAD остаётся материаловедческой — производство живёт
в индустриальных каналах (патенты, конференции, SNF).

**Для кейса:** S2-сигнал по абстрактам OpenAlex НЕ показывает «открытие→инжиниринг»
(прикладных не становится больше). Это подтверждает: S2 — фильтр зрелости области
в целом, для IBAD решающие сигналы — S1 (патенты/SNF/рынок) и S4 (скорость IBAD-MgO).
Вердикт «тренд состоялся» опирается на них, а не на сдвиг лексики статей.

### Оговорки
- Малые выборки поздних периодов (2021-2024: 17, 2025-2026: 5) — шум.
- Абстракты короткие (2-5 абзацев) — пороги дискриминатора ужесточены (абстракт-режим).
- OpenAlex search не покрывает все синонимы; часть производственных работ могла не попасть
  (они в SNF/патентах). Якорные работы (Wang 1997, Foltyn 1999, Kreiskott 2004, Iijima
  1991/1992) дозагружены по DOI/PDF (см. §8). Matias 2009/Hühne/Yamada/Usoskin — отложены
  (OpenAlex 429 rate limit, единичные работы).
- «Смешанные» (30-57%) — реально гибридные работы (физика + производство).

### 8.1 Тест на 9 экспертно-размеченных статьях (Discrimination/)

| Статья | Классификатор | Эксперт | ✓ |

| Iijima 1991 — First IBAD-YSZ | fundamental | fundamental | ✓ |

| Iijima 1992 — Biaxially Aligned YSZ (ISS) | mixed | fundamental | ≈ (есть прикладная мотивация «for cables» — гибрид) |

| Yu 2023 — MgO Self-Epitaxial | applied | applied | ✓ |
| Wu 2025 — CeO₂ Buffer Optimization | applied | applied | ✓ |
| Baruah 2026 — 30mm Wide KC4 | applied | applied | ✓ |

**Точность: 8/9 строгих (89%), 1 частичное** (гибридная работа 1992 ISS — классификатор прав).

### 8.2 Кросс-проверка «цитаты vs вердикт» (якоря)
- Wang 1997 (314 цит, механизм текстурирования) → **mixed** (конец абстракта: «economical
  application in real manufacturing» — прикладная нота завышает eng). ⚠️ Ограничение метода.
- Foltyn 1999 (151 цит, meter-long tapes) → **applied** — ПРАВИЛЬНО: это производственная
  работа (96 A на 87 см ленте, continuous process), а не фундамент.
- Kreiskott 2004 (53 цит, R2R IBAD-MgO) → **applied** — ПРАВИЛЬНО: R2R = производство.

### 8.3 Анализ ранних applied (почему не фундаментальные)
Ранние (≤2005) applied — это в основном **обзоры/программные отчёты** («Evaluation of
methods for application», «DEVELOPMENT OF IN-SITU CONTROL DIAGNOSTICS», «Recent Development
of High-Tc») — реально прикладные (обзоры методов производства). Классификатор прав.

### 8.4 Известные ограничения (честно)
1. **Прикладная нота в конце абстракта** («for applications», «in real manufacturing»)
   завышает eng у фундаментальных работ (Wang 1997 → mixed). На агрегате это даёт
   верхнюю границу доли applied.
2. Абстракты короче полных текстов → пороги ужесточены, но «смешанных» много (30-57%).
3. Ранние applied — это обзоры (реально прикладные), не фундаментальные работы.

**Вывод: дискриминатор работает (89% на экспертных статьях), ограничения понятны.
Доля applied по абстрактам — ВЕРХНЯЯ граница (реальная доля прикладных в журналах
ниже, т.к. часть applied-сигнала — прикладные ноты в конце фундаментальных абстрактов).**
