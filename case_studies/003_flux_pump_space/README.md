# Кейс 003: Flux pump для космоса — питание ВТСП-магнитов без токовводов

> **Роль:** третий кейс после 001 (IBAD-MgO — состоялся) и 002 (RCE-DR/TLAG — не состоялся).
> **Отличие от 001/002:** это НЕ удешевление производства ВТСП-2G лент, а **применение**
> этих лент (flux pump использует REBCO-ленты). Механизм ценности — устранение
> токовводов (главного источника теплопритока в криостате).
> **Статус:** оформляется () на основе проекта Flux_pump (102 статьи в literature/).

---

## 1. Суть технологии

**Накачка магнитного потока (HTS flux pump)** — питание ВТСП-магнитных систем БЕЗ токовводов:
- Токовводы — главный источник тепла в криостате (80 мВт/А при 295→77 K)
- Flux pump преобразует переменное поле в постоянный ток в замкнутом контуре
  индуктивно (без гальванического контакта)
- Механизм: динамическое сопротивление HTS-ленты (R_dyn) + направленное движение вихрей
- Ключевое: **не удешевление лент, а устранение системного узкого места**

**Почему для ВТСП особенно актуально:**
- LTS-магниты: сверхпроводящие спаи возможны → персистентный режим работает без flux pump
- ВТСП-ленты (REBCO): сверхпроводящий спай труден → крип потока + сопротивление соединений
  медленно гасят ток → flux pump поддерживает ток квази-персистентно

## 3. Миссия Hēki (ядро кейса)

**Первая в мире космическая демонстрация HTS-магнита + flux pump:**
- Запуск 14.09.2025 (Cygnus NG-23), JEM-EF #4 (МКС)
- Магнит: 4 double-pancake SuperOx REBCO, bore 62 мм
- Flux pump: self-rectifier (трансформатор + HTS-мост как диод)
- **Результаты:** 500 мТл при ~55 Вт, накачка ~0.2 Вт, работа 6 мес без деградации
- Теплоприток flux pump ~150 мВт vs 1476 мВт токовводов → **10% от токовводов**
- Квенч-защита сработала (незапланированный квенч → восстановление)
- 12 целей миссии — все выполнены

**Значение:** flux pump из лабораторного курьёза стал бортовой аппаратурой.
Два драйвера: дешевеющая HTS-лента (кейс 001!) + миниатюрные криокулеры.

## 4. Вердикт (анализ)

**✅ СТОИЛО** (подтверждается):
1. Устраняет главную проблему криостата (токовводы) — фундаментальная ценность
2. kA-уровни к 2019 (1.1 kA) — быстрый прогресс, не «вечно в R&D»
3. Несколько применений: генераторы, маглев, NMR/MRI, космос — не одна ниша
4. **Космическая демонстрация 2025-2026** — промышленная зрелость

## 5. Связь с кейсами 001/002

| Аспект | 001 IBAD-MgO | 002 RCE-DR/TLAG | 003 Flux pump |
|---|---|---|---|
| Цель | Удешевление лент | Удешевление лент | **Применение лент** |
| Слой | Буфер (MgO) | Сверхпроводник (REBCO) | Устройство на REBCO |
| Механизм ценности | Скорость текстуры | Скорость роста | **Устранение токовводов** |
| Исход | ✅ состоялся | ❌ не состоялся | ✅ стоило (подтверждено) |
| Зависимость от 001 | — | Использует IBAD | **Использует REBCO (001+002)** |

**Ключевое:** 003 — пример «нисходящего» тренда (применение), в отличие от
001/002 — «восходящих» (производство). Это третий тип для модели:
- 001: производственный тренд (успех)
- 002: производственный тренд (провал)
- 003: прикладной тренд (успех)
