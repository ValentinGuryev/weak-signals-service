## Суть работы
Обзор всех классов сверхпроводящих источников тока (flux pumps) за ~20 лет (к 1981): принципы, материальные проблемы, ограничения. Часть 1: механические устройства (flux compressors, dynamos) + начало электрических выпрямителей. Уравнение: V − dΦ/dt = IR + L·dI/dt (ур. 1); для сверхпроводящей петли (R = 0): Φ + L·I = const (ур. 2) — сохранение потока.

## Принцип
- **Сохранение потока**: Φ + L·I = const (ур. 2) для R = 0.
- **Схема (рис. 1)**: две параллельные переключателя S1/S2; S2 закрыт (сохранение тока), S1 открыт → добавление потока Φ0; S1 закрыт, S2 открыт → ток в нагрузке.

## Flux compressor (механический)
- **Конструкция**: два цилиндрических отверстия + узкий слот; внешнее поле параллельно осям; охлаждение до 4.2 К.
- **Поршень**: вставка сверхпроводящего поршня в отверстие A → поток вытесняется в отверстие B.
- **Формула**: B_final = (area до/после)·B_initial − B_losses (ур. 3).
- **Компрессия**: механическая работа → магнитная энергия; любой коэффициент сжатия (в пределах критической плотности, flux flow диссипации, flux jump).
- **Цикличность**: два клапана-нагревателя (нормальные зоны) в стенках отверстий → циклический процесс.

## Dynamo (механический)
- Движущиеся магниты/нормальные пятна; опыт по материалам, переключателям, стабильности (ac/dc).

## Выпрямители (электрические)
- **Ток >10 кА** с высокой эффективностью.
- Индуктивная коммутация (без потерь переключения).
- Полная/полуволна.

## Ключевые результаты
- **Принцип**: V − dΦ/dt = IR + L·dI/dt (ур. 1); Φ + L·I = const (ур. 2).
- **Flux compressor**: B_final = (A₁/A₂)·B_initial − B_losses (ур. 3).
- **Механические**: компрессоры, dynamo (опыт по материалам, переключателям, стабильности).
- **Выпрямители**: ток >10 кА, высокая эффективность.
- **Мотивация**: Ic > 5 кА при 5 Тл (типовые); теплоприток токовводов; высокая эффективность → меньшие криосистемы.
- Применения: изгибающие магниты, левитация, fusion, разделение, тест-беды, энергохранилища, высокие поля.
- Полная загрузка (малые системы) / компенсация омических потерь (большие).

## Теоретическая модель
- Сохранение потока: Φ + L·I = const (ур. 2).
- Flux compressor: B_final = (A₁/A₂)·B_initial − B_losses (ур. 3).
- Выпрямители: индуктивная коммутация, полная/полуволна.

## Конструкция flux pump
Все типы к 1981: flux compressors (поршни), dynamo (движущиеся магниты/нормальные пятна), transformer-rectifiers (переключатели); жидкий гелий.

## Ограничения и замечания авторов
- Материальные проблемы: переключатели, соединения, стабильность (ac/dc).
- Dynamo — опыт для понимания материалов; выпрямители — перспективнее (ток >10 кА).
- Часть 2 — теоретическое сравнение (см. WISHLIST).
