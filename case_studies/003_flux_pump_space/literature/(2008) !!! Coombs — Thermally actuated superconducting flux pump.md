Название: A thermally actuated superconducting flux pump
Журнал: Physica C 468, 153–159 (2008)
Год: 2008

Тип: рецензируемая статья

## Релевантность проекту: 5/5
**ИСТОРИЧЕСКАЯ ВЕХА — первый HTS travelling wave flux pump (термически-активированный)** — тепловой импульс меняет проницаемость магнитного материала (Prussian Blue analogue, NdFeB) → бегущая магнитная волна → накачка вихрей в YBCO-объём. Прямо закрывает пробел «история» (раздел 10, 2.3): от LTS (van Klundert) к HTS travelling wave. Даёт численные данные (54 мТл, 326 мТл, 120/200 мТл) и физическую модель (E-J law, уравнения 1a–7).

## Суть работы
Новый метод накачки магнитного потока в сверхпроводник без нормального пятна и без переключателей: тепловой импульс на краю тела из магнитного материала создаёт тепловую волну, которая движется через тело; изменение намагниченности/проницаемости (NdFeB — твёрдый магнит, магнитные свойства меняются с температурой; Prussian Blue аналог Ni¹·⁵[Cr(CN)₆] — мягкий, ферромагнитный при криогенных температурах) создаёт магнитный импульс, движущийся по поверхности сверхпроводника. Каждый проход увлекает вихри внутрь сверхпроводника (накачка), поле накапливается. Продемонстрировано на bulk YBCO (13 мм круглый, 23 мм гексагональный) при 77 К. Ключевое: полное запертое поле ограничено сверхпроводником, а не намагничивающим полем; метод применим к BSCCO, MgB2, тонким/толстым плёнкам.

## Магнитные материалы
- **NdFeB** (твёрдый): обратимое изменение намагниченности с температурой (растёт ниже ~120 К); малый гистерезис (~100 К).
- **Prussian Blue аналог Ni¹·⁵[Cr(CN)₆]** (мягкий): ферромагнитный переход между 100 К и 70 К; Curie-точка ~5.6 К (Prussian Blue), аналоги — шире; μ_eff ≈ 3; насыщение ~60 мТл при 40 К; при 0.3 Тл (2.5×10⁵ А/м) изменение намагниченности между 45–70 К ≈ 3×10⁴ А/м (38 мТл).
- **Изготовление**: преципитация (порошок), серебряная связка (silver Dag) — повышение теплопроводности, электрической проводимости, сохранение packing factor.

## Результаты
- **Trapped field (полевое охлаждение 0.5 Тл, 77 К)**: 13 мм круглый — 54 мТл; 23 мм гексагональный — 326 мТл (табл. 1).
- **Накачка с Prussian Blue + NdFeB** (13 мм): накачка при охлаждении (вихри увлекаются внутрь, поле растёт); при нагреве — размагничивание (реверс накачки). Смена знака градиента — доказательство накачки.
- **Накачка с NdFeB без Prussian Blue** (уменьшение магнитного сопротивления пути): 13 мм — ~120 мТл; 23 мм — ~200 мТл. Полное поле зависит от сверхпроводника, не от метода.
- **Полное запертое поле** = функция потокоудерживающей способности сверхпроводника, не метода накачки.
- Контекст: 14.4 Тл (запертое в 27 мм Zn-doped YBCO при 22.5 К) — мотивация.

## Теоретическая модель
- Осесимметричная модель: ∇×(1/(μ0μr)·∇(Az+M)) = Jz (ур. 1a); Ez = −∂Az/∂t (ур. 1b); Jz = Ez/ρ (ур. 1c); нелинейное ρ по E-J закону ρSc = (E0/Jc)·|Ez|^(1/n−1) + ρ0 (ур. 2); граничные условия: Neumann (внутренние), Dirichlet Az = 0 (внешнее) (ур. 5); магнит M = [0, Mz], Jz = 0 (ур. 6).
- Аналитически: тепловая волна → магнитный импульс → движение вихрей (всё под линией необратимости).

## Конструкция flux pump
Термически-активированный: NdFeB-магнит + Prussian Blue аналог (Ni¹·⁵[Cr(CN)₆], серебряная связка) над сверхпроводником; тепловые пути A/B (рис. 3); холодная головка для циклирования температуры; Hall-датчики; вакуумная камера; модульная геометрия.

## Ограничения и замечания авторов
- Метод применим только пока поле ниже линии необратимости (поток остаётся запертым).
- Теплопроводность Prussian Blue плохая (порошок) — нужен металлический связующий (серебро).
- Термоциклирование NdFeB обратимо (малый гистерезис) — пригодно.
- Доказано: полное поле определяется сверхпроводником, а не методом.
- Метод может быть расширен: несколько фикстур, паттернирование поля.
