## Релевантность проекту: 3/5

## Суть работы
FEM-модель намагничивания сверхпроводящих bulk-образцов (YBCO) с помощью «solid-state» flux pump — развитие термически-активированного метода Coombs 2008: вместо термического управления используется твёрдотельный переключаемый магнитный материал. Модель описывает увлечение вихрей бегущей магнитной волной через нелинейный E-J закон (ур. 1a–1c, 2) и осесимметричную геометрию (ур. 3–7). Продолжает серию Coombs по flux pumping bulk-материалов (после 2008 — термический, 2011 — твёрдотельный).

## Ключевые результаты
- FEM-модель (осесимметричная) намагничивания bulk сверхпроводников solid-state flux pump.
- Нелинейное ρ по E-J закону: ρSc = (E0/Jc)·|Ez|^(1/n−1) + ρ0 (ур. 2); смещение ρ0 = 1e−12 Ом против сингулярности.
- Осесимметричные уравнения: ∇×(1/(μ0μr)·∇(Az+M)) = Jz (ур. 1a, 4); Ez = −∂Az/∂t (ур. 1b); Jz = Ez/ρ (ур. 1c); граничные: Neumann (внутренние), Dirichlet Az = 0 (ур. 5); магнит M = [0, Mz] (ур. 6).
- Поле B = √(Br² + Bz²) (ур. 7); Br = −∂Az/∂z, Bz = Az/r + ∂Az/∂r.

## Теоретическая модель
- Осесимметричная FEM (векторный потенциал A); E-J power law (нелинейное ρ); магнит как источник M.
- Увлечение вихрей бегущей волной (как Coombs 2008).

## Ограничения и замечания авторов
- Модель осесимметричная (2D) — ограничение для 3D-геометрий.
- E-J закон с ρ0-смещением — приближение.
- Численные результаты ограничены (модель-демонстрация подхода).
