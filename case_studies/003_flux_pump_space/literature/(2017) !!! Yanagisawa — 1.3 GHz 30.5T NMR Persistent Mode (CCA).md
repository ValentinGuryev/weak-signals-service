# (2017) !!! Yanagisawa — Development of a 1.3 GHz (30.5 T) LTS/HTS NMR Magnet in the Persistent Mode (CCA)

- **Библиография:** Yoshinori Yanagisawa (RIKEN Center for Biosystems Dynamics Research, Yokohama).
  CCA 2017. IEEE/CSC SNF. Японская коллаборация под JST-Mirai Program (старт late 2017).
- **Релевантность:** 5/5 (!!!) — японская программа persistent NMR (конкурент flux pump)

## Суть
Проект JST-Mirai (Япония, с конца 2017): persistent-mode NMR магнит 1.3 GHz (30.5 Тл):
- Магнит: REBCO inner coil + Bi-2223 middle coil + LTS (NbTi/Nb3Sn) outer
- Цель: высокое разрешение NMR (исследование амилоид-бета белка и др.)
- **Persistent mode — ключевое требование** (нужны сверхпроводящие соединения)

## Ключевые результаты
- 1.3 GHz (30.5 Тл) — самый высокий persistent NMR
- Гибридная конструкция: REBCO + Bi-2223 + LTS
- Требует сверхпроводящие соединения для всех трёх типов проводов

## Выводы для кейса 003
- **Япония системно инвестирует в persistent-mode HTS магниты (JST-Mirai)**
- Для этого нужны соединения REBCO/Bi-2223 — прямая альтернатива flux pump
- Если соединения удадутся — flux pump не нужен для NMR
- Конкурентная технология развивается государственной программой
