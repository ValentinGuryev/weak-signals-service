## Суть работы
Диссертация раскрывает механизм HTS dynamo: DC-напряжение возникает из **нелинейной резистивности** (сломанная симметрия закона Ома). В сверхпроводнике циркулирующие вихревые токи: forward (под магнитом) |Jz| ≥ Jc → Ez ≠ 0 (flux flow); reverse (вне магнита) |Jz| ≤ Jc → Ez ≈ 0. Среднее поле по ширине ленты ≠ 0 → частичное выпрямление → DC. Для линейного проводника Ez ∝ Jz всегда → среднее = 0 (нет DC). Структура: гл. 1-3 (введение, обзор, методы), гл. 4 (NI катушки), гл. 5 (механизм DC), гл. 6 (характеристики dynamo), гл. 7 (менее резистивный dynamo), гл. 8 (полупроводниковый dynamo), гл. 9 (выводы).

## Глава 4. Моделирование NI катушек
- **NI (no-insulation) катушки** — чрезвычайно устойчивы к механическим, тепловым, электрическим нагрузкам и отказам.
- Простая модель: **вращательная анизотропная резистивность** (turn-to-turn ток) — захватывает физику с достаточной точностью.
- Предсказывает: shielding и magnetisation токи (присущие HTS), межвитковый ток.
- Пример: 60-витковая NI катушка; turn-to-turn ток In′; Ic = 43 А; время эволюции td + τs + τ.
- Применение: устойчивость HTS-магнитов (космос, Hēki-контекст).

## Глава 5. Механизм DC-напряжения (КЛЮЧЕВАЯ)
- DC-напряжение возникает из **нелинейной E-J резистивности** (сломанная симметрия закона Ома) — ур. 5.9.
- В сверхпроводнике циркулирующие вихревые токи: forward (под магнитом) |Jz| ≥ Jc → Ez ≠ 0 (flux flow, ρJz > 400 мкВ/см); reverse (вне магнита) |Jz| ≤ Jc → Ez ≈ 0.
- Среднее Ez по ширине ≠ 0 → частичное выпрямление → DC; для линейного проводника — всегда 0.
- **Пик ΔV до −500 мкВ** (позиция B).
- **Если ширина магнита < половины ширины ленты**: reverse-регион шире forward → Vdc ≠ 0, полярность противоположна emf.
- **n-value**: Vdc растёт с n; **n = 1 → Vdc = 0** (линейная резистивность + поле недостаточно) — **опровергает** Giaever (магнетосопротивление).
- **Jc(B,θ)**: подавление Jc под магнитом усиливает Vdc (лучшее согласие с экспериментом).
- Остаточные токи (|J| ≤ Jc) — не дают ΔV, когда магнит далеко.
- Позиции A-E магнита: A (левый край, первый −пик), B (−500 мкВ), C (центр, ΔV ≈ 0, смена направления вихрей), D/E (симметрично).
- **Расширение на LTS**: n(B,θ) → 1 при B → Bc (нормальное пятно).

## Глава 6. Характеристики и поведение dynamo
- **Модель**: dynamo = источник напряжения Voc + внутреннее сопротивление Rint (или источник тока + Rint).
- **I-V характеристики** для разных частот: все кривые начинаются с отрицательного Voc, пересекаются при V = 0.
- **Isc vs f**: короткое замыкание; **Voc vs f**: растёт; **нормированные** (поток за цикл) — показаны.
- **Rint vs f**: частота-нормированное.
- Анализ: выход vs ток, Rint vs Voc (6.5.1-6.5.2).
- Fill factor η (для статоров 12 и 60 мм) — по I-V кривой.

## Глава 7. Менее резистивный dynamo
- **Снижение Rint**: увеличение ширины статора (stator width) снижает внутреннее сопротивление.
- **I-V кривые для разной ширины** (38.25 Гц): Voc, Isc, Rint как функции ширины (7-4, 7-5).
- **Squirrel cage dynamos** (гл. 7.4.1): многократные статоры — масштабирование тока.
- **Drum dynamo** (гл. 7.4.2): построен в Robinson.
- До гл. 5 все улучшения dynamo были эмпирическими; теперь — на основе механизма.

## Глава 8. Полупроводниковый dynamo (предсказание)
- Механизм dynamo достаточно силён, чтобы предсказать **полупроводниковый dynamo** (аналог HTS, но с полупроводником): Zener-диоды (нелинейная проводимость, обратно-параллельно).
- A-formulation модель; заряд за цикл vs частота (рис. 8-2).
- **Не проверен экспериментально** (предсказание).

## Глава 9. Выводы и будущее
- Механизм: нелинейная резистивность — ключ.
- NI coils + HTS dynamo — ключевые технологии для высокопольных HTS-магнитов.
- Развитие анизотропного моделирования NI.
- Высокочастотное поведение и тепловые эффекты (9.5.3).

## Ключевые результаты (сводка)
- **Механизм DC**: нелинейная E-J — ЕДИНСТВЕННОЕ необходимое условие.
- **n = 1 → Vdc = 0** (опровержение Giaever).
- **Jc(B,θ)** усиливает Vdc.
- **Пик ΔV −500 мкВ**; ρJz > 400 мкВ/см.
- **Ширина магнита < половины ленты** → Vdc ≠ 0.
- **NI катушки**: анизотропная резистивность, turn-to-turn токи, устойчивость.
- **Rint ↓ с шириной статора**.
- **Полупроводниковый dynamo** (Zener) — предсказан.

## Ограничения и замечания авторов
- n = 1 → Vdc = 0 (линейная резистивность недостаточна).
- Jc(B,θ) — значимое усиление (современные REBCO — меньше эффект).
- Полупроводниковый dynamo — предсказан, не проверен.
- LTS dynamo — расширение через n(B,θ) → 1 (нормальное пятно).
- 2D остаётся быстрейшим методом (3D — точнее, но медленнее).
