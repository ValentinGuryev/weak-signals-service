## Релевантность проекту: 2/5
**Смежная технология — НЕ flux pump.** Портативный MRI-магнит 0.5 Тл на REBCO, охлаждаемый твёрдым азотом (SN2) в диапазоне 30–36 К, с отцепляемым cryocirculator'ом; quasi-persistent mode через сверхнизкоомные паяные соединения (0.55 нОм на 1 м спая) + persistent-current switch (PCS) для зарядки. Ценность для проекта: (1) пример системы, которая **обходится без flux pump** — зарядка через PCS и токовводы, удержание поля за счёт SN2-тепловой массы; (2) паяные соединения 0.3–0.55 нОм — данные для сравнения с flux pump (потери на спаях); (3) контекст PCS как альтернативы. Раздел 12 (competing technologies) LIT_REVIEW.

## Суть работы
Концептуальный дизайн портативного all-REBCO MRI-магнита для головы: 0.5 Тл, RT-бор 560 мм, однородность <1 ppm (Vrms) в 26-cm DSV, работа в 30–36 К без LHe и без постоянно подключённого криокулера. Ключевые идеи: (1) quasi-persistent mode с паяными соединениями длинной длины (увеличение площади контакта) — измерено 0.55 нОм для 1-м спая в LN2, ожидаемо ~0.3 нОм для 2-м; (2) SN2 (твёрдый азот) как тепловая масса — 84 л LN2, при 30 К ~70 л SN2, энтальпийная плотность 1.4 Дж/см³ (30–35.6 К) + скрытая теплота 8.3 Дж/см³ при 35.6 К → >18 ч работы при ~10 Вт теплопритока; (3) отцепляемый cryocirculator (Pulse Tube) — только для зарядки и заморозки азота; (4) no-insulation (NI) намотка Coils 1–3 (самозащита), layer-winding для минимизации соединений.

## Ключевые результаты
- Магнит: 6 катушек, REBCO 3 мм × 65 мкм (модель 3.5 × 0.1 мм), I_op = 102 А, пиковое поле в катушках 2 Тл, I_c при 40 К/2 Тл > I_op; hoop stress max 28 МПа, axial force max 26 кН (Coil 3) — некритичны.
- Соединения: 20 бобин (2/2/6 на Coils 1/2/3) → 21 паяное соединение; измеренный R_joint = 0.55 нОм (1-м спай, LN2, flux-trapped метод); с 2-м спаями ~0.3 нОм; полное R_joint ~6 нОм (21 × 0.3 нОм); L = 10.4 Гн → τ = L/R = 1.7×10⁹ с → скорость спада поля ~1 мкТл/ч (44 Гц/ч при 0.5 Тл = 9.5 ppm/ч).
- Сверхпроводящие соединения (heat treatment) [13–17] — не повторяемы, не ремонтопригодны; пайка — проще и повторяемее.
- PCS (persistent-current switch): ≥3 Ом в открытом состоянии при 100 К, 20-м лента, неиндуктивная намотка, нагрев ≤1 Вт; нужен для зарядки/разрядки закрытого контура.
- SN2: 84 л LN2 → ~70 л SN2 при 30 К; работа >18 ч при 10 Вт (температурная экскурсия 30→36 К); shield охлаждается до ~50 К.
- Зарядка: temperature-controlled charging sequence [19] против screening-current induced field (SCF); B0 shim coil компенсирует дрейф до 200 Гц/ч (0.1 ppm/ч требование MRI).
- Дрейф поля: 1 мкТл/ч (44 Гц/ч) — приемлемо для B0-компенсации; с 5-м спаями и отбором лент <1.5 нОм → <11 Гц/ч.
- Возможность: «detachable current leads or a flux pump [26] can be used» — flux pump упомянут как опция зарядки.

## Теоретическая модель
- LR-цепь свободного спада: τ = L/R_joint (10.4 Гн / 6 нОм = 1.7×10⁹ с).
- Тепловая модель SN2: энтальпийная плотность 1.4 Дж/см³ (30–35.6 К) + скрытая теплота фазового перехода 8.3 Дж/см³ (35.6 К) → время работы = теплоёмкость/теплоприток.
- SCF-эффект REBCO: снижается temperature-controlled charging sequence; остаточные ошибки — ферромагнитные и RT шимы.

## Конструкция (смежная, не flux pump)
Портативный MRI: all-REBCO NI-магнит + SN2-тепловая масса + отцепляемый Pulse Tube cryocirculator; зарядка через PCS (3 Ом при 100 К) + токовводы (или опционально flux pump [26]); 21 паяное соединение; B0 shim coil для компенсации дрейфа; MLI, radiation shield (50 К).

## Ограничения и замечания авторов
- Магнит без активного/пассивного экранирования (fringe field — проблема для POC и транспортировки; оптимизация — следующий шаг).
- RFI в портативной среде — вызов; bucking coils / физический экран.
- Gradient coil для головы — не off-the-shelf, требует оптимизации под портативность.
- Сверхпроводящие REBCO-соединения ненадёжны → выбран путь паяных длинных спаев + B0-компенсация.
- Flux pump упомянут как альтернатива токовводам (для зарядки) — но не используется.

## Связь с нашим проектом
- Раздел 12 (competing technologies): пример MRI-системы без flux pump — удержание поля за счёт сверхнизкоомных спаев + SN2-тепловой массы; зарядка через PCS.
- Раздел 2.5 (потери): паяные соединения 0.3–0.55 нОм — порядок величин для сравнения с «потерями на спаях», которые flux pump должен компенсировать.
- Раздел 2.4 (космос/портативность): SN2-охлаждение 30–36 К, отцепляемый криокулер — смежная криогенная архитектура.
- Контекст: почему flux pump (Hēki и др.) снижает теплоприток токовводов, а здесь — обходятся PCS + пайкой.
