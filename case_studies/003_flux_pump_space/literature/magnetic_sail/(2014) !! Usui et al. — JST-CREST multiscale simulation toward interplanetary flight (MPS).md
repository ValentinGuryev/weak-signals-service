  (Project Review: Multi-Scale Plasma Particle Simulation toward the Development of Interplanetary

- **Язык:** японский → максимально полная выжимка.
- **Релевантность:** 4/5 (!!). MPS + JAXA (Funaki = изобретатель патента JP5417643B2!) + упоминание

## Суть (проект-ревью)
Итоговый отчёт **JST/CREST-проекта** (2007-2012, ~5.5 лет) «Мультимасштабное моделирование для
межпланетной навигации»: разработка AMR-PIC кода **PARMER** для моделирования MPS (магнито-плазменного
паруса). Соавторы — ключевые фигуры JAXA (Funaki, Yamakawa — авторы концепции MPS).

## Ключевые технические результаты
1. **Тяга MPS/магнитного паруса vs MHD-теория:** впервые получены **количественные кинетические
   оценки** тяги для малых диполей (ионный-электронный масштабы). Вывод: **кинетические эффекты
   (конечный ларморовский радиус) СНИЖАЮТ тягу** относительно MHD-предсказаний. Тяга ~пропорциональна
   магнитному моменту диполя; при малых моментах (10¹⁵-10¹⁶ А·м²?) — **тяга < 1 мН** (не достигает
   целевых мН-N).
2. **Сверхпроводящая катушка (超伝導コイル) для диполя:** прямо указано — «искусственное дипольное
   поле, создаваемое **бортовой сверхпроводящей катушкой** спутника». Чтобы получить достаточную тягу,
   нужно **увеличивать ток катушки** (магнитный момент), но «увеличить ток только катушки трудно»
   → предложена **плазменная струя для раздувания поля** (плазменный ток создаёт доп. магнитный момент).
3. **Плазменное раздувание поля (MPS):** тепловая плазма с борта захватывается дипольным полем,
   дрейфы (∇B, кривизна) создают **кольцевой ток** → доп. магнитный момент. Модель OCP (One-Component
   Plasma) показала: **до 40× увеличение магнитного момента** при оптим. параметрах (β~20).
   → тяга тоже может вырасти ~40×.
4. **Эксперимент в симуляции:** плазменная струя расширяет магнитосферу с ~900 м до ~2700 м (~3×),
   тяга растёт ~5× (для электронного масштаба диполя).
5. **Код PARMER:** AMR-PIC, распараллеливание, DDD (динамическое распределение данных) — для
   больших прогонов на «К»-компьютере.

## Значение для кейса 003 (КЛЮЧЕВОЕ)
Это прямой документ японской программы, связывающей:
- **космический парус (MPS)** — движитель для межпланетных перелётов;
- **сверхпроводящую катушку** — источник дипольного магнитного поля (сотни км масштаба!);
- **JAXA / Funaki** — тот же человек, что в патенте JP5417643B2 (Toshiba+JAXA, космический
  HTS-магнит с термоэлектрической накачкой, заявка 2009).

**Вывод:** магнитный парус — реальный драйвер спроса на БОЛЬШОЙ космический СП-магнит (ток катушки
→ магнитный момент → тяга). Для такого магнита нужна накачка тока; flux pump — естественный кандидат
(убирает токовводы и теплоприток). Связка «магнитный парус + flux pump» = космический HTS-магнит
с бестоковводной накачкой для межпланетного движителя. Это ответвление, достойное отдельного сигнала.

## Ограничения
- Проект 2007-2012 — по сути симуляции; реального лётного эксперимента MPS не было (на 2014).
- Тяга в симуляциях < 1 мН без плазменного раздувания — технология ещё в R&D.
