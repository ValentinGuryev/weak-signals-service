## Суть
Предложен **малый космический аппарат (МКА, 53 кг)** для эксперимента по созданию сильного магнитного
поля с помощью **ВТСП-ленты 2-го поколения** и разворачиваемых конструкций из **материалов с памятью
формы (NiTi)**. Цель: проверить взаимодействие поля СП-катушки с плазмой солнечного ветра и измерить
силовое воздействие (тягу) на МКА. Статья дискуссионная (концепт).

## КЛЮЧЕВАЯ СВЯЗКА С FLUX PUMP (для кейса 003!)
Цитата: «Проблема создания больших токов в катушке решается применением в составе МКА
**ВТСП генератора (flux pump)** [16]. Он представляет собой ротор с **NdFeB-магнитами**, вращающимися
относительно статора, с размещёнными на нём ВТСП-лентами. ВТСП-генератор позволяет создавать в ВТСП
катушке токи не более критических... Привод через магнитную муфту от бесконтактного двигателя ~4 Вт».

**Ссылка [16] = Hoffmann C., Walsh R., Karrer-Mueller E., Pooke D. «Design parameters for an HTS flux
pump», Physics Procedia 36 (2012) 1324-1329** — это **новозеландская школа (Pooke = HTS-110, Robinson)**,
та же, что создала flux pump для Hēki! Российский проект прямо опирается на NZ-технологию flux pump.

**Это ПРЯМОЕ пересечение: магнитный парус (РФ) + flux pump (Новая Зеландия/Robinson)** — единственное
найденное в мировой литературе/патентах/грантах!

## Параметры МКА (полный разбор)
| Параметр | Значение |
|---|---|
| Масса МКА | **53 кг** |
| ВТСП-катушка | 41 кг, разворачиваемая |
| Радиус катушки (рабочий) | **7500 мм** (в сложенном — Ø540 мм, H 850 мм) |
| Витки / ток | 80 витков / **500 А** |
| **Магнитный момент** | **7.07×10⁶ А·м²** |
| Flux pump | 0.2 кг, NdFeB-ротор, привод ~4 Вт через магнитную муфту |
| ВТСП-лента | **ЗАО «СуперОкс»** (РФ): Ic 300-500 А при -196°С, ширина 12 мм, до 350 м |
| Охлаждение | Пассивное: 4 полиимидных экрана (металлизир. 10-15 мкм) → ~-215°С у катушки |
| Тяга магнитного паруса FМП | **5.64×10⁻⁶ Н** (при V=500 км/с, n=7 см⁻³, M=7.07×10⁶ А·м², α=45°) |
| Тяга магнитоплазменного | 6.77×10⁻⁵ Н (плазменная инжекция ×12) |
| Эффект на орбиту | Δ большой полуоси: ~29 000 км/год (магн.) и ~347 000 км/год (магнито-плазм.) |
| Орбита | Гелиоцентрическая, 1 а.е. (вне магнитосферы Земли) |

## Технические решения
- **Разворот катушки:** элементы из NiTi (нитинол), активация нагревом от Солнца или резистивно;
- **Теплоразвязка:** катушка удалена на 600 мм от платформы углепластиковой изогридной конструкцией
  (λ ≤ 0.15 Вт/(м·К)); магнитная муфта исключает кондуктивный поток через вал;
- **Расчёт:** конечно-элементная тепловая модель Siemens NX Thermal; аналог — экраны JWST и «Миллиметрон»;
- Ссылки на мировые проекты: LightSail2, NanoSail-D2, IKAROS (солнечные паруса — запущены),
  наземные эксперименты (увеличение тяги плазменной инжекцией в 12 раз).

## Значение для кейса 003
1. **Прямая связка «парус + flux pump» найдена и документирована** (НПО Лавочкина/МАИ используют
   NZ-flux pump Hoffmann/Pooke для накачки 500 А в СП-катушке паруса);
2. Российская космическая промышленность (НПО Лавочкина — производитель «Спектр-РГ», межпланетных
   станций) + МАИ — реальный интерес к HTS+flux pump в космосе;
3. Используется **российская ВТСП-лента СуперОкс** (та же, что в Hēki! — Hēki магнит на SuperOx REBCO);
4. Flux pump 0.2 кг на 53-кг МКА — миниатюрный, как в Hēki (компактный conduction-cooled);
5. Статья 2021 — концепт, НЕ запущенный аппарат (нет данных о реализации).
