# Магнитный парус (Magnetic Sail / Magneto-Plasma Sail) — ответвление кейса 003

> **Зачем это здесь:** магнитный парус — космический движитель, которому нужен **большой бортовой
> сверхпроводящий магнит** (диполь → магнитный момент → перехват солнечного ветра → тяга).
> Питание такого магнита в космосе БЕЗ токовводов — задача **flux pump**. Связка «парус + flux pump»
> потенциально очень сильна: тот же JAXA (Funaki), что патентовал космический HTS-магнит с
> термонакачкой (JP5417643B2), развивает и MPS.

## Ключевые выводы (на 2026-09-04, обновлено)
1. **Япония (JAXA + JST/CREST + 11 KAKEN-грантов)** — главный игрок MPS; Funaki (JAXA) = PI 4 грантов
   И автор патента космического HTS-магнита (JP5417643B2) → грантовый мост «парус→СП-магнит»;
2. **⭐ ПРЯМАЯ СВЯЗКА «парус + flux pump» НАЙДЕНА**: российский проект **НПО Лавочкина/МАИ
   (Комбаев 2021)** использует **NZ-flux pump Hoffmann/Pooke** для накачки 500 А в ВТСП-катушке
   (М = 7×10⁶ А·м²); ВТСП-лента — СуперОкс (общая с Hēki!);
3. СП-катушка паруса спроектирована (Nagasaki 2013: YBCO, 2×10⁶ А-витков, грант ISAS/JAXA);
4. **Россия**: НПО Лавочкина (Калуга+Химки) + МАИ — промышленный проект, грант РНФ не подтверждён;
5. **США/Европа**: 0 грантов по MPS (NASA Magsail/M2P2 1990-2005 — без HTS, затухли; ЕС — только solar sail);
6. **Китай**: публикации NUAA/Beihang/PLA (2022-23), NSFC не проверен.
