## 2. США — NSF: 0; NASA: ранние концепты (1990-2005), БЕЗ HTS, затухли

### NSF: 0 прямых грантов
- По "magnetic sail", "magneto-plasma sail", "solar sail": 0 релевантных (API матчит широко);
- Локальный дамп NSF — тоже 0. **Вывод:** NSF не финансирует магнитный парус.

### NASA — 3 волны концептов, все без HTS/flux pump
| Год | Концепт | Авторы/Орг. | Детали | Связь с СП/flux pump |
|---|---|---|---|---|
| **1990** | **Magsail** — «Use of magnetic sails for advanced exploration missions» | Andrews (Boeing), Zubrin (Martin Marietta) | СП-петля км-масштаба перехватывает солнечный ветер/межзвёздную среду; NTRS 19910012840 | 🔶 СП-петля концептуально (Zubrin); НЕТ flux pump |
| **2000** | **M2P2** — Mini-Magnetospheric Plasma Propulsion | Winglee (UW), Slough, Ziemba + **NASA Marshall** (Gallagher) | Helicon+диполь → пузырь-магнитосфера; **тяга ~1 N при ~1 kW**, 0.25-0.5 кг/день; **193+133 цит.** | ❌ обычная катушка + helicon |
| **2001-03** | M2P2 prototype | Winglee et al. (UW) | Лаб. прототип в вакуумной камере 5×6 ft; плотность 10¹²-10¹³ см⁻³ | ❌ |
| **2004** | M2P2 + радиационная защита | Winglee | Развитие: тяга + shielding | ❌ |
| **2005** | **Plasma Magnet** | Slough (UW/MSNW) | Развитие M2P2 | ❌ |

**NTRS по "magnetic sail": всего 3 записи** (1991 Exotic concepts, Interstellar beam, Magsail 1991).
**После 2005 — НЕТ современной NASA-активности** (ушли в solar sail: NEA Scout, ACS3 — реальные миссии).

**Вывод по США:** Magsail (1990, Zubrin) концептуально предлагал СП-петлю — и это ЕДИНСТВЕННОЕ
касание СП в NASA-ветке. M2P2/Plasma Magnet (2000-05) — helicon без СП. Все затухли. США не довели
идею до СП-катушки (в отличие от Японии) и не связывали с flux pump.

## 4. Россия — НПО Лавочкина + МАИ: ПРЯМАЯ СВЯЗКА «парус + flux pump» (2021)

### Проект (полный разбор)
**Комбаев Т.Ш.** (филиал АО «НПО Лавочкина», Калуга) + **Артёмов М.Е., Сысоев В.К.** (АО «НПО Лавочкина»,
Химки) + **Дежин Д.С.** (МАИ, НИУ) — «Малый космический аппарат с магнитным парусом на ВТСП»,
Космическая техника и технологии №2(33)/2021, с.130-140. Посвящена 75-летию РКК «Энергия».

**НПО Лавочкина** — российское космическое предприятие (АМС «Спектр-РГ», «Луна» и др.), филиал в Калуге.
**МАИ** — Московский авиационный институт. Это **проект космической промышленности**, не академический грант
(грант РНФ не подтверждён; вероятно, внутреннее НИОКР/инициативное).

### ⭐ КЛЮЧЕВОЕ: flux pump в проекте (единственная найденная прямая связка!)
Цитата из статьи: «Проблема создания больших токов в катушке решается применением в составе МКА
**ВТСП генератора (flux pump)** [16]. Он представляет собой ротор с **NdFeB-магнитами**, вращающимися
относительно статора, с размещёнными на нём ВТСП-лентами... Привод через магнитную муфту от
бесконтактного двигателя ~4 Вт».

**Ссылка [16] = Hoffmann, Walsh, Karrer-Mueller, Pooke — «Design parameters for an HTS flux pump»,
Physics Procedia 36 (2012) 1324-1329** — новозеландская школа (Pooke = HTS-110 / Robinson Research),
создатель flux pump для миссии Hēki!

**ИТОГ: российский проект магнитного паруса прямо использует новозеландский flux pump (Robinson/HTS-110)
для накачки СП-катушки. Это ПРЯМОЕ пересечение «магнитный парус ∩ flux pump» в мировой практике.**

### Параметры МКА
| Параметр | Значение |
|---|---|
| Масса МКА | 53 кг |
| ВТСП-катушка | 41 кг, разворачиваемая (радиус 7500 мм) |
| Витки / ток | 80 / **500 А** |
| Магнитный момент | **7.07×10⁶ А·м²** |
| Flux pump | 0.2 кг, NdFeB-ротор, ~4 Вт |
| ВТСП-лента | **ЗАО «СуперОкс»** (РФ): Ic 300-500 А, 12 мм, до 350 м |
| Охлаждение | Пассивное (4 экрана) → ~-215°С |
| Тяга (магн.) | 5.64×10⁻⁶ Н; (магнито-плазм.) 6.77×10⁻⁵ Н |
| Орбита | Гелиоцентрическая 1 а.е. |

**Связь с кейсом 003:** СуперОкс — та же российская ВТСП-лента, что в магните Hēki (SuperOx REBCO)!
Flux pump Hoffmann/Pooke — та же технология, что в Hēki. Проект — концепт 2021, запуска нет.

## 6. Итог: грантовый сигнал связки «парус + flux pump» — ОБНОВЛЕНО

**Прорыв (2026-09-04):** связка «магнитный парус + flux pump» больше НЕ латентная —
**найден прямой документ**: проект НПО Лавочкина/МАИ (2021) использует NZ-flux pump (Hoffmann/Pooke)
для накачки 500 А в ВТСП-катушке паруса.

**Полная картина по странам:**
1. **Япония** — системное финансирование MPS (11 KAKEN + JST/CREST + ISAS/JAXA), Funaki (JAXA) — PI
   4 грантов и изобретатель патента космического HTS-магнита (JP5417643B2). СП-катушка доведена до
   дизайна (Nagasaki 2013: YBCO, 2×10⁶ А-витков). Flux pump в японских работах НЕ упоминается;
2. **Россия** — НПО Лавочкина + МАИ (2021): МКА-концепт с ВТСП-парусом И flux pump (NZ Hoffmann) —
   **единственная прямая связка**; плюс ВТСП-лента СуперОкс (общая с Hēki);
3. **США** — NASA: Magsail (1990, СП-петля концептуально), M2P2/Plasma Magnet (2000-05, helicon без СП) —
   затухли, в solar sail ушли;
4. **Европа** — 0 по MPS (только solar sail);
5. **Китай** — наука активна (NUAA/Beihang/PLA), NSFC не проверен.

**Для S1 (пересечение баз):** теперь схема богаче:
- Япония: патенты (JP5417643B2) ∩ гранты (KAKEN Funaki) ∩ статьи (Nagasaki/Minami) ∩ конференции (Usui);
- **РФ: статья (Комбаев) ∩ flux pump-технология NZ (Hoffmann/Pooke) ∩ ВТСП-лента (СуперОкс, общая с Hēki)** —
  пересечение «парус+flux pump» в одной точке;
- Flux pump (Hēki/NZ) оказывается востребован для магнитного паруса (РФ) — применение-драйвер №2 после Hēki.
