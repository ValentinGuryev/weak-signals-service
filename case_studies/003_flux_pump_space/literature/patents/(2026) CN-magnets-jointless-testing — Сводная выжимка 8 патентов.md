## По-патентно (полный разбор)

### 1. CN112309670B — Магнитная катушка с интегрированным стыком (HTS→LTS) — Bruker
- HTS-лента (10) спирально намотана в главной полости (8) катушкодержателя (2);
- **Первый (21) и второй (22) стыки** от HTS-ленты к **сверхпроводящим продолжениям (31, 32)** — т.е. **HTS→LTS переход**;
- В области стыка многовитковая HTS-лента и продолжение **перекрываются**;
- Стыки выходят **аксиально из главной полости**; радиальная зона (RBS) ≤ +20% внешнего радиуса обмотки;
- Результат: **компактная конструкция, высокая токонесущая способность** (для гибридных HTS-LTS магнитов — NMR).
- Заявитель: **Brook(e) Switzerland AG** (Bruker) — NMR-магниты.

### 2. CN117727530A — HTS-магнит с низкоомными стыками (разъёмные двойные панкейки)
- Магнит: двойные панкейк-катушки + ленты + **два типа припоев для стыков** + бандаж;
- **Вакуумно-импрегнационная пайка (VPI):**
  - **Первый припой (высокотемпературный)** — стыки ВНУТРИ двойного панкейка;
  - **Второй припой (низкотемпературный)** — стыки МЕЖДУ соседними двойными панкейками;
- Разные температуры плавления → **каждый двойной панкейк разъёмный/съёмный**;
- VPI исключает **поры (газовые пузыри)** в стыках;
- Результат: низкоомные, ремонтопригодные стыки для HTS-магнитов.

### 3. CN115064336B — БЕССТЫКОВЫЙ (jointless) HTS-магнит
- Магнит без единого стыка: **два двойных панкейка** (первый и второй) на кольцевых каркасах;
- **Метод бесстыковой намотки:** лента разделяется на «верхнюю/нижнюю» половинки, левый конец
  проходит через средний зазор и возвращается → две половинки наматываются на два каркаса;
- Катушки соединяются **параллельно** при возбуждении;
- Результат: **магнит БЕЗ сверхпроводящих стыков** → стабильная работа (крип потока меньше).
- **Прямая альтернатива соединениям и flux pump** (для замкнутого контура)!

### 4. CN114388259B — Бесстыковая намоточная машина (jointless multi-pancake)
- Два намоточных устройства (симметричных, друг напротив друга);
- **Датчик натяжения** + контроллер — контроль натяжения ленты при намотке;
- Контроллер регулирует **относительное положение** устройств;
- Результат: **автоматическая бесстыковая намотка** многослойных катушек.

### 5. CN116072372B — HTS-магнитная система для термояда (15 Тл)
- Термоядерная магнитная система: **тороидальное поле (TF)**, **центральный соленоид (CS)**, **полоидальное поле (PF)**;
- **TF полностью из HTS CICC-проводников** → поле **>15 Тл** для удержания плазмы;
- **CS — гибрид LTS+HTS CICC** (создание плазменного тока);
- HTS CICC = **пучки REBCO-проводов (собраны в кабель-в-оболочке)**;
- Результат: компактный термояд, выше мощность (заявитель: CAS Hefei — китайский термояд!).
- **Важно:** китайский термояд использует REBCO CICC — потребитель лент.

### 6. CN116313370A — HTS-магнит с замкнутым контуром (без стыков, без токовводов!)
- Магнит из **чередующихся сверхпроводящих и изолирующих колец** (все HTS);
- **Возбуждение в поле (field-cooled)** с помощью внешнего «бит-магнита» (высокое поле);
- Результат: **БЕЗ пайки, БЕЗ источника питания, БЕЗ токовводов** — замкнутый контур;
- Компактный, разборный, стабильный; **высокое поле** (для NMR и больших магнитов).
- **Это НЕ flux pump, а field-cooling** — ещё одна технология зарядки без токовводов (конкурент!).

### 7. CN210041676U — Без-изоляционный (NI) HTS-магнит с flux pump'ами
- Магнит: вакуумный корпус + **несколько катушечных групп**;
- Каждая группа: мотор, **переключатели (1-й, 2-й)**, тепловой якорь, криокулер, **холодный резервуар**,
  **несколько flux pump'ов**, **последовательные NI-катушки**, **стабилизатор тока (persistent switch)**, холодный экран;
- Вакуум + экран → меньше тепловое излучение; NI-катушки → стабильность/устойчивость;
- **Гибридное охлаждение** (экран + катушки + среда);
- **Важно:** использует flux pump для зарядки NI-катушек — практическое применение flux pump!

### 8. CN111366879B / CN209821330U — Тестовая установка для стыков лент/кабелей (Southwestern Inst Physics)
- **Дьюар**, источник давления, электроды, тестовый стол;
- Среда: **криогенная**, **многоленточная параллель**, **разные площади/давления**;
- Многоконтурная конструкция — универсальность; параллельное тестирование образцов;
- **Сменный прижимной пуансон** — равномерное давление без повреждения лент;
- **Защита от квенча** (шунт при квенче — ток уходит, образец не сгорает);
- Заявитель: **Southwestern Institute of Physics** (SWIP — термоядерный институт Китая!) —
  тестирование стыков для термояда.

## Обобщение для кейса 003

1. **Три конкурирующие технологии «без токовводов»:** (а) flux pump, (б) бесстыковые/jointless
   магниты (CN115064336, CN114388259), (в) **field-cooling** (CN116313370) — все патентованы в Китае;
2. **Bruker (CH) патентует HTS-LTS стыки** для NMR (CN112309670) — западный игрок в Китае;
3. **Китайский термояд (CAS Hefei, SWIP)** — REBCO CICC + тестирование стыков — потребитель лент;
4. **Flux pump применяется в NI-магнитах** (CN210041676) — практическое внедрение (важно для кейса!);
5. **CN117727530 (разъёмные панкейки)** — ремонтопригодность стыков — инженерный прогресс.
