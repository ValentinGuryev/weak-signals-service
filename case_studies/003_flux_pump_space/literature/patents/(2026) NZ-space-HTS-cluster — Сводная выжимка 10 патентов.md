## Кластер 1: Zenno Astronautics (Новая Зеландия) — 5 патентов

Спин-офф Robinson Research Institute (создатели Hēki). Спутниковые системы с
**сверхпроводящими электромагнитами** (HTS) для управления ориентацией и магнитосферы.

### 1. US12354791B2 — Satellite system (грант, 2025)
- Патентообладатель: **Zenno Astronautics Limited**, Auckland (NZ); изобретатель Maksim Arshavskiy;
- Приоритет: 25.02.2019 (NZ 751022); PCT/IB2020/051579 → WO2020/174378;
- **Семейство EP3931850B1** (уже в базе 003). CPC: H01F6/008, H01F6/04, B64G1/10, B64G1/283.
- Суть: **система охлаждения сверхпроводящего электромагнита** (740) для спутника (700):
  криоохладитель (735) теплосвязан с охлаждающим элементом; охлаждение электромагнита
  **только теплопроводностью** (conduction-cooled) без жидкого хладагента;
  + система управления ориентацией спутника этим электромагнитом.

### 2. US12139277 — Satellite system (грант, 2024)
- Zenno; изобретатели Jayakody, Lavey, Arshavskiy; приоритет 2020 (WO2020170003);
- CPC: B64G1/32, H01F6/06, H01F6/04.
- Суть: спутниковая система с **несколькими HTS-электромагнитами** для создания магнитного
  момента/управления ориентацией; ссылки на трёхосные Helmholtz-катушки для аэрокосмоса.

### 3. US20220084729A1 — Satellite system (публикация)
- Та же заявка, что US12354791B2 (PCT-публикация, приоритет 2019);
- Полный abstract: система охлаждения СП-электромагнита для спутника + управление положением.

### 4. HK40066832B — 衛星系統 (Гонконг, грант)
- HK-регистрация семейства EP3931850B1 (Zenno); приоритет 25.02.2019 NZ.

### 5. HK40110731A — 改良的衛星系統 (Гонконг, заявка)
- Улучшенная спутниковая система: **три непараллельные катушки** (главный + 2 вторичных
  электромагнита) из сверхпроводника, криоохлаждение ниже Tc, управление ориентацией по осям.

**Вывод по Zenno:** 5 публикаций одного семейства (NZ-приоритет 2019-2020) — коммерциализация
технологии HTS-магнитов Hēki для спутникового рынка (магнитная система без токовводов,
conduction-cooled). Первый «продуктовый» патентный кластер вокруг миссии Hēki.

## Кластер 2: NeutronStar Systems (Германия, Кёльн + Univ Stuttgart) — 3 патента

Стартап по HTS-магнитам для **магнитоплазмодинамических (MPD) двигателей** космических аппаратов.

### 6. GB2600493A — Propulsion unit for spacecraft (2022)
- Заявитель: NeutronStar Systems UG; соавторы из Univ Stuttgart (Г. Хердрих — MPD-эксперт);
- Приоритет: DE 10 2020 128 964 (03.11.2020);
- Суть: **плазменный MPD-движитель с HTS-катушками (120,125)** вокруг коаксиальных
  катод/анод; сверхпроводящие катушки создают сильное магнитное поле для ускорения
  плазменной струи; криоохлаждение катушек.
- **Связь с кейсом 003:** HTS-магнит + космос (движитель), та же технологическая база,
  что Hēki, но для пропульсии, а не для управления ориентацией.

### 7. GB2606768A — Thermal management system for spacecraft thruster (2022)
- NeutronStar Systems; приоритет DE 10 2021 113 185.5 (20.05.2021);
- Суть: **термомост между HTS-магнитом (120) и плазменным разрядом (15)** MPD-движителя:
  тепловой барьер (40,60) у плазмы + криостатная изоляция (80) у СП-магнита +
  многослойная изоляция (70) между ними + радиационный зазор (50).
- Решает проблему: MPD-движитель горячий (>1000°C у плазмы), HTS-магнит требует ~30-77 K —
  нужен тепловой экран между ними.

### 8. US20230407851A1 / WO2022243543A1 — Propulsion unit / Thermal management (2022-23)
- US-публикация PCT/EP2021/080513 (NeutronStar + Univ Stuttgart) — тот же MPD+HTS-движитель;
- WO2022243543A1 — PCT теплового менеджмента (приоритет DE 2021).

**Вывод по NeutronStar:** немецкий стартап применяет HTS-магниты в космической пропульсии
(MPD/плазма) — второй независимый космический HTS-патентный кластер после NZ. Показывает
**диффузию HTS+космос за пределы одной миссии** (Hēki) — сигнал зрелости тренда.

## Кластер 4: JAXA (Япония) — 1 патент (не-англ/не-рус, полный разбор)

### 10. JP5417643B2 — 宇宙用超電導磁石装置 (Космическое сверхпроводящее магнитное устройство, рег. 2014)
- **Заявители: Toshiba Corp + JAXA** (изобретатели: 高橋政彦, 田崎賢司, 戸坂泰造, 井岡茂, 溝田樹容子 — Toshiba;
  船木一幸 (Funaki Kazuyuki, JAXA/ISAS — специалист по магнитным парусам!), 杉田寛之 — JAXA);
- **Заявка: JP2009-207344, 2009-09-08**; публикация заявки JP2011058398A (2011-03-24); рег. патента 2014-02-19;
- Цитирует: Funaki & Yamakawa, «Магнитный плазменный парус» (J. Plasma Fusion Res. 83(3), 2007) — контекст: JAXA нужен космический СП-магнит для магнитного паруса/плазменного движителя.
- **Формула (полный разбор):**
  1. Устройство: **сверхпроводящая катушка** + возбудитель (励磁装置) + **токовводы**
     (電流リード) + **опорная конструкция** к шине космического аппарата (宇宙機のバス部) +
     **многоступенчатые тепловые экраны** с радиационным охлаждением (放射冷却面を有する複数段の熱シールド板)
     + **солнечный экран** (サンシールド) на шине. Тепловые экраны — цилиндрические/многоугольные,
     ось совпадает с осью катушки.
  2. Катушка — **высокотемпературная сверхпроводящая** (HTS-провод).
  3. HTS-провод — **лента на металлической подложке** (IBAD-тип: подложка+промежуточный слой+оксидный СП-слой).
  4. **Персистентный токовый ключ (永久電流スイッチ)** параллельно катушке.
  5. Тепловые экраны — 4-6 ступеней.
  6. Катушка окружена тепловыми экранами.
  7. Ступени экранов уменьшают периметр по мере удаления от солнечного экрана.
  8. **Магнитный экранирующий СП-экран** (磁気シールド用超電導コイル) защищает шину от поля катушки.
  9-10. Экранирующая катушка — на тех же экранах, последовательно с основной.
  11. Возбудитель содержит **термоэлектрический элемент** (熱電素子) на токовводах.
  12. Термоэлемент: горячая сторона — приёмная пластина, холодная — радиатор.
  13-16. Питание возбудителя от солнечных батарей + DC/DC; контроль тока возбуждения.
- **Суть:** космический HTS-магнит с пассивным радиационным охлаждением (многоступенчатые
  тепловые экраны), термоэлектрической накачкой через токовводы и персистентным ключом.
- **Значение:** JAXA патентует космические СП-магниты с **токовводами+термоэлектрикой** (не flux pump!),
  в отличие от NZ-подхода (flux pump / бестоковводная накачка). Два инженерных пути к одной цели.

## Общий вывод

Пачка 09-04 дала **патентное подтверждение космического HTS-тренда** (кейс 003):
- **NZ-кластер** (Zenno 5, Open Star 1, +Victoria Link WO2025042296A1 в другом файле) —
  прямое продолжение миссии Hēki: спутниковые HTS-электромагниты, conduction-cooled;
- **Victoria Link WO2025042296A1** — генератор магнитного поля для thrust assembly (Hēki-технология);
- **NeutronStar (DE)** — HTS-магниты для MPD-плазменных движителей (2-е независимое применение);
- **JAXA (JP)** — космический HTS-магнит с радиационным охлаждением и термоэлектрической накачкой
  (альтернативный инженерный путь, БЕЗ flux pump).

Это усиливает S1-сигнал кейса 003: не одна миссия (Hēki), а **формирующийся патентный ландшафт
«HTS-магниты для космоса»** (NZ + DE + JP) к 2022-2025.
