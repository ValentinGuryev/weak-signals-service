# Flux pump vs IBAD-MgO vs RCE-DR — три типа трендов

> **Статус:** . Сравнение для модели «перспективный vs неперспективный тренд».

---

## 1. Три типа технологических трендов

| Тип | Кейс | Пример | Механизм ценности |
|---|---|---|---|
| **Производственный (успех)** | 001 | IBAD-MgO | Скорость текстуры → дешевле ленты |
| **Производственный (провал)** | 002 | RCE-DR/TLAG | Скорость роста → дешевле ленты |
| **Прикладной (успех)** | 003 | Flux pump | Устранение токовводов → дешевле система |

## 2. Ключевые отличия (что определяет исход)

| Критерий | 001 (успех) | 002 (провал) | 003 (успех) |
|---|---|---|---|
| Снимает предел? | ✅ Скорость | ✅ Скорость | ✅ Теплоприток (10×) |
| Качество сохранено? | ✅ Да | ❌ Нет (пиннинг) | ✅ Да (500 мТл) |
| Драйвер | Корпорации | Гранты | **Лаборатория + миссия** |
| Патенты | ✅ Fujikura | ⚠️ не набраны | 🔶 не проверено |
| Гранты | ❌ Затихли | ✅ Продолжаются (11 лет) | ✅ Robinson (НЗ) |
| Масштаб (R2R) | ✅ км-ленты | ✅ RCE-DR / ❌ TLAG | ✅ Космос (миссия) |
| Системная ценность | Высокая | Средняя | **Высокая (убирает узкое место)** |

## 3. Гипотеза: системная ценность > скорость

**Flux pump показал: успех прикладного тренда определяется НЕ скоростью/дешевизной,
а устранением системного узкого места (токовводы) + явным заказчиком (миссия).**

| | 002 (провал) | 003 (успех) |
|---|---|---|
| Что снимают | Скорость производства | Теплоприток криостата |
| Кому нужно | Производителям лент | Космическим программам |
| Заказчик | Нет (гранты) | **Есть (миссия Hēki)** |
| Результат | Остался R&D | **Демонстрация в космосе** |

**Вывод:** для прикладных трендов решает не «скорость», а:
1. **Устранение системного узкого места** (не оптимизация, а снятие ограничения)
2. **Наличие конкретного заказчика** (миссия, программа) — не «рынок абстрактно»

## 4. Что это даёт модели

Три оси для оценки тренда:
1. **Производственный vs прикладной** (что оптимизируется)
2. **Скорость vs системная ценность** (механизм ценности)
3. **Гранты vs заказчик** (кто платит)

Комбинации:
- Производственный + скорость + корпорации = **успех** (001)
- Производственный + скорость + гранты = **провал** (002)
- Прикладной + системная ценность + заказчик = **успех** (003)

## 5. Проверка на будущих кейсах

- МОСVD (SuperPower/Dongfang): производственный, скорость+качество, корпорации → ожидаем ✅
- ISD (THEVA): производственный, скорость, ниша → ожидаем 🔶
- MgB₂ для МРТ: прикладной? → проверить
- ВТСП-кабели AC: прикладной, системная ценность → проверить
