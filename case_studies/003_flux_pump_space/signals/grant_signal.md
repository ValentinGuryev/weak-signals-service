### Ключевой вопрос для модели

**Соединения REBCO финансируются Японией (JST-Mirai) как госпрограмма — это:**
- (а) незрелость (нужны гранты, как TLAG)? или
- (б) госприоритет (стратегическая технология, как ядерные исследования)?

**Различие от TLAG:** у TLAG гранты = ERC (академия), у соединений = JST-Mirai
(национальная программа с целью persistent NMR). Это НЕ «гранты для R&D», а
«госпрограмма для конкретного продукта» (NMR 1.3 GHz). **Соединения ближе
к коммерциализации, чем TLAG.**

## 4. Вывод для кейса 003

1. **Flux pump**: мало грантов (НЗ MBIE), но есть конкретный заказчик (миссия Hēki) —
   «миссия > гранты» (аналогично 003 успешен по типу «прикладной + заказчик»)
2. **Соединения REBCO**: госпрограмма Японии (JST-Mirai) с целью persistent NMR —
   финансируются как стратегическая технология
3. **Контраст с TLAG (002)**: там гранты = академия (ERC), здесь — госпрограмма
   с продуктом → соединения более «зрелые» по драйверу
4. **Европа**: не финансирует ни flux pump, ни соединения напрямую (ниша)

**Грантовый сигнал различает:**
- TLAG: гранты ERC (академия) = незрелость → НЕ состоялся
- Flux pump: миссия + немного грантов = прикладной тренд → состоялся (космос)
- Соединения: госпрограмма с продуктом = стратегический тренд → прогресс (10⁻¹⁷ Ом)
