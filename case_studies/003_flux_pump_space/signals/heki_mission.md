> **Статус:** . Источники: SNF-статьи (Pollock 2026, Mallett 2026, Strickland 2026).
> Роль: ядро кейса 003 — доказательство зрелости flux pump.

| Параметр | Значение |
|---|---|
| Запуск | 14.09.2025 (Cygnus NG-23, Cape Canaveral) |

| Длительность | 6 месяцев работы без деградации |

## 2. Результаты

- **Зарядка:** Day 4: 100 мТл, Day 5: 300 мТл, Day 6: 500 мТл; удержание 3 дня
- **12 целей миссии — все выполнены**
- **Квенч (незапланированный!):** программный сброс → криокулер выключен → квенч.
  Квенч-защита (проводящий эпоксид) сработала — энергия рассеяна медленно, без повреждений.
  Повторная зарядка 0→500 мТл с точностью 1%. **Контролируемый квенч в космосе — цель 12!**
- **Теплоприток flux pump:** ~150 мВт при 18 А (500 мТл) vs 1476 мВт токовводов → **10%**
- **Свободный спад:** τ = 35 ч (L/R = 0.192 Гн / 1.55 мкОм + flux-flow)
- **Стабильность:** ±50 мкТл/час; 2 недели стабильного поля (4-18.02.2026)

## 3. Значение для кейса

1. **Flux pump работает в космосе** — первая демонстрация HTS-магнита с накачкой
2. **Теплоприток 10× меньше токовводов** — подтверждает S4 (снятие предела)
3. **Квенч-защита работает** — критично для космических систем
4. **6 месяцев без деградации** — ресурс подтверждён

## 4. Kōkako-iti (AF-MPDT)

- Копия магнита Hēki для AF-MPDT двигателя (электрический двигатель для космоса)
- ~300 мТл (ниже Hēki из-за отсутствия стального экрана)
- Первичка flux pump на HTS (снижение тепловой нагрузки)
- Показывает: flux pump + HTS-магнит = база для космических двигателей

## 5. Драйверы (почему сейчас)

- Дешевеющая REBCO-лента (кейс 001 — IBAD-MgO!)
- Дешевеющие космические криокулеры
- Потребность в электрических двигателях (AF-MPDT) для дальних миссий
