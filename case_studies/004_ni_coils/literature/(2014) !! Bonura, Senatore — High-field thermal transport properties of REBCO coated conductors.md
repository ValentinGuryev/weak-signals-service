---

## Суть работы

Первое исследование **продольной теплопроводности κ_L** REBCO-лент (6 производителей) в магнитных полях до 19 T (параллельно и перпендикулярно тепловому потоку). Цель — данные для thermal stability анализа HTS-магнитов.

## Ключевые результаты
1. **κ_L в нулевом поле** можно рассчитать с точностью ±15% из RRR стабилизатора и Cu/non-Cu отношения;
2. **Закон Видемана-Франца работает** для оценки κ в поле из электрических измерений (подтверждено);
3. В поле κ Cu падает (магнитосопротивление) — важно для высокопольных магнитов;
4. Данные — «primary ingredients» для quench-симуляций.

## Значимость для кейса 004
1. **κ_L >> κ_T** (см. трансверсальную статью): продольный перенос через Cu (k≈500-1700), поперечный — через подложку (k≈5);
2. **В поле κ падает** (до ~2× при 19 T для высокого RRR) — надо учитывать в дизайне;
3. Подтверждает: радиальный (поперечный) тепловой путь — узкое место; NI/MI, дающие радиальный путь через Cu-контакты, обходят именно это ограничение;
4. База данных для quench-моделей NI/MI катушек.
