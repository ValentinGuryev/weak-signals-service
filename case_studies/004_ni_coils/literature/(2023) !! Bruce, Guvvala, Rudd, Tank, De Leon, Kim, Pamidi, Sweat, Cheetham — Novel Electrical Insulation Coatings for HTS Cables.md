## Суть работы

Оценка двух коммерческих криогенных эпоксидов MASTERBOND (EP29-LPSP = «EP1», EP37-3FLFAO = «EP2») как электроизоляции для HTS-кабелей: пробой, механическая прочность, сдвиговая прочность интерфейса с HTS-лентой, DMA. Измерения при RT и 77 K.

## Ключевые результаты

### 1. Влияние покрытия на Ic (критично!)
- Нагрев при 80°C/8ч (отверждение) — небольшое снижение Ic;
- Покрытие EP1/EP2 — **небольшое снижение Ic**, EP2 меньше;
- EP1 труднее снимать с формы → больше механических повреждений → ниже Ic;
- **Вывод: эпоксидное покрытие НЕ убивает Ic, но требует аккуратной обработки.**

### 2. Диэлектрическая прочность (77 K vs RT)
- **Оба эпоксида: прочность ВЫШЕ при 77 K, чем при RT**: EP1 +17%, EP2 +120%;
- EP1 лучше EP2 (выше прочность и при RT, и при 77 K);
- При 77 K пробои почти не повреждают образцы; при RT — EP2 пробивается насквозь;
- Слой 1.5-1.9 мм соответствует кабелям 10 кВ.

### 3. Интерфейс эпоксид/HTS-лента (IFSS)
- **EP1: выше сдвиговая прочность** (выше модуль → лучше связывание);
- Интерфейс важен: delamination → пустоты → усиление поля → частичные разряды → ограничение напряжения и срока жизни;
- IFSS измерен только при RT (при 77 K — в работе).

### 4. DMA / гибкость
- EP1: Tg=33.8°C, EP2: Tg=5.6°C;
- Оба достаточно гибки для намотки кабеля на барабан (важно для транспортировки).

### 5. Практический вывод авторов
- Эпоксидное покрытие позволяет **заводское тестирование кабелей ДО установки** (сейчас невозможно — LN2/GHe часть диэлектрической системы);
- Начата разработка 1-м прототипов HTS-кабелей с EP1/EP2, PDIV не деградирует после термоциклов.

## Контекст (важно для кейса)
- Стандарт для HTS-кабелей — **PPLP + LN2** (бумага, пропитанная азотом); ограничение — частичные разряды в зазорах;
- Для авиации/флота — **газообразный гелий (GHe)**: низкая диэлектрическая прочность → PD при <10 кВ;
- Проблема всех эпоксидов: **рассогласование КТР с металлом → delamination, трещины, потеря Ic** (ссылки на Takematsu 2010, Matsuda 2018, Yang 2022);
- **Barth 2013** — «degradation free epoxy impregnation» (КИТ) — техника, смягчающая проблему.

## Значимость для кейса 004

1. **2023 год — эпоксидная изоляция всё ещё «в разработке»**: авторы только начинают прототипы кабелей, IFSS при 77 K ещё не измерен. Тема НЕ взлетела и к 2023.
2. **Подтверждает главный барьер:** delamination из-за КТР-рассогласования — «the disparity in CTE causes delamination, mechanical damage, reduction in Ic» — то же, что в кейсе hts_insulation (D-блок wishlist).
3. **Показывает разницу применений:** для КАБЕЛЕЙ (PPLP/LN2, GHe) изоляция критична для напряжения; для МАГНИТОВ (наш кейс 004) — для quench-защиты. В магнитах NI обходит проблему, убрав изоляцию.
4. **Контраргумент:** эпоксидные покрытия (в отличие от лент PPLP) дают гладкую поверхность → меньше PD → возможно, для кабелей это будущее. Но для магнитов — нет.
