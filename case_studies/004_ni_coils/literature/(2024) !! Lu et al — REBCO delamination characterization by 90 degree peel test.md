## Суть работы

Разработка **90° peel test** для измерения прочности на отрыв REBCO-лент — простой и воспроизводимый метод для QA в проекте 40 T all-superconducting magnet (NHMFL).

## Ключевые результаты
1. REBCO силён вдоль длины, но **слаб на отрыв поперёк (delamination)**;
2. **Даже термическая усадка при пропитке эпоксидом может вызвать delamination**;
3. 90° peel test: прост, воспроизводим, годится для массового QA;
4. **Peel strength растёт с уменьшением толщины Cu;**
5. **Peel strength положительно коррелирует с RRR Cu** (чистота меди).

## Значимость для кейса 004
1. **Подтверждает главный механический барьер изоляции:** пропитка → термонапряжения → delamination;
2. Метод для контроля качества — важно для промышленности;
3. 40 T проект NHMFL — прямое применение NI/высокопольных технологий;
4. Связь: D-блок wishlist (delamination), кейс 004, fusion_magnets.
