# Грантовый сигнал: SMES (кейс 005)

> **Дата:** .
> **Вопрос:** кто и сколько финансировал SMES через исследовательские гранты?
> **Метод:** поиск по грантовым базам (NSF, CORDIS, KAKEN, NIH, РНФ, NSFC) + национальные программы из литературы.
> **Данные:** `data/raw/grants_foreign/nsf_smes_results.json`, `cordis_smes_results.json` (собраны ).

**Вывод 1: SMES НЕ получал исследовательских грантов** (NSF/CORDIS/KAKEN) в сколько-нибудь заметном объёме.
Это контраст с NI-coils (KAKEN 17 грантов), flux pump и др. — SMES не имел даже «академического» грантового следа
на Западе после ~2000-х.

**Уточнение 2026-09-02 (окно 2000-2010):** NSF-грантов по SMES НЕТ даже точечно по 2000/2005/2008/2010.
⚠️ НО: в США SMES финансировал **DOE** (энергетика), а NSF API покрывает только научные гранты —
DOE-гранты в нашей базе отсутствуют (собирали NSF/NIH). SMES-финансирование США шло через DOE/EPRI
(SMES-ETM 1990-1995, BNL 2015), не через NSF.

## 2. Национальные ПРОГРАММЫ (не гранты, а целевое финансирование) — из литературы

Финансирование SMES шло НЕ через исследовательские гранты, а через **национальные программы развития**:

| Страна | Программа | Объём/период | Источник |
|---|---|---|---|
| **Япония** | NEDO/METI национальная программа | 1991-2003+: 20 MW/100 kWh → 100 MW/500 kWh; весь СП-истеблишмент (ISTEC, Hitachi, Toshiba, Chubu, Kyushu) | (Tatsuta 2004) |
| **Корея** | Ministry of Commerce, Industry and Energy | 2003-2012: K-SMES 600 kJ → 2.5 MJ → 5 MJ (KERI, Hyundai, Seoul Nat.) | (KERI 2006), (KERI 2009), (Lee 2012) |
| **США** | BPA + Los Alamos (гос. энергетика) | 1979-1982: 30 MJ демо | (BPA 1979) |
| **США** | DOE (через BNL) | 2015: HTS SMES coil (Gupta) — исследовательский | (SNF Gupta 2015) |
| **Германия/ЕС** | LIQHYSMES (KIT) | 2013: концепт 48 GJ MgB2+LH2 (не построен) | (SNF Sander 2013) |
| **Китай** | CAS / гос. программы | 2014 (100 kJ), 2022 (1 MJ CORC для ускорителей) | (Li 2022) |

**Вывод 2: SMES финансировался государственными ПРОГРАММАМИ развития (NEDO, Korea MOCIE), не грантами.**
Япония потратила больше всех (1991-2003, консорциум всей индустрии), Корея — вторая (2003-2012).
К 2012-2020 все западные/корейские программы закрыты; активен только Китай (CAS).

## 3. Что это значит для кейса (сигнал)

1. **Грантовый сигнал SMES = пусто** (в отличие от живых тем) — уже в 2018 фонды не давали денег;
2. **Финансирование было «программным» (сверху вниз)**, не «грантовым» (снизу вверх) — типично для
   технологий, продвигаемых государством вопреки экономике;
3. **Закрытие программ (Korea 2012, Япония фактически 1998-2003) = смерть финансирования** → тема
   осталась только на китайских госпрограммах (CAS) и единичных исследовательских (BNL 2015);
4. Для ML: фича «грантовая поддержка» для SMES = 0 на Западе → сильный отрицательный сигнал;
5. **Контраст с BESS:** Li-ion получал огромные частные инвестиции (гигафабрики Tesla/LG/CATL — $млрд)
   + господдержку (DOE, ЕС) — см. s5_bess_competition.md.
