## 0. ⭐ Проблема, которую закрывает технология (каркас кейса)

**Фундаментальная проблема: как надёжно зарегистрировать ОДИН фотон (единичный квант света)?**
Это «узкое горло» для целого класса приложений, где информация закодирована в отдельных фотонах
и потеря/шум одного фотона = потеря бита информации:

1. **Квантовая связь (QKD)** — секретный ключ шифруется в состояниях одиночных фотонов;
   перехват = возмущение = обнаруживается. Нужен детектор, который не пропускает фотоны и
   не даёт ложных срабатываний (dark counts);
2. **Квантовые вычисления (фотонные)** — фотонные кубиты (Xanadu, PsiQuantum): измерение
   исхода вычисления = детекция одиночных фотонов с разрешением числа фотонов (PNR);
3. **Квантовая оптика / фундаментальная физика** — тесты Белла, квантовая телепортация,
   Loophole-free эксперименты: нужны высокоэффективные детекторы;
4. **Прикладные:** LiDAR (дальномеры, автономное вождение), биология (флуоресценция
   одиночных молекул), астрофизика/тёмная материя, проверка квантовой механики;
5. **Космос/спутники** — квантовая связь на большие расстояния (Micius, будущие
   спутниковые QKD-сети).

**Почему это трудно:** фотон — единичный квант энергии (~1 эВ для видимого/ИК). Его надо
поймать с эффективностью >90-99%, отличить от шума (dark count < Гц), быстро (jitter < 100 пс,
чтобы не терять темп), и в широком спектре (телеком 1550 нм — где минимальные потери в оптоволокне).

## 0.1 ⭐ Альтернативы (конкурирующие технологии детекции одиночных фотонов)

| Технология | Принцип | Сильные стороны | Слабые стороны | Статус 2018→2026 |
|---|---|---|---|---|
| **SNSPD** (нанопроволока, сверхпроводник) | Фотон → горячая точка → резистивный переход в nanowire | **98-99.5% эффект., jitter 3-30 пс, dark ~Гц, быстрый (1.5 Gcps)** | Крио (<4K, теперь до 25K исслед.) | Ниша 2012 → **СТАНДАРТ 2026** |
| **TES** (transition edge sensor) | Сверхпроводник у Tc: фотон → нагрев → рост R | **PNR (разрешение числа фотонов), 95-98%** | Медленный (~мкс), нет jitter-скорости | Ниша (астрофизика, метрология) |
| **SPAD/APD (InGaAs, Si)** | Лавинный пробой p-n перехода | **Комнатная T, дёшево, компактно** | Тёмные счёты, afterpulsing, jitter хуже, <50% эффект. (InGaAs) | Стандарт для «дешёвых» задач |
| **PMT** (фотоумножитель) | Фотоэффект + умножение | Комнатная T, дёшево | Низкая эффект. в ИК, шум | Устаревает |
| **SNSPD-конкуренты в крио:** MKID, STJ | Кинетическая индуктивность / туннель | Широкий спектр | Медленнее/сложнее | Ниши |
| **Полупроводниковые nanowire** | — | — | — | Не вышли |

**Ключевое преимущество SNSPD (почему выиграл):**
1. **Эффективность >98% при 1550 нм** (телеком-окно) — недостижимо для InGaAs SPAD (~20-50%);
2. **Джиттер 3-30 пс** — на порядки лучше SPAD; критично для квантовой связи на скорость;
3. **Тёмные счёты ~1 Гц** — на порядки ниже SPAD (послеpulsing у InGaAs — фундаментальная
   проблема);
4. **Быстрый счёт 1.5 Gcps** — для высокоскоростной QKD.

**Почему это S4 («снятие предела»):** SNSPD снял предел чувствительности/шума/скорости,
который полупроводниковые детекторы (SPAD/APD) снять не могут (afterpulsing, тёмные счёты,
эффективность в ИК). Как только квантовые технологии (QKD, фотонные кубиты) упёрлись в этот
предел — SNSPD стал необходимым. **Конкурент (полупроводники) НЕ дешевел экспоненциально
в этой нише** (S5 не сработал против SNSPD) — редкий случай, когда сверхпроводник выиграл у
полупроводника.

## 1. Суть технологии

**SNSPD (Superconducting Nanowire Single Photon Detector)** — сверхпроводящая нанопроволока, регистрирующая одиночные фотоны. Лучшие характеристики: эффективность >99%, малый джиттер, высокая скорость.

## 2. Сигнал 2018

- Natarajan 2012 (953 цит.) — классический обзор
- Применения: квантовая связь (QKD), квантовые вычисления (фотонные), лидар, биология
- Китай (Pan Jian-Wei) и Европа — активны
- **Выглядело**: нишевая, но растущая технология

## 3. Вердикт 2018 (гипотеза автора)

**✅ ИНВЕСТИРОВАТЬ** — однозначно.

## 4. Исход 2026 (факт-чекинг)

| Веха | Год | Статус |
|---|---|---|
| Chang — 99.5% эффективность | 2021 | ✅ (231 цит.) |
| Steinhauer — масштабирование | 2021 | ✅ |
| Квантовая связь (QKD, спутники Micius) | 2020-26 | ✅ SNSPD — стандарт |
| Квантовые вычисления (фотонные) | 2026 | ✅ нужны SNSPD |
| Коммерческие SNSPD (ID Quantique, Single Quantum) | 2026 | ✅ |

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО — СТОИЛО.** SNSPD стали стандартом для квантовой связи и фотонных вычислений. Эффективность 99.5%, коммерческие поставщики.

## 5. Почему стоило (анализ)

1. **Квантовая связь взлетела** (QKD, спутниковая — Micius) — SNSPD критичен.
2. **Фотонные квантовые вычисления** (Xanadu, PsiQuantum) — нужны SNSPD.
3. **Превосходные характеристики**: >99% эффективность, малый джиттер.
4. **Коммерциализация** — ID Quantique, Single Quantum продают.

**Новые инсайты (2026-документы):**
1. **Применение расширяется, а не насыщается:** (а) спутниковая QKD переходит в mid-IR (3-5 мкм) —
   новое окно для SNSPD (Flannigan 2026); (б) квантовая криптография выходит за QKD — coin flipping,
   quantum internet (Vajner 2026). Оба — свежие драйверы спроса на однофотонные детекторы;
2. **SPAD не умер, а разделил ниши:** 96×96 комнатно-температурный InGaAs SPAD для flash LiDAR (Yildirim 2026)
   — полупроводник берёт массовые применения (имиджинг/массивы), СП — квантовые. Вердикт «стоило» точен
   именно для квантовой ниши, НЕ для всей детекции;
3. **Коммерциализация подтверждена:** рекорд 99.5% сделан TU Delft + **Single Quantum** (Chang 2021) —
   наука+бизнес (как Scontel в России).

## 7. Урок для калибровки (черновик)

**«Нишевая технология + снятие предела чувствительности (S4) + растущее применение = стоило»:**
- SNSPD выглядел нишевым в 2012-2018, но квантовая связь/вычисления создали спрос;
- Характеристики превосходили альтернативы (InGaAs APD): эффективность, джиттер, dark counts;
- S4: снят предел детекции одиночных фотонов (недостижим для полупроводников);
- S5: конкурент (полупроводники) НЕ смог догнать в этой нише — редкий случай, когда СП выиграл;
- Коммерциализация произошла.
