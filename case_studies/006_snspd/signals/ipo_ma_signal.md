# IPO/M&A сигнал: SNSPD (кейс 006) — коммерциализация через рынок капитала

> **Дата:** .
> **Вопрос (тест стратегии):** можно ли проследить IPO/M&A как индикатор коммерциализации SNSPD?
> **Метод:** ручной веб-поиск (DuckDuckGo) по ключевым игрокам кейса (патентные assignee +
> производители из реестра слаботочной СП). БЕЗ платных API (PitchBook/Crunchbase — антибот/устарели).
> **Вывод:** метод РАБОТАЕТ — SNSPD даёт богатый IPO/M&A-сигнал, согласованный с вердиктом «состоялся».

## TL;DR
SNSPD-экосистема к 2026 **коммерциализирована через рынок капитала**:
- **M&A: ID Quantique (CH) куплена IonQ за $119M (2025)** — явное M&A;
- **Крупные раунды:** PsiQuantum $1 млрд Series E (2025, оценка $7 млрд; всего $2.32B/8 раундов);
- **Гранты→коммерция:** Single Quantum (NL) — 13 раундов, инвестор EIC Fund (EU);
- **Новые стартапы:** QUAD (Южная Корея, SNSPD) — pre-Series A;
- **Публичные:** IonQ (NYSE) — покупатель; D-Wave/Rigetti (СП-кубиты, не SNSPD).
- РФ (Scontel): внешних раундов не найдено — вероятно, гос/самофинансирование.

## 3. Интерпретация (что даёт сигнал)

1. **M&A — сильнейший сигнал зрелости**: IonQ (публичная квантовая) покупает ID Quantique
   (пионера SNSPD/QKD, основана 2001 Gisin/Zbinden) за $119M в 2025. Это значит: **SNSPD-технология
   ценна для индустрии** — гигант платит, а не развивает сам.
2. **Крупный частный капитал**: PsiQuantum $1 млрд (2025) — фотонные квантовые вычисления,
   где SNSPD — ключевой компонент. Деньги идут в платформу, потребляющую SNSPD.
3. **Гранты → коммерция**: Single Quantum вырос из TU Delft (ERC PoC «Bringing to Market»)
   → теперь EIC Fund инвестор. Траектория «академия → ERC → EIC-фонд» — типична для состоявшейся
   глубокотех-компании.
4. **Новые игроки** (QUAD Корея) — экосистема расширяется, не консолидируется в монополию.
5. **РФ (Scontel)** — вне глобального рынка капитала (санкции/гос) — НО продаёт SNSPD (нишево).

## 4. Связь с вердиктом кейса 006 («состоялся»)

| Сигнал | 2018 (год окна) | 2026 (исход) |
|---|---|---|
| Публикации | рост (96/год) | 155/год, стандарт |
| Патенты | академия/CN | 182 изобретения |
| **IPO/M&A** | **~0** (Single Quantum только 1-й раунд 2015) | **ID Quantique куплена ($119M), PsiQuantum $1 млрд** |

**Вывод:** IPO/M&A — **ПОЗДНИЙ сигнал** (в 2018 их не было, к 2026 — есть). Он НЕ предсказывает
(в 2018 по IPO/M&A нельзя было сказать «состоится»), но **ПОДТВЕРЖДАЕТ исход** («состоялся» =
не только публикации/патенты, но и рынок капитала признал технологию). Для features_table:
`commercial_events` = 1 (M&A ID Quantique + PsiQuantum $1B) — часть метки «исход», не «сигнал 2018».

## 5. Что это даёт для ML (важно)
1. **IPO/M&A — верификатор «состоялся»** (как grants для зрелости), НЕ ранний сигнал.
2. Для negative-кейсов (SMES 005): проверить — были ли IPO/M&A? (ожидаемо 0 → отличает от SNSPD).
3. Метод ручного веб-поиска по assignee — **работает, дёшев, без API-бюджета**.

## 7. ⭐ Сравнение с negative-кейсом SMES (005) — различающая пара (2026-09-07)

> Проверено: SNSPD (positive) vs SMES (negative) по IPO/M&A — даёт различающий сигнал для ML.

| Критерий | SNSPD (006, ✅ состоялся) | SMES (005, ❌ не состоялся) |
|---|---|---|
| **M&A** | ✅ **ID Quantique куплена IonQ за $119M (2025)** | ❌ нет (поиск пуст) |
| **Крупные раунды** | ✅ PsiQuantum $1 млрд Series E (2025) | ❌ нет SMES-стартапов с раундами |
| **Компании-бизнес = технология** | ✅ Single Quantum, ID Quantique, QUAD | ❌ Infinity Power — НЕ SMES (афр. renewable); SMES-специфичных нет |
| **Публичные** | ✅ IonQ (покупатель), (D-Wave/Rigetti смежно) | ❌ AMSC (публичная) делала D-SMES, но не как продукт |
| **Коммерческие установки** | ✅ стандарт QKD (Single Quantum и др. продают) | ❌ «no relevant big facilities» (JRC 2025) |
| **Рынок капитала признал** | ✅ ДА (M&A $119M, $1B раунды) | ❌ НЕТ (0 событий) |

**Вывод для ML:**
1. **IPO/M&A — различающий признак** «состоялся/не состоялся»: SNSPD имеет M&A ($119M) и $1B-раунды,
   SMES — 0 (только госпрограммы NEDO/KERI/DOE). Это согласуется с grants_flag (у SMES гранты=0,
   только госпрограммы).
2. **IPO/M&A ≠ ранний сигнал** (в 2018 у SNSPD тоже ~0) — это **верификатор исхода**,
   но он ОТЛИЧАЕТ positive от negative в 2026 → полезен как фича «исхода» в features_table.
3. **Метод**: ручной веб-поиск по assignee/производителям кейса работает; для negative-кейса
   пустой результат (0 новостей) сам по себе — сигнал.
4. Оговорка: DuckDuckGo местами rate-limit (0 результатов) — перепроверять; но для SMES пустота
   согласуется с JRC 2025 (независимый источник).
