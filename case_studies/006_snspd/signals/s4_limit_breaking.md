## 2. Что именно «снято» (три предела)

1. **Эффективность в ИК (1550 нм):** 93% (2013) → 99.5% (2021).
   InGaAs SPAD: 20-50% — **фундаментально** (лавина требует высокой энергии, ИК-фотоны слабы);
2. **Джиттер:** 3 пс (2020). SPAD: ~100-400 пс. Для time-bin QKD и LiDAR критично;
3. **Тёмные счёты / afterpulsing:** у SPAD после лавины — паразитные срабатывания (afterpulsing) —
   **неустранимо** в полупроводнике. У SNSPD нет лавины → нет afterpulsing.

**Механика S4:** сверхпроводящая nanowire в токовом режиме близко к критическому току:
один фотон → горячая точка → резистивный домен → регистрируемый импульс.
Нет умножения (лавины) → нет afterpulsing; нет полупроводниковой запрещённой зоны → нет
порога энергии (работает в ИК, где фотоны ~0.8 эВ).

## 3. Почему конкуренты НЕ сняли (S4 → S5-вывод)

| Конкурент | Упёрся в | Итог |
|---|---|---|
| InGaAs SPAD | afterpulsing + низкая ИК-эффективность | проиграл в QKD |
| Si SPAD | не работает >1100 нм (кремний) | не для телекома |
| TES | медленный (~мкс) | ниша (астрофизика, PNR-метрология) |
| PMT | низкая квантовая эффективность в ИК | устарел |

## 4. Вывод S4

SNSPD — **классический случай «снятия предела»**: технология упёрлась в физический барьер
полупроводников (afterpulsing, ИК-эффективность) и сняла его. Это ровно тот сигнал, который
в методологии (S4) предсказывает успех — при условии, что есть спрос (квантовые технологии,
см. S5 §4). **Спрос пришёл извне (квантовая гонка), а не из самой технологии** — паттерн
успешных кейсов (003 космос, 004 термояд, 006 кванты).
