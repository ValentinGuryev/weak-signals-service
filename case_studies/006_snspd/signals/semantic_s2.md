## 1. Главные семантические сдвиги (частоты ‰)

### Терминология: SSPD → SNSPD (смена имени технологии)
```
sspd:  5.2 → 2.4 → 1.1 → 0.5 → 0.1  (умирает)
snspd: 5.0 → 11.1 → 10.4 → 10.5 → 9.8  (становится стандартом с 2010)
```
**Маркер созревания:** ранняя аббревиатура SSPD (superconducting single-photon detector)
вытеснена SNSPD (nanowire) — сообщество унифицировало название после ~2010.

### Материал: NbN → NbTiN / WSi / MoSi (смена рабочего материала)
```
nbn:   17.0 → 5.5 → 4.0 → 2.3 → 0.9  (резкое падение!)
nbtin: 1.0 → 0.8 → 0.9 → 1.0 → 1.2  (рост)
wsi:   0.0 → 0.9 → 1.0 → 0.7 → 0.6  (появился 2010+)
mosi:  0.0 → 0.1 → 0.9 → 0.6 → 0.2
```
**Маркер технического прогресса:** NbN (2001-2008, быстрый, но низкая эффективность)
уступил NbTiN/аморфным WSi/MoSi (высокая эффективность, PNR) — физика созрела.

### Фокус: QKD → общие квантовые технологии + новые применения
```
quantum:  5.7 → 8.5 → 8.9 → 11.9 → 12.4  (устойчивый рост)
qkd:      2.0 → 0.8 → 1.1 → 0.8 → 0.8    (снижение доли)
imaging:  0.0 → 0.6 → 1.2 → 2.7 → 3.4    (взрыв! новый драйвер)
lidar:    0.0 → 0.0 → 1.0 → 1.7 → 1.8    (появился 2015+)
temporal: 0.0 → 0.9 → 0.9 → 1.0 → 1.6    (растёт)
array:    0.5 → 2.0 → 1.5 → 3.8 → 2.4    (масштабирование)
pixel:    0.2 → 0.7 → 1.4 → 1.4 → 1.0    (массивы/имиджинг)
```

### Что «остыло» (зрелость базовых параметров)
```
efficiency: 13.2 → 13.1 → 11.6 → 9.8 → 8.9  (падает — предел достигнут, не главная тема)
detector:   11.7 → 11.4 → 10.5 → 9.9 → 8.3
photon:     15.2 → 13.8 → 14.4 → 12.5 → 10.7
telecom:    0.8 → 0.7 → 0.7 → 0.7 → 0.3
```

## 2. Обороты речи (отсечены LLM-фильтром — НЕ термины)
leading, achieves, offers, demonstrating, moreover, achievable, improved, development,
significant — растут/падают статистически, но это риторика, не технология.
**Пример ценности фильтра:** если бы не LLM-фильтр, «improved»/«demonstrating» выглядели бы
«растущими маркерами» — но это шум (как у коллег: 71% кандидатов — обороты).

## 3. Интерпретация (S2-вывод)

**SNSPD — зреющая, но не «угасающая» технология:**
1. **Терминология устоялась** (SNSPD вместо SSPD) — маркер консолидации;
2. **Материал эволюционировал** (NbN → NbTiN/WSi/MoSi) — технология не застыла, идёт инженерия;
3. **Применения РАСШИРЯЮТСЯ** (imaging ×∞, lidar, temporal, array) — НЕ насыщение, а диверсификация:
   от QKD (2010-е) к имиджингу/LiDAR/биомедицине (2020-е);
4. **Базовые параметры остыли** (efficiency) — потому что достигнуты (99.5%, S4), фокус сместился
   на новые метрики (jitter растёт 2.2→4.0, dark);
5. **Квантовый контекст растёт** (quantum 12.4‰) — технология встроена в квантовую экосистему.

**Отличие от IBAD (001):** там семантический сдвиг «фундаментальное→прикладное» НЕ подтвердился
(доля applied стабильна). Здесь — сдвиг ЕСТЬ, но другого рода: **смена материала + расширение
применений + унификация термина**. Это более информативный сигнал, чем «открытие→инженерия».

## 5. Для ML/методологии
- Семантические маркеры SNSPD: **смена аббревиатуры** (sspd→snspd), **смена материала**
  (nbn→nbtin/wsi/mosi), **рост применения-лексики** (imaging/lidar/temporal) — это обучающие
  признаки «технология в фазе инженерии/масштабирования»;
- LLM-фильтр оборотов обязателен: без него wordshift даёт ~141 «ложных растущих» слов-оборотов.
