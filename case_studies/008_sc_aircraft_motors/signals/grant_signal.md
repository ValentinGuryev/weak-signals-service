  (4 проекта: 2017, 2018, 2019, 2023) — включая «жидкий водород» (2019, 2023). **РФ-сигнал СИЛЬНЫЙ,

  (косвенный сигнал NSFC). «0 в базе ≠ 0 в реальности» (урок 007).

## 1. 🇷🇺 РФ — РНФ: МАИ, непрерывная линия 2017→2023 (КЛЮЧЕВАЯ НАХОДКА)

Из локальной базы РНФ (407 карточек) — **прямые проекты по ВТСП-машинам для самолётов**,
все — Московский авиационный институт (МАИ):

| № | Проект | Год | Руководитель | Суть |
|---|---|---|---|---|
| **17-19-01269** | Создание сверхпроводниковых электрических машин высокой удельной мощности для БЭС/ПЭС | **2017** | Ковалев К.Л. (МАИ) | ВТСП-2 машины для более/полностью электрических самолётов — **ровно год окна!** |
| **18-79-00306** | Рациональные параметры обмоток из ВТСП для электрических машин | **2018** | Иванов Н.С. (МАИ, молодёжн.) | ВТСП-обмотки, AC-потери |
| **19-79-10206** | Системы криогенного обеспечения ВТСП электромеханических преобразователей + **жидкий водород** | **2019** | Голованов Д.В. (МАИ, молодёжн.) | Крио + LH2 — РФ идёт в водород! |
| **23-19-00624** | Электрические машины с ВТСП-обмотками для **гибридной силовой установки**, жидкий водород | **2023** | Иванов Н.С. (МАИ) | Продолжение в водородной волне |

**Выводы по РФ:**
1. **РФ финансирует СП-авиамоторы непрерывно с 2017** (год «гонки»!) — сигнал 2018 в РФ был (РНФ-грант 17-19-01269 стартовал в 2017).
2. **МАИ — единственный центр** (Ковалев/Иванов/Голованов — одна школа).
3. РФ **синхронно с миром перешла к «жидкому водороду»** (2019, 2023) — водородная платформа глобальна.
4. Старый README (2026-08-21) РФ-гранты НЕ упоминал — **пробел закрыт**.

## 2. 🇪🇺 ЕС — CORDIS: ядро мало, конкуренты-водород обильны

**Ядро (СП/крио-моторы):**
| Проект | Программа | Суть |
|---|---|---|
| **ASuMED** | H2020 (2017) | Advanced SC Motor Experimental Demonstrator — СП-мотор для авиации |
| **HIVOMOT** | H2020 (2021) | High power voltage electric MOTors in aeronautics |
| **HyperMorpH** | HORIZON | **Hyperconducting** Electric Propulsion + Composite Structures (новый!) |

**Конкуренты (водород/гибрид/электромоторы) — ОБИЛЬНЫ:**
FAME (Fuel cell Megawatt Engines, Clean Aviation), HYLENA (H2-electrical engine), HEAVEN (H2 fuel cell),
ENABLEH2 (cryogenic H2), H3PS (hybrid powertrain), HE-ART (hybrid regional), SWITCH (hybrid turbofan),
QualE-fly, EPS55, TRIATHLON (H2-thermo), NEWBORN, MINIMAL, EFACA...

**Вывод по ЕС:** СП-моторы — **малая ниша** (2-3 проекта), а **водород/гибрид-электрические — приоритет**
(10+ проектов HORIZON/Clean Aviation). ЕС финансирует поле, но СП — не главный путь (в отличие от РФ-МАИ и NASA).

## 3. 🇨🇳 Китай — NSFC: прямых нет в базе, но университеты активны

- **NSFC-база (129 по «超导»):** прямых проектов по СП-авиамоторам **НЕТ** (7 совпадений — квантовые/материалы).
- ⚠️ Артефакт канала: база собиралась по общим СП-ключам, не по «高温超导电机/航空».
- **Косвенный сигнал:** в корпусе 453 — **230 работ с CN-авторами** от HUST (49), Beihang (27), Hunan (18),
  SJTU (15), CAS (13) → университеты финансируются (NSFC/министерства), тема активна.

## 6. Что это даёт кейсу (связь с S1a и вердиктом)

1. **РФ-сигнал 2018 = СИЛЬНЫЙ** (РНФ-МАИ 2017) — в отличие от вывода README «слабый сигнал» (там РФ не было).
   РФ (МАИ) — наравне с ЕС (ASuMED) и NASA (HEMM) финансировала СП-авиамоторы в год окна.
2. **Гранты растут к 2026** (HyperMorpH HORIZON, NASA 5MW, МАИ-2023) — согласуется с S1a (публикации растут).
3. **Водородная платформа глобальна** (РФ LH2, ЕС H2-проекты, NASA cryo) — подтверждает смену платформы.
4. **Гранты — НЕ lagging здесь** (в отличие от JTWPA 007): были в 2017-18 (год окна) — потому что госпрограммы
   (РНФ/NASA) реагируют на «гонку» быстрее, чем конкурсные гранты.
