## Суть
Разработаны короткие экспериментальные образцы ВТСП-ТНЭ для магнитной системы ТРТ, проведены
физико-механические испытания (изгиб на разные диаметры, измерение Ic после каждого) для выработки
методики аттестации. ⭐ Среди образцов — «V-Shape» (Тип 3).

## ⭐ Ключевое: 5 типов образцов ТНЭ (для ТРТ)
1. **Тип 1:** CORC малого диаметра (Ø6.7), без оболочки — проверка возможности CORC в крупных сборках.
2. **Тип 2:** CORC уменьшенный (Ø15.6) в стальной оболочке — отработка методики аттестации.
3. **⭐ Тип 3 = «V-Shape»:** полноразмерный (Ø26 мм) кабель с **радиальным расположением стопок
   ВТСП-лент**, заключённых в медные стабилизирующие сектора + оболочка из нержавеющей стали.
   **6 стопок по 20 лент, угловой шаг 60°.** Ленты (пакеты) направлены **плоскостями ПО РАДИУСУ**
   круглого кабеля (V-образное расположение). Пакеты НЕ твистированы. Потенциально применим в ЭМС ТРТ.
4. **Тип 4:** полноразмерный CORC (Ø26 мм) со стальной оболочкой — кандидат для ЭМС ТРТ.
5. **Тип 5:** плоская шина 3×15 мм, ленты под углом к плоскости, в медной оболочке — вспомогательный
   ТНЭ для второстепенных задач.

Типы 1,2,4 — коаксиальная многослойная намотка (CORC-технология); **Тип 3 — V-образное расположение
пакетов лент по радиусу** (другие варианты такого типа — в работе [3] статьи, не найдена).

## Методика
Изгиб на трёхроликовом трубогибе на разные диаметры (по проектных параметрам обмоток) → измерение
Ic (критерий 1 мкВ/см) в жидком азоте после каждого воздействия → оценка деградации. Источник тока
до 21.5 кА.

## Значимость для кейса 009 (⭐ V-Shape найден!)
1. **V-Shape — российская (Курчатовский ин-т) разработка для ТРТ**: ленты стоят «на ребро» (радиально),
   в медных секторах, 6 стопок × 20 лент, Ø26 мм — НЕ намотаны на сердечник (как CORC), а уложены
   радиально V-образно. Это принципиально иная организация, чем CORC.
2. **Концепт V-Shape существует и испытывается** (2023, ВАНТ) — НО это Курчатовский институт, а не
   Быковский/Сытников. (Автор задачи предполагал Быковского или Сытникова — фактически это Диев/Курчатов;
   концепт «другие варианты» — в ссылке [3] статьи, требует уточнения.)
3. **V-Shape vs CORC — прямое сравнение в одной работе** (Тип 3 vs Тип 4, оба Ø26 для ТРТ):
   Курчатовский институт испытывает оба как кандидатов для ТРТ.
4. Гео-картина дополняется: **РФ (Курчатовский ин-т) развивает V-Shape + CORC для ТРТ**;
   Сытников/ВНИИКП — stacked-tape для TRT (2021). Обе российские линии — в контексте ТРТ.
