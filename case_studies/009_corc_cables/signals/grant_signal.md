## 1. NSF (США) — ПУСТО (0 релевантных из 132) — канал-артефакт, как в кейсе 007

**Запросы:** "CORC conductor", "conductor on round core", "REBCO cable", "coated conductor cable",
"superconducting cable fusion magnet", "round core superconductor" + точечно "REBCO", "coated conductor",
"YBaCuO coated conductor", "superconducting cable".
**Собрано:** 132 гранта, **релевантных CORC: 0**.

| Что даёт NSF по "CORC" | Пример |
|---|---|
| шум «corc» = Correlated-Electron | Light-Emitting Devices Enabled by Large-Area Correlated-Electron Transparent Conductors |
| шум «corc» = Organic Ranking Cycle | SBIR: Compact Torus-Shaped Organic Ranking Cycle (солнечная энергия) |
| шум «cable» = power line/transmission | Hovering Drone for Electric Utility |
| REBCO-релевантные (не CORC) | только 40T All-Superconducting Magnet (FSU, 2019/2021, $4.2M/$15.8M) — частично HTS, не CORC |

**Вывод NSF:** NSF-поиск по CORC пуст. **Причина (методологическая):** финансирование CORC в США идёт
через **DOE (FES — Fusion Energy Sciences, SBIR/STTR)** и CERN, а не NSF. NSF API ловит только прямое
слово в названии/абстракте и НЕ покрывает DOE. **NSF-числа НЕ читать как «США не финансировали»**
(тот же урок, что в кейсах 006 SNSPD и 007 JTWPA).

- **Ключевое (методологический инсайт v2):** грантовый сигнал CORC был РАННИМ и сильным, НО через
  **DOE SBIR/STTR (ACT)**, который НЕ ловится грантовыми API (NSF/CORDIS/РНФ). Опора только на NSF/CORDIS

- **Контраст с кейсами:** 005 SMES — гранты = 0 ВООБЩЕ (нет даже DOE-следа в статьях);
  007 JTWPA — гранты ЕС 2021+; **009 CORC — DOE SBIR/STTR с 2012 (ранний!)** — уникально.

### 7a. ⚠️ Recall-попытка Lens (2026-09-09) — урок: термин-поиск не покрывает ACT

**Попытка:** ~7 вызовов (R0-R2 = 4 успешных + R3-R5 = 3 неудачных) для расширения патентной базы.
**Результат:** recall добавил ~0 к чистой базе (43 найденных = дубли старого + мусор); recall_extra = 0.

**Критические уроки Lens:**
1. **ACT-семейства (series-connected, quench, power cable, cable machine, connections) НЕ содержат
   «CORC»/«round core» в abstract** (проверено US11587701: generic «superconducting cable») →
   fielded-поиск по термину их НЕ ловит. Они есть только в ручной базе (добраны по title-фразам).
2. **`sort: priority_date` — HTTP 400** («Mismatched input for fields - [sort, priority_date]»).
3. **`inventors` match_phrase — 0** (van der Laan, ten Kate/Mulder) — поле не индексируется как phrase;
   работает только простой match по одному токену (как в academy-скрипте по университетам).
4. СП-контекст на сервере (must: superconducting/cable/wire/...) хорошо режет фарм-мусор — приём полезен.

**Вывод о покрытии:** чистое CORC-ядро = 57 уник. документов (ACT 18, Кит. ун-ты 11, Кит.-энергетика 9,
Hefei/CAS 6, Кит. СП-компании 5, NKT 5, Lyon/Takayasu/Rey по 1). Полное покрытие ACT требует
inventor/assignee-обхода, который в Lens недоступен текущим синтаксисом → **~70-80% за fielded-поиск
недостижимо без ручной добивки**. База пригодна для качественного анализа игроков, не для строгих
количественных сигналов.
