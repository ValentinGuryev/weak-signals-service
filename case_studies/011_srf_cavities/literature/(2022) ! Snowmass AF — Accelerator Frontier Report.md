# (2022) ! Snowmass AF — Accelerator Frontier Report

- **Библиография:** Snowmass 2021 Accelerator Frontier Report (Frontier Conveners S. Gourlay (LBNL), T. Raubenheimer (SLAC), V. Shiltsev (FNAL); topical conveners включая S. Belomestnykh (FNAL, RF), A. Valishev, F. Zimmermann и др.), arXiv:2209.14136v2 [physics.acc-ph], 2022-11-17 (v2).
- **Аффилиации:** LBNL, SLAC, Fermilab, Cornell, CERN и др.
- **Релевантность для кейса 011 (SRF-резонаторы):** 3/5 (!). Официальный отчёт по всему Accelerator Frontier (не только SRF); SRF-содержимое — важные, но фрагментарные упоминания. Контекст будущих проектов.

## Суть
Итоговый отчёт Snowmass 2021 (десятилетний план физики ускорителей США) по делам Accelerator Frontier: будущие коллайдеры (ILC, FCC-ee, CepC, C3, HELEN, ReLiC), нейтринные фабрики, продвинутые ускорители, GARD-темы (включая SRF как один из 4-5 research thrusts).

**SRF-фрагменты по факту текста:**
- Достижение: «новые методы обработки поверхности дали **35-55 МВ/м градиенты в SRF-полостях** с беспрецедентными quality factors (успешно применены в LCLS-II/HE)».
- GARD (Generic Accelerator R&D) включает SRF: 35-55 МВ/м + HTS-магниты (14.5 Тл Nb3Sn, 300 Т/с HTS) как знаковые успехи десятилетия.
- ILC: 250 ГэВ, SRF @ 31.5 МВ/м в среднем; XFEL (Гамбург) = 750+ SRF-полостей @ 23 МВ/м, действующая демонстрация 10% масштаба ILC; ILC «shovel-ready», фокус — удешевление криомодулей.
- FCC-ee/CepC: сотни SRF-полостей; C3 — альтернатива на «холодной меди» (LN2), HELEN/ReLiC — TW-SRF (traveling wave), в апгрейдах — **«SRF с большим Q, большим градиентом, TW-полости и Nb3Sn»** (повторяется для ILC/HELEN/ReLiC).

## Ключевые результаты
1. SRF — признанная ключевая технология будущих коллайдеров; градиент 35-55 МВ/м — «новое нормальное» (LCLS-II/HE).
2. Драйвер развития SRF на 2030-40-е: **высокое Q + высокий градиент + traveling wave + Nb3Sn** — официальная повестка.
3. R&D-фокус: удешевление криомодулей (для ILC/FCC), промышленнаяготовность.

## Выводы для кейса
- **S2/S3-контекст 2022:** SRF «созрела до инженерного этапа» на уровне национальных программ, но коммерческая экспансия — через крупные проекты (LCLS-II/HE, будущие коллайдеры), а не рынок.
- Nb3Sn официально в дорожной карте будущих линаков — подтверждает «в развитии» для кейса 011.
- Экономический канал: объём SRF определяется проектами (XFEL: 750+ полостей) — «патенты без конверсии» для 011 частично объясняются моделью «один большой заказчик» (лаборатории), а не серийным производством.
