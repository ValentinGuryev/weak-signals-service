# Паспорт: матрица взаимных цитирований таксономии поля (кейс 011, S3-cross)

- **Файл (сигнал):** `case_studies/011_srf_cavities/signals/s3_cross_taxonomy.md` — 3 матрицы
  (все годы / цитирующие ≤2018 / цитирующих 2019+) + фокус-строка/столбец Nb3Sn + выводы.
- **Скрипт:** `src/crosscite_taxonomy_011.py` (0 API, локально, воспроизводимо).
- **Вход:** `data/raw/openalex/srf_corpus.json` (7579) ∪ `srf_problem_supplement.json` (12444)
  = 19999 работ (дедуп по id). Паспорт дополнения: `srf_problem_supplement.md`.
- **Метод:**
  1. Классификация работ по 7 таксонам (первый матч по title+abstract, приоритетный порядок:
     Nb3Sn → Nb bulk → др.СП-материалы → SRF-системы → NC/медь → диэлектр./THz → плазма/лазер);
     классифицировано 11920 работ; фон (общая RF-физика) = 8079 — не технология, исключён.
  2. Ориентированные рёбра: для каждой работы с `references` (исходящие) — если цитируемый id
     тоже в корпусе → ребро (группа_цит, группа_цит-ся). Среза по году ЦИТИРУЮЩЕЙ работы.
  3. Матрицы: абсолютные рёбра + нормировка по строкам (%).
- **Покрытие:** рёбра внутри корпуса 20248 (self-cites 17000, 84%). Ссылки на работы ВНЕ корпуса
  не учитываются → абсолютные числа = нижняя оценка, направления/доли — состоятельны.
- **Дата:** 2026-09-14. **API-расход:** 0 (локальные данные).
- **Как восстановить:** `.venv/bin/python src/crosscite_taxonomy_011.py`.
