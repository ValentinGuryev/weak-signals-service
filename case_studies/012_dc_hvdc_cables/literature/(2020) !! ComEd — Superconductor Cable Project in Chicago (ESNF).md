# (2020) !! ComEd — Superconductor Cable Project in Chicago (ESNF)

## Метаданные
- **Авторы:** Daniel P. Brotzman (ComEd), Jim Maguire (AMSC)
- **Год:** 2020 · **Источник:** SNF-коллекция (ESNF)

## Резюме (релевантность 4/5)
**Чикаго (ComEd + AMSC) — первый постоянный HTS-кабель в энергосети США** (2G-технология).

**Факты:**
- «newly announced project in Chicago that will install a **permanent in-grid superconducting cable**» —
  **первая постоянная установка в США** на 2G HTS;
- «**low voltage cable**» — низкое напряжение (городское распределение);
- План масштабирования технологии (технологическая площадка).

## Ценность для кейса 012
- **США подключаются:** первый постоянный городской HTS-кабель (2G) — после десятилетий лабораторий
  США (LIPA 2008 — пилот) наконец постоянная установка;
- **Низкое напряжение** = городское распределение (не >100 кВ магистраль) — подтверждает «вольты
  не обязательно огромные»;
- AMSC — производитель 2G-лент (индустриальный игрок).

## Итоговая оценка
**4/5** — первый постоянный HTS-кабель США (2020); переносит кейс в американский контекст.
