## Вопросы кейса (S4 — «снят ли предел» + почему актуализация)
1. **Снят ли предел?** Что именно меняется физически/экономически у крио/СП-вычислений,
   чтобы заявка «~25× perf/W» (Snowcap) стала возможной vs десятилетние циклы «умерших» идей
   (RQL, AQFP, гибридные проекты c 1990-х)? Какие барьеры остались (охлаждение, компрессоры,
   плотность СП-логики, экономика криосистемы)?
2. **Почему актуализировалась в 2025-2026?** Что изменилось внешне: энергопотребление ЦОД,
   дефицит HBM/энергии для ИИ, новый капитал (Snowcap $23M Playground, Гелсингер в совете),
   интерес Reuters/EENews.
3. **Публикационный сигнал (S1a):** разведка OpenAlex (2026-09-16) показывает:
   - `cryogenic computing` — пик **2026** (28); рост с 2021;
   - `superconducting logic` — пик **2026** (81; 2024:46 → 2026:81 ≈ ×1.8);
   - `cryo-CMOS` — пик **2026** (94; 2022:42 → 2026:94 ≈ ×2.2);
   - `cryogenic data center` — скачок **2025:26 → 2026:59** (×2.3!);
   - `RQL` — пик **2022** (9), к 2024-25 затухание → старая школа не растёт;
   - `AQFP` — пик **2019** (37), спад → старая школа не растёт;
   - `Snowcap` по названию в аннотациях — 0 (новизна/отсутствие научного следа у стартапа).
   Вывод разведки: актуализация видна по «прикладным» терминам (дата-центры, cryo-CMOS, СП-логика),
   старые технологические школы (RQL/AQFP) угасают.

## Гипотеза (для проверки чтением)
Актуализация 2025-2026 = (а) кризис энергопотребления ИИ-ЦОД (дойлловый драйвер), (б) зрелость
cryo-CMOS/компрессоров/3D-интеграции (инженерный драйвер), (в) капитал первого VC-входа (Snowcap)
при отсутствии массового научного следа («0 в базе ≠ 0 в реальности», но и «внимание ≫ содержание»
пока не подтверждено). Вопрос S4: заявка 25× perf/W — на какой элементной базе (адиабатическая
логика? RSFQ? cryo-CMOS + холодные HBM?) и с какой полной стоимостью владения (compressor → 4K).
