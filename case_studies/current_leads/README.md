# Кейс: СП-токовводы (HTS current leads) — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза автора : ✅ СТОИЛО (безальтернативно).
> Вопрос: стоило ли инвестировать в сверхпроводящие токовводы в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**HTS токовводы** — токовводы из ВТСП для питания сверхпроводящих магнитов. Снижают тепловую нагрузку криостата (вместо медных). Используются в LHC, ITER, ускорителях.

## 2. Сигнал 2018

- LHC использует HTS токовводы (Ballarino 2002, 43 цит.) — с 2008
- ITER закупает (70kA токовводы)
- **Выглядело**: зрелая ниша, стабильный спрос

## 3. Вердикт 2018 (гипотеза автора)

**✅ ИНВЕСТИРОВАТЬ** — безальтернативное применение (все СП-магниты нуждаются).

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО — СТОИЛО.** HTS токовводы — стандарт для LHC/ITER, зрелая ниша с постоянным спросом от всех СП-магнитов.

## 5. Почему стоило (анализ)

1. **Безальтернативность**: любой СП-магнит требует токовводов; HTS снижает теплоприток.
2. **LHC/ITER** — реальные заказы, не демо.
3. **Технология зрелая** — низкий риск.
4. **Новые драйверы**: fusion (CFS, ITER), FCC, квантовые магниты.

## 7. Урок для калибровки

**«Зрелая безальтернативная ниша = стоило»** (как детекторные магниты, SRF):
- HTS токовводы — обязательный компонент всех СП-магнитов
- LHC/ITER дали реальные заказы
- Низкий риск, стабильный спрос

→ Признак «стоило»: **обязательный компонент + реальные заказы (не демо).**
