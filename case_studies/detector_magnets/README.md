# Кейс: СП-магниты для детекторов (физика частиц) — стоило ли в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза автора : ✅ СТОИЛО (безальтернативное применение).
> Вопрос: стоило ли инвестировать в сверхпроводящие магниты для детекторов частиц в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**СП-магниты для детекторов** — крупные соленоиды в экспериментах физики частиц (ATLAS, CMS, ALICE, PANDA, Mu2e). Создают магнитное поле для измерения импульса частиц.

**Безальтернативность:** без сверхпроводящего магнита невозможно измерить импульс — это прямое, «обязательное» применение сверхпроводимости (как термояд).

## 2. Сигнал 2018

- CMS (3.8Т), ATLAS (2Т) работают с 2008
- Новые: PANDA (FAIR), Mu2e (Fermilab) — строятся
- Green 2016 — классика детекторных магнитов
- **Выглядело**: стабильный спрос, новые проекты

## 3. Вердикт 2018 (гипотеза автора)

**✅ ИНВЕСТИРОВАТЬ** — безальтернативное применение.

## 5. Почему стоило (анализ)

1. **Безальтернативность**: без СП-магнита нельзя измерить импульс частиц — это обязательное применение.
2. **Стабильный спрос**: новые эксперименты (PANDA, Mu2e, DUNE) — постоянные заказы.
3. **Наука-драйвер**: физика частиц продолжается (CMS, FCC).
4. **Технология зрелая**: надёжная, предсказуемая.

## 7. Урок для калибровки

**«Безальтернативное применение — всегда перспективно» (гипотеза автора подтверждена):**
- Там, где без сверхпроводимости НЕЛЬЗЯ (детекторы, термояд) — спрос гарантирован
- Не зависит от рыночной конкуренции (ВТСП vs LTS не важно — нужно поле)
- Наука финансирует стабильно

→ Признак «стоило»: **применение, где сверхпроводимость обязательна (не заменяема).**
