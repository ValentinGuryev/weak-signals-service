## 2. Сигнал 2018 (что видел бы алгоритм)

| База | Сигнал 2018 | Оценка |
|---|---|---|
| **Основание компаний** | CFS (2018, $50M Eni), Tokamak Energy (REBCO ST25-HTS 2015) | ✅ |
| **Патенты** | ВТСП-ленты: no-insulation 70k, superconducting magnet 118k | ✅ огромный |
| **Гранты** | РНФ пиннинг ВТСП, CORDIS (термояд) | ✅ |
| **Инвестиции** | $50M CFS 2018 → $115M 2019 | ✅ растущие |
| **Технология** | REBCO-ленты для 20 T (SPARC) | ✅ |

**Вердикт алгоритма 2018: ИНВЕСТИРОВАТЬ.**
- Мульти-сигнал: патенты (70k+) + инвестиции ($50M→$115M) + гранты + компании.
- Уникальное преимущество DC-ВТСП: высокое поле без потерь (20 T) — недостижимо для меди/LTS.

## 3. Исход 2026

| Признак | Статус 2026 |
|---|---|
| **CFS** | $50M (2018) → >$1 млрд (2023-2025); SPARC строится (18 катушек, янв 2026) |
| **Tokamak Energy** | $335M всего; ST40 >100 млн°C (2022) |
| **SPARC** | сборка идёт (2026), план ARC 400 MWe к 2030-м |
| **Рекорд** | 20 T HTS-магнит (2021) — подтверждён |

**Исход: УСПЕХ.** Инвестиции 2018 года в магнитные катушки для термояда окупились (CFS стал единорогом, SPARC строится).

---

## 4. Урок для алгоритма
- **DC-ВТСП (магниты) — успех** (в отличие от AC-ВТСП-кабелей — провал).
- **Мульти-сигнал решает:** патенты + инвестиции + гранты + компании → уверенный «инвестировать».
- **Термояд = главный драйвер** ВТСП-лент (70k патентов) — именно через магниты.
