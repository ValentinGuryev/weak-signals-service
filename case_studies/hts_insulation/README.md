# Кейс: Изоляция для ВТСП-магнитов — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза автора: ✅ СТОИЛО (базовая); «умная» — ниша.
> Вопрос: стоило ли инвестировать в электроизоляцию для ВТСП-магнитов (теплопроводящая + изолирующая) в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ). Идея автора — факт-чекнута в `results/calibration/calibration_candidates_author_ideas.md`.

## 1. Суть технологии

**Изоляция для ВТСП-магнитов** — материал, сочетающий высокую теплопроводность (отвод тепла из катушки) и электрическую изоляцию. Классика: Al2O3 (теплопроводен при 77 K, изолятор). «Умная» изоляция: свойства изолятора → проводника по температуре (материалов НЕТ).

## 2. Сигнал 2018

- Al2O3 — стандарт для ВТСП
- **ЦЕРН: полиимидная изоляция** (Winkler 2017, La China & Tommasini 2008) — лучше теплоотвод к сверхтекучему гелию
- Актуальная задача: теплоотвод из катушки vs электроизоляция
- **Выглядело**: нужна всем ВТСП-магнитам, задача не решена полностью

## 3. Вердикт 2018

**✅ ИНВЕСТИРОВАТЬ** (базовая изоляция — нужна всем ВТСП-магнитам).

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО (базовая) — СТОИЛО.** Ультратонкое акриловое покрытие (Guo 2022), полиимид ЦЕРН (Winkler 2017), база данных лент (Zhang 2022). «Умная» изоляция — НЕ существует (перспективная ниша).

## 5. Почему стоило (анализ)

1. **Нужна всем ВТСП-магнитам**: фундаментальная компонента, не одна ниша.
2. **ЦЕРН валидировал**: полиимидная изоляция для сверхтекучего гелия (Winkler 2017).
3. **Реализовано**: ультратонкие акриловые покрытия (Guo 2022).
4. **База данных лент** (Zhang 2022) — стандартизация для индустрии.

## 7. Урок для калибровки

**«Фундаментальная компонента всех магнитов + валидация ЦЕРН = стоило»**:
- Изоляция — «пик и лопата» для ВТСП-магнитов (fusion, МРТ, ускорители)
- Задача не решена в 2018 (компромисс тепло/изоляция) → пространство для улучшений
- Реализация к 2026 (Guo 2022) подтвердила
- Осторожно: «умная» изоляция (переключаемая) — НЕ существует, не вкладывать
