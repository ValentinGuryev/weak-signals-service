# Кейс: ВТСП-ленты (coated conductors / 2G HTS) — калибровочный «успех»

> **Роль кейса:** калибровочная тема «успех». Вопрос: рекомендовал бы наш алгоритм инвестиции в ВТСП-ленты в 2018? Исход 2026 — успех?
>
> **Гипотеза пользователя (ключевая!):** надо было инвестировать в **удешевление производства** и **лазерную технику** — вся ВТСП-индустрия завязана на **эксимерные лазеры** и расходники к ним (окна, которые не запыляются и остаются прозрачными в вакуумном процессе).

---

## 1. Почему это «успех» (мульти-базовый сигнал)

| База | Сигнал | Данные |
|---|---|---|
| **Патенты** | no-insulation coil: **70 176**, superconducting magnet: 117 954 | ✅ огромный |
| **Инвестиции** | CFS (Commonwealth Fusion) $1 млрд (2021), термояд | ✅ |
| **CORDIS** | SCARLET €15M (сверхпроводящие кабели) | ✅ |
| **Китай** | Shanghai Superconductor (223 публ.), Western Superconducting (113) | ✅ |
| **Гранты РНФ** | пиннинг ВТСП-2G: 6 грантов | ✅ |
| **arXiv** | 11 статей по NI-катушкам (но патенты 70k!) | ⚠️ «одна база врёт» |

**Ключевой инсайт:** ВТСП-ленты — это тот случай, где **arXiv молчит** (11 статей), а **патенты (70k) и инвестиции ($2 млрд) кричат**. Мульти-база видит успех, хотя наука слаба.

## 2. Производство ВТСП-лент — роль лазеров (инсайт пользователя)

### Технология (2G HTS coated conductors)
Основные методы производства:
1. **PLD (Pulsed Laser Deposition)** — импульсное лазерное осаждение (эксимерный лазер!) — самый распространённый для REBCO-слоя.
2. **IBAD / ABAD** — ионно-лучевое осаждение текстуры (не лазер).
3. **MOCVD** — химическое осаждение (не лазер).
4. **CSD / TFA** — химическое (Solvay/AMSC) (не лазер).

**PLD = эксимерные лазеры (KrF 248 нм, XeCl 308 нм)** — ключевой инструмент.

### «Узкие места» (инсайт пользователя — расходники!)
- **Окна в вакуумной камере:** лазерный луч проходит через окно; в процессе напыления окно **запыляется** (материал мишени оседает) → теряет прозрачность → падает энергия лазера → ухудшается качество плёнки.
- **Решение:** окна с анти-запыляющим покрытием, газовые завесы, вращающиеся окна — **ниша расходников**.
- **Лазерные источники:** эксимерные лазеры (Coherent, Lambda Physik) — дорогие, требуют газового обслуживания (KrF: F2, Kr, Ne), **замена газовых смесей — регулярные расходы**.
- **Мишени:** YBCO/REBCO-мишени — сами по себе дорогие расходники.

### Почему это «незамеченный» инвестиционный сигнал
- **2018:** все инвестировали в «саму ленту» (материал, Ic), но **удешевление производства = лазеры + расходники** — меньший рынок, но стабильный «pick-and-shovel».
- **2026:** ВТСП-индустрия выросла (термояд, кабели, магниты) → **спрос на эксимерные лазеры и расходники вырос пропорционально**.
- **Калибровка:** алгоритм, следящий только за «лентами» в arXiv, **пропустил бы** лазерный слой. Мульти-база (патенты 70k) его бы поймала.

## 3. Вердикт алгоритма на 2018

**ИНВЕСТИРОВАТЬ.** Причины:
1. **Размер:** патенты 70k+ (массивные).
2. **Мульти-сигнал:** патенты + инвестиции (CFS) + гранты (РНФ пиннинг) + CORDIS (SCARLET) — **пересечение 4+ баз**.
3. **Экономика:** рынок термояда/энергетики огромен; удешевление производства — ключевая ниша.
4. **Новизна:** 2G HTS — новая технология (2000-е+), растёт.

## 4. Исход 2026

| Признак | Статус 2026 |
|---|---|
| Термояд | **УСПЕХ** — CFS, Tokamak Energy, MIT SPARC |
| Кабели | SCARLET €15M (CORDIS), HTS-кабели |
| Магниты | 70k+ патентов, высокопольные |
| Индустрия | Shanghai Superconductor, Western Superconducting, AMSC, Fujikura |
| Лазеры/расходники | спрос растёт с производством |

**Исход: УСПЕХ** (в отличие от SMES/fluxonics). Алгоритм был прав, рекомендуя.
