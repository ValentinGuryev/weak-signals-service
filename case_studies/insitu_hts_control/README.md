## 1. Суть технологии

**In-situ контроль качества при производстве ВТСП-лент** — системы контроля в линии (компьютерное зрение, XRD, Raman, кривизна) для выявления брака на ранней стадии, не дожидаясь готовой ленты. Существенная экономия на браке.

## 2. Сигнал 2018

- White 2002 «On-Line Texture Diagnostics for Coated Conductor Manufacture» (DOE) — ранняя попытка
- Barth 2015 «Electro-mechanical properties of REBCO from various manufacturers» — контроль как задача
- Разрозненные работы; контроль постфактум (TEM, электро-механические тесты)
- **Выглядело**: назревшая задача, но без готовой платформы

## 3. Вердикт 2018

**✅ ИНВЕСТИРОВАТЬ** — экономия на браке = ясный ROI.

## 5. Почему стоило (анализ)

1. **Экономика**: брак ленты = потеря дорогого материала и времени → ROI очевиден.
2. **2G-HTS растёт**: fusion, МРТ, кабели → нужен контроль в линии.
3. **Технологии созрели**: Raman, CV, профилирование — доступны.
4. **Реализовано**: Castañeda 2026 — реальная R2R-платформа (не концепция).
