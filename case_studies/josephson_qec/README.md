# Кейс: Джозефсоновские переходы для квантовой коррекции ошибок — калибровочный «УСПЕХ»

> **Роль:** калибровочный кейс «успех». В 2018 нужно было ПОДДЕРЖИВАТЬ исследования джозефсоновских переходов ДЛЯ QEC (а не для кубитов) — жизнь подтвердила в 2026.
> **Вопрос:** рекомендовал бы наш алгоритм инвестиции в 2018?

---

## 1. Ключевые проекты/вехи (проверяемые данные)

### 1.1 QEC на сверхпроводящих системах — прорывы
| Год | Событие | Источник |
|---|---|---|
| **2016** | **Первый break-even QEC**: время жизни логического кубита > физического (Schrödinger-cat состояния в СП-резонаторе, реальная обратная связь) | Wikipedia (QEC) |
| **2021** | Первый entangling gate между логическими кубитами в топологическом коде (toric code, 10 ионов) | Wikipedia (QEC) |
| **2023-2024** | IBM/Google: поверхностный код, логические кубиты | Wikipedia |

### 1.2 Роль джозефсоновских переходов (JJ)
- **Кубиты** (трансмон) — на JJ.
- **QEC требует** считывания (дисперсионное, через JJ-усилители JPA), логики (CX через JJ).
- **Поверхностный код** — 10+ физических кубитов на 1 логический — **нужны миллионы JJ**.
- Ключевой инсайт: **в 2018 ставка была на «кубиты» (единичные), а реально выиграли те, кто инвестировал в JJ для QEC-масштабирования (тысячи JJ)**.

### 1.3 Индустриальные проекты
- **IBM Quantum:** roadmap (2018+) — поверхностный код, 1000+ кубитов (2023-2025).
- **Google Quantum AI:** Sycamore (2019), демонстрация surface code (2023-2024).
- **Quantinuum/IONQ:** трап-ионы (другая платформа, но QEC).
- **SEEQC** (Mukhanov): СП-электроника для считывания/управления квантовых систем.

## 2. Сигнал 2018 (что видел бы алгоритм)

| База | Сигнал 2018 | Оценка |
|---|---|---|
| **Патенты** | quantum error correction: **168 666** (огромный!) | ✅ |
| **Гранты** | РНФ: джозефсоновские контакты, квантовые вычисления | ✅ |

| **Наука** | 2016 break-even → 2018 консолидация | ✅ |

**Вердикт алгоритма 2018: ИНВЕСТИРОВАТЬ.**
- Самый большой патентный сигнал из всех (168k).
- Мульти-сигнал: патенты + гранты + индустрия (IBM/Google) + наука (2016 break-even).

## 3. Исход 2026

| Признак | Статус 2026 |
|---|---|
| **QEC** | стал ОБЯЗАТЕЛЬНЫМ для квантовых компьютеров (IBM/Google roadmap) |
| **JJ-масштабирование** | тысячи/миллионы JJ — индустрия (SEEQC, IBM) |
| **Поверхностный код** | реализован (2023-2024) |
| **Инвестиции** | квантовые вычисления: $1 млрд+ раунды (PsiQuantum, Quantinuum) |

**Исход: УСПЕХ.** Инвестиции 2018 в QEC (и JJ для него) — правильные. QEC — обязательный этап к fault-tolerant.

## 4. Урок для алгоритма
- **QEC — крупнейший патентный сигнал (168k)** → алгоритм должен был дать максимальный Score.
- **Ключевой инсайт пользователя:** важно различать «JJ для кубитов» vs «JJ для QEC» — последнее масштабируется (тысячи JJ на систему).
- **Мульти-база:** патенты + индустрия (IBM/Google) + гранты.
