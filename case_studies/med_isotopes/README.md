# Кейс: Медицинские изотопы на СП-циклотронах (Mo-99, 225Ac) — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза: 🔶 СПОРНО.
> Вопрос: стоило ли инвестировать в производство медицинских изотопов на сверхпроводящих ускорителях/циклотронах в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex/arXiv, ).

---

## 1. Суть технологии

**Медицинские изотопы** — Mo-99/Tc-99m (диагностика, 16+ млн процедур/год в США), 225Ac (терапия). Традиционно — ядерные реакторы (хрупкая цепочка). Альтернатива — ускорители/циклотроны (включая СП-циклотроны, СП-линки IsoDAR).

## 2. Сигнал 2018

- Дефициты Mo-99 (2010-2018, закрытие реакторов)
- СП-циклотроны для PET — коммерческие (Cyclone, IBA)
- IsoDAR (2020+) — СП-циклотрон для изотопов
- **Выглядело**: дефицит + ускорительные альтернативы = ниша

## 3. Вердикт 2018

**🔶 СПОРНО** — дефицит реален, но СП-ускорители для изотопов не стали стандартом.

## 4. Исход 2026 (факт-чекинг)

| Факт | Год | Статус |
|---|---|---|
| Проекты ускорительных изотопов (Moon 2026, Alonso 2020) | 2020-2026 | 🔶 активные, не массовые |
| СП-циклотроны для изотопов | 2026 | ❌ не стандарт |
| Mo-99 из реакторов (основной путь) | 2026 | ✅ остаётся |
| 225Ac — дефицит (Higashi 2022) | 2022 | 🔶 растущий спрос |

**Итог 2026:** 🔶 **НЕ ОДНОЗНАЧНО.** Дефицит Mo-99/225Ac реален, ускорительные проекты идут (Moon 2026, IsoDAR), но СП-циклотроны для изотопов НЕ стали основным путём. Реакторы доминируют.

## 5. Почему спорно (анализ)

1. **Дефицит реален**: Mo-99 хрупкая цепочка (реакторы стареют), 225Ac дефицитен.
2. **Ускорительные альтернативы идут**: Moon 2026 (D+ циклотроны), IsoDAR, 225Ac из ускорителей (Higashi 2022).
3. **НО**: СП-специфика не критична — большинство ускорителей не СП-циклотроны.
4. **Для калибровки**: «дефицит + решение в пути, но не СП-специфично» — пограничный.

## 7. Урок для калибровки

**«Дефицит + решение, но не СП-специфичное = СПОРНО»**:
- Дефицит Mo-99/225Ac реален → тема важна
- НО: ускорительные решения не требуют СП-циклотронов (обычные тоже)
- СП-компонент слабый → инвестиция в СП-специфику рискованна
- Для ML: «рыночная потребность ≠ СП-специфическая возможность»
