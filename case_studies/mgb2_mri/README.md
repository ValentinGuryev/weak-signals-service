# Кейс: Диборид магния (MgB₂) для МРТ нового поколения — калибровочный «УСПЕХ»

> **Роль:** калибровочный кейс «успех». В 2018 нужно было ПОДДЕРЖИВАТЬ MgB₂ для МРТ — жизнь подтвердила в 2026.
> **Вопрос:** рекомендовал бы наш алгоритм инвестиции в 2018?

---

## 1. Ключевые проекты/вехи (проверяемые данные)

### 1.1 История MgB₂ для МРТ
| Год | Событие | Источник |
|---|---|---|
| **2001** | Открытие сверхпроводимости MgB₂ (39 K) | Wikipedia |
| **2006** | **0.5 T открытое МРТ на MgB₂** — 18 км провода, cryocooler без жидкого гелия | Wikipedia (MgB₂) |
| **2010-е** | Компании: Paramed (Италия), ASG Superconductors, Columbus Superconductors | отраслевые |
| **2018** | MgB₂-МРТ — «next generation MRI instruments must be made of MgB₂ coils instead of NbTi» | Wikipedia (цитата) |
| **2020-е** | 1.5 T МРТ на MgB₂ (Paramed/ASG) — дешёвые, без гелия | отраслевые |

### 1.2 Ключевые игроки
- **Paramed Medical Systems (Италия)** — МРТ на MgB₂.
- **ASG Superconductors (Италия)** — MgB₂-провод (PIT), тот же, что в SCARLET (кабели).
- **Columbus Superconductors (Италия)** — MgB₂ wire (входит в ASG).
- **NIH RePORTER (наши данные):** гранты на «MgB2 Croygen-Free Magnet Technologies — Enabling Affordable MRI» ($808k, 2010-2012) — ранние.

### 1.3 Преимущество MgB₂
- **T_c = 39 K** — работает при 20-25 K (cryocooler, без гелия!).
- **Дёшево:** MgB₂-провод дешевле NbTi и намного дешевле REBCO.
- **МРТ без гелия** — решает дефицит гелия (цена выросла в разы с 2020).

## 2. Сигнал 2018 (что видел бы алгоритм)

| База | Сигнал 2018 | Оценка |
|---|---|---|
| **Патенты** | mgb2: **4 757** (Google Patents) | ✅ |
| **Гранты** | NIH RePORTER: MgB2 MRI гранты ($808k, $3M) | ✅ |
| **CORDIS** | SCARLET (MgB2-кабели), Bologna DRYSMES4GRID (MgB2) | ✅ |
| **KAKEN** | Япония: MgB2-соединения для μMRI | ✅ |
| **Индустрия** | Paramed, ASG, Columbus | ✅ |

**Вердикт алгоритма 2018: ИНВЕСТИРОВАТЬ.**
- Мульти-сигнал: патенты (4.7k) + гранты (NIH) + CORDIS + индустрия (Италия).
- **Ключевое:** дефицит гелия (2020+) → «МРТ без гелия» = растущая ниша.

## 3. Исход 2026

| Признак | Статус 2026 |
|---|---|
| **MgB₂-МРТ** | коммерциализируется (Paramed/ASG) |
| **Дефицит гелия** | кризис 2020-2026 → спрос на безгелиевые МРТ |
| **MgB₂-провод** | в SCARLET (кабели), DRYSMES4GRID (SMES) |
| **Патенты** | 4.7k (растут) |

**Исход: УСПЕХ.** Инвестиции 2018 в MgB₂ для МРТ — правильные (дефицит гелия подтвердил).

---

## 4. Урок для алгоритма
- **MgB₂ — «тихий» успех:** патенты 4.7k (меньше, чем REBCO), но мульти-сигнал (гранты + CORDIS + индустрия) + **внешний драйвер (дефицит гелия)**.
- **Важно:** алгоритм должен учитывать внешние рыночные факторы (цена гелия), а не только патенты.
- **Италия — кластер MgB₂** (Paramed, ASG, Columbus, SCARLET).
