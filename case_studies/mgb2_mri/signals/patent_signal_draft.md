## 4. МРТ-специфичное ядро (34 уник.) — ключевые вехи
- **2012–2013**: Conductive-cooling persistent current switch + MRI (JP, 3 пат.); **Persistent-mode MRI magnet from monofilamentary MgB2 (MIT/US 2013)** — «персистент-режим» — центральная технология МРТ.
- **2016**: методы производства MgB2-провода/катушки для МРТ (JP/KR).
- **2018 (пик сигнала!)**: серия JP-патентов «MgB2 superconducting wire, superconducting coil, and MRI» (+KR shield) — совпадает с цитатой README «next-gen MRI must be MgB2».
- **2021–2023 (Китай)**: MgB2-соединители для linek (2021, 2022), быстрый MgB2-провод для МРТ (2023), **МРТ для стоячей позы / портативная МРТ (2023—2024)** — прикладной сдвиг к продукту.

## 5. Вывод (для сигнального слоя кейса)
- **Сигнал 2018 — есть:** кластер МРТ-специфичных патентов конкретно в 2018 (Япония: wire+coil+MRI), персистент-магниты с 2012, лидер Hitachi (31 пат. MgB2) и производственники (Starck, NIMS). Патентный канал подтверждает «тренд зарождался» (S1-гейт: статьи ∩ патенты).
- **Исход 2026 — подтверждён на патентном уровне:** Китай вышел в продукт (быстрая МРТ-лента 2023, портативная МРТ 2024), Япония держит производство (2018→2023).
- ⚠️ **Хвост/честность:** A4=0 — Paramed/ASG/Columbus в Lens по связке «игрок×MgB2» не найдено (их патенты без фразы MgB2 или в Lens отсутствуют) — итальянцев добирать вручную (веб/Google Patents автором) при разработке кейса; часть A1 — NMR-оборудование (мусор ~10-15%).

## 6. Что осталось к разработке кейса
- Чистка мусора (NMR vs MRI) и полный A5 (774) при необходимости;

- Сопоставление с грантами (NIH MgB2 cryogen-free $808k 2010-12) и конференциями (TAS MgB2);
