# Кейс: MKID (кинетически-индуктивные детекторы) для астрономии — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза: ✅ СТОИЛО.
> Вопрос: стоило ли инвестировать в MKID (microwave kinetic inductance detectors) для мм/субмм-астрономии в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**MKID** — сверхпроводящие детекторы (на кинетической индуктивности), мультиплексируемые тысячи каналов на одном криостате. Альтернатива TES (наш кейс #33) с преимуществом масштабируемости (частотное мультиплексирование).

## 2. Сигнал 2018

- NIKA (2010, Monfardini) — MKID-камера миллиметрового диапазона
- Mauskopf 2018 (48 цит.) — обзор «TES and KID in astronomical instruments»
- DESHIMA (Нидерланды, Endo) — on-chip спектрометр
- **Выглядело**: MKID — растущий стандарт для больших матриц

## 3. Вердикт 2018

**✅ ИНВЕСТИРОВАТЬ** — масштабируемость (тысячи каналов) — ключ для астрономии.

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО — СТОИЛО.** MKID — стандарт для больших детекторных матриц (NIKA2, DESHIMA, CONCERTO). Масштабируемость победила.

## 5. Почему стоило (анализ)

1. **Масштабируемость**: тысячи каналов (частотное мультиплексирование) — ключ.
2. **Растущие телескопы**: NIKA2, DESHIMA, CONCERTO — инструменты строятся.
3. **Отличие от TES**: MKID проще читать (частотная мультиплексация), дешевле.
4. **Зрелость к 2026**: ревью (D'addabbo 2026), CRS readout — индустриализация.

## 7. Урок для калибровки

**«Масштабируемая технология для растущего рынка инструментов = стоило»**:
- MKID решает главную проблему TES (чтение тысяч каналов)
- Строящиеся инструменты (NIKA2, DESHIMA) — реальный спрос
- К 2026 — зрелость и readout-индустриализация
- «Выигрывает тот, кто масштабируется» (как REBCO vs BSCCO)
