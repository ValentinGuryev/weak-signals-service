# Кейс: Импульсные магнитные поля (NHMFL 100T) — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза: ✅ СТОИЛО.
> Вопрос: стоило ли инвестировать в импульсные магнитные поля (100T-класс) в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**Импульсные магниты** — генерация полей до 100+ Тл на миллисекунды (NHMFL Pulsed Field Facility, Лос-Аламос). Для: физика конденсированного состояния, материаловедение, квантовые явления.

## 2. Сигнал 2018

- NHMFL 100T multi-pulse (Michel 2020)
- Pulsed Field Facility (Wampler 2021)
- **Выглядело**: уникальная научная инфраструктура

## 3. Вердикт 2018

**✅ ИНВЕСТИРОВАТЬ** — уникальная user facility, безальтернативна.

## 4. Исход 2026 (факт-чекинг)

| Веха | Год | Статус |
|---|---|---|
| NHMFL 100T multi-pulse | 2020 | ✅ |
| Pulsed Field Facility (Wampler 2021) | 2021 | ✅ |
| Новые duplex магниты | 2020+ | ✅ |
| Спрос (физика, материалы) | 2026 | ✅ |

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО — СТОИЛО.** NHMFL 100T работает, уникальная инфраструктура для физики высоких полей. Как и центры стационарных полей — «пик и лопата» для науки.

## 5. Почему стоило (анализ)

1. **Безальтернативность**: 100 Тл — только импульсные, мало кто может.
2. **User facility**: учёные приезжают (материаловедение, кванты).
3. **Монополия**: NHMFL — один из немногих.
4. **Геополитика**: доступ ограничен (для РФ закрыт после 2022).
