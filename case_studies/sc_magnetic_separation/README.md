# Кейс: Магнитная сепарация на СП-магнитах (водоочистка)

> **Калибровочный кейс (2018 → 2026).** Идея автора .
> Вопрос: стоило ли инвестировать в 2018 в СП-магнитную сепарацию?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

Магнитная сепарация: частицы разделяются магнитным полем. **Высокоградиентная магнитная сепарация (HGMS)** использует сильное поле + матрицу из ферромагнитных шариков/нитей для захвата слабомагнитных частиц.

**СП-вариант:** сверхпроводящий магнит даёт поля 5-10 Тл (против 1-2 Тл у постоянных/электромагнитов) → захват более слабомагнитных и мелких частиц.

**Применения:**
- ✅ **Водоочистка** (удаление фосфатов, мышьяка, тяжёлых металлов) — РАБОТАЕТ
- ✅ Биотех/фарма (белки, клетки)
- ⚠️ **Горнодобыча** (каолин, уголь, хвосты) — на ПОСТОЯННЫХ магнитах, СП-прототипов нет

---

## 2. Сигнал 2018

- HGMS промышленная с 1974 (Kelland 1974)
- СП-магниты для сепарации — с 2003 (Yokoyama 2003, 29 цит.)
- **Водоочистка**: Zhang 2011 (26 цит.), Zhao 2012 (42 цит.) — уже работали!
- **Горнодобыча**: на постоянных магнитах, СП нет

## 3. Вердикт 2018 (гипотеза автора)

**НЕ ИНВЕСТИРОВАТЬ** (в СП-сепарацию для горнодобычи — СП-прототипов нет).

**НО:** в водоочистку СП-сепарация уже работала в 2011-2012 → туда, возможно, стоило.

## 4. Исход 2026

| Ниша | Статус | Прототипы |
|---|---|---|
| **Водоочистка** | ✅ РАБОТАЕТ | Zhang 2011, Zhao 2012, Li 2022 (47 цит. — мышьяк) |
| Биотех/фарма | ✅ работает | Kamioka 2014, Schwaminger 2019 (94 цит.) |
| **Горнодобыча** | ⚠️ нет СП | постоянные магниты; СП-HGMS только для хвостов (Yang 2017) |

## 5. Почему (анализ)

**Водоочистка выиграла** потому что:
- Сточные воды содержат слабомагнитные частицы (фосфаты, мышьяк) — нужно СИЛЬНОЕ поле → СП-магниты дают преимущество
- Крупные объёмы, готовая инфраструктура водоочистки
- Экологические требования (ужесточение норм) → спрос

**Горнодобыча отстала** потому что:
- Каолин/уголь разделяются на 1-2 Тл (постоянные магниты достаточно)
- СП-магниты дороже, криогеника сложнее
- Экономика не оправдывает замену постоянных магнитов
- СП-HGMS начал проникать только для микро-хвостов (Yang 2017)

## 7. Урок для калибровки

**Ниши важны!** Одна технология (СП-сепарация) — разный исход в разных нишах:
- Водоочистка: ✅ (сильное поле = преимущество, спрос есть)
- Горнодобыча: ❌ (постоянные магниты достаточно, СП не окупается)

→ Калибровочный кейс должен фиксировать НИШУ, не только технологию.
