# Кейс: СП-передача для развивающихся стран («умные сети») — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза: ❌ НЕ СТОИЛО.
> Вопрос: стоило ли инвестировать в СП-сети как решение для энергосистем развивающихся стран (Пакистан, Африка) в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**СП-передача для «умных сетей»** — идея: сверхпроводящие сети как решение энергетических проблем развивающихся стран (потери, плотность нагрузки). Обсуждалась в обзорах (Thomas 2015), без проектов.

## 2. Сигнал 2018

- Thomas 2015 (129 цит.): «польза СП-передачи не известна лицам, принимающим решения»
- Нет ни одного проекта в развивающихся странах
- **Выглядело**: академическая дискуссия, не рынок

## 3. Вердикт 2018

**❌ НЕ ИНВЕСТИРОВАТЬ** — СП не конкурентно по цене для этих рынков.

## 4. Исход 2026 (факт-чекинг)

| Факт | Год | Статус |
|---|---|---|
| Raza 2022 — smart grid Пакистан (77 цит.) | 2022 | ❌ без СП |
| СП-проекты в развивающихся странах | 2026 | ❌ нет |
| Обычные сети (ВИЭ + HVDC) | 2026 | ✅ выбор рынка |

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО — НЕ СТОИЛО.** Развивающиеся страны строят обычные сети (smart grid Пакистан — без СП). СП не появился.

## 5. Почему не стоило (анализ)

1. **Цена**: СП-кабели в разы дороже обычных — для бюджетов развивающихся стран недоступно.
2. **Инфраструктура**: криостаты, охлаждение, обслуживание — нет кадров/сервиса.
3. **Приоритеты рынка**: сначала базовый доступ к энергии, потом эффективность.
4. **Thomas 2015 прямо говорит**: решение-мейкеры не знают о СП — значит, нет спроса.

## 7. Урок для калибровки

**«Технология дорогая + рынок с другими приоритетами = НЕ стоило»**:
- СП не конкурирует по цене на развивающихся рынках
- «Умные сети» решаются дешёвыми решениями (ВИЭ + цифровизация), не СП
- Отсутствие спроса (Thomas 2015: «не известна решение-мейкерам») — сигнал
