# Кейс: СП-генераторы для ветряков (EcoSwing) — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза автора : ❌ НЕ СТОИЛО.
> Вопрос: стоило ли инвестировать в сверхпроводящие генераторы для ветроэнергетики в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**СП-генераторы для ветряков** — ротор на ВТСП (REBCO) вместо постоянных магнитов/обмоток. Цель: выше мощность при меньшем весе/размере.

## 2. Сигнал 2018

- **EcoSwing** (EU H2020, грант ~€5.9M) — полномасштабный демонстратор 3.6 МВт
- Kyling 2019 (2 цит.): «world's first superconducting wind turbine generator»
- Япония (Furuse 2016, 16 цит.) — криосистемы для СП-генераторов
- **Выглядело**: «вот-вот СП-генераторы для ветряков»

## 3. Вердикт 2018 (гипотеза автора)

**❌ НЕ ИНВЕСТИРОВАТЬ** — демо без ясного пути к коммерции.

## 4. Исход 2026 (факт-чекинг)

| Веха | Год | Статус |
|---|---|---|
| EcoSwing демонстратор 3.6 МВт (Bergen 2019, 128 цит.) | 2019 | ✅ TRL 6-7 |
| **Коммерциализация** | 2026 | ❌ **НЕТ** |
| СП-генераторы в рынке ветряков | 2026 | ❌ нет |

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО — НЕ СТОИЛО.** EcoSwing успешно продемонстрировал технологию (TRL 6-7), но коммерческих СП-ветрогенераторов нет — ВТСП дорого, редкоземельные постоянные магниты дешевле.

## 5. Почему не выстрелили (анализ)

1. **Экономика**: ВТСП-ленты дорогие, криосистема сложная; постоянные магниты (NdFeB) дешевле и проще.
2. **Цена на магниты падала** (2018-2020) — делала СП ещё менее конкурентным.
3. **Демо без коммерции** — как СП-авиамоторы: технология работает, но не окупается.
4. **Криосистема в роторе** (вращающаяся) — сложно, надёжность под вопросом.

## 7. Урок для калибровки

**«Демо-успех ≠ инвестиционный успех»** (тот же паттерн, что авиамоторы):
- EcoSwing достиг TRL 6-7 (технология работает!)
- НО экономика против: ВТСП дороже постоянных магнитов
- Без удешевления ВТСП и решения криосистемы — коммерции нет

→ Признак «не стоило»: **работающее демо, но экономика не сходится** (конкурент дешевле).
