# Кейс: TES-детекторы (transition edge sensors) — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза: ✅ СТОИЛО.
> Вопрос: стоило ли инвестировать в сверхпроводящие детекторы TES (болометры) в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**TES (Transition Edge Sensor)** — сверхпроводящий болометр на границе перехода. Сверхчувствительные детекторы для: рентгеновской астрофизики, космологии (CMB), нейтрино, квантовой оптики.

**Масштаб:** 351 статья в IEEE TAS (1993-2026) — огромная тема!

## 2. Сигнал 2018

- TES-массивы для космологии (CMB-S4, LiteBIRD)
- Рентгеновская астрофизика (Micro-X, Athena)
- **Выглядело**: растущая научная ниша

## 3. Вердикт 2018

**✅ ИНВЕСТИРОВАТЬ** — критичные для астрофизики/космологии.

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО — СТОИЛО** (для науки). TES — стандарт в астрофизике/космологии, массивы масштабируются. НО: это научный рынок (миссии, обсерватории), не массовый продукт.

## 5. Почему стоило (анализ)

1. **Безальтернативность** для космологии (CMB, рентген) — другие детекторы хуже.
2. **Крупные миссии**: CMB-S4, LiteBIRD, Athena — финансирование.
3. **Технология зреет**: массивы, readout (RFSoC).
4. **Научный рынок** — стабильный, но ограниченный (миссии, не быт).

## 7. Урок для калибровки

**«Научная ниша с крупными миссиями = стоило, но не массовый рынок»**:
- TES незаменимы для CMB/рентгеновской астрофизики
- Крупные миссии финансируют (CMB-S4, Athena)
- Рынок — научный, стабильный, но не бытовой
