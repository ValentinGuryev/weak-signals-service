# Кейс: Измерительные стенды для СП-кабелей (SULTAN-тип) — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Идея автора : ✅ СТОИЛО (однозначно).
> Вопрос: стоило ли инвестировать в постройку экспериментального измерительного оборудования (типа SULTAN) для ВТСП-кабелей в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**Измерительные стенды для СП-кабелей** — крупные тестовые установки для испытания сверхпроводящих кабелей под нагрузкой (ток, поле, механические напряжения, квенч).

**SULTAN** (PSI, Швейцария) — самый известный: тестирует кабель-в-кондуит (CICC) для ITER, fusion.
**EDIPO** — тестовый дипольный магнит PSI для испытаний кабелей.
**FENIX** (LBNL) — исторический стенд для ITER-кабелей.

## 2. Сигнал 2018

- SULTAN работал для ITER (Nb3Sn CICC)
- **2015: Upgrade SULTAN/EDIPO for HTS Cable Test** (Wesche) — начали адаптировать под ВТСП
- Fusion на ВТСП набирал обороты (CFS, MIT ARC 2015)
- **Выглядело**: стенды нужны, но ВТСП-кабели ещё не массовые

## 3. Вердикт 2018 (гипотеза автора)

**✅ ИНВЕСТИРОВАТЬ** — измерительные стенды = «пик и лопата» для всех, кто делает СП-кабели.

**Итог 2026:** ✅ **ПОДТВЕРЖДЕНО — СТОИЛО.** SULTAN стал ключевой площадкой для тестирования HTS-кабелей fusion (VIPER от CFS тестировали там). Fermilab строит свой стенд — спрос растёт. Все fusion-компании (CFS, Tokamak Energy) и CERN нуждаются в тестовых установках.

## 5. Почему стоило (анализ)

1. **«Пик и лопата»**: не нужно угадывать, какой кабель выиграет — все нуждаются в тестировании.
2. **Fusion-бум**: CFS (SPARC), Tokamak Energy, ITER — все используют HTS-кабели (CORC, VIPER) → нужны стенды.
3. **Единственный в мире**: SULTAN — монополист для CICC-тестов → высокая загрузка.
4. **Дорогой вход** (100M+ стенд) → мало конкурентов, высокая маржа.
5. **Новые стенды строят** (Fermilab 2023) — подтверждает спрос.

## 7. Урок для калибровки

**«Инфраструктура для тестирования = надёжная ставка»:**
- Пока есть несколько конкурирующих СП-кабелей (CORC, VIPER, Roebel, CICC) — все должны тестироваться
- Стенды (SULTAN) — монопольная позиция, высокая загрузка
- Fusion-бум создаёт спрос на тестирование
- Даже конкуренты строят свои стенды (Fermilab) — рынок растёт

→ Признак «стоило»: **измерительная инфраструктура (пик и лопата) с растущим числом клиентов (fusion, ускорители).**
