## 1. Суть технологии

**Топологические кубиты** — кубиты на Majorana-фермионах. Обещали: топологическая защита от ошибок (fault-tolerant по построению). Microsoft — главный сторонник (Station Q).

1. **Обещания без демонстрации**: «топологическая защита» не показана экспериментально.
2. **Конкуренты выиграли**: transmon (IBM/Google) масштабируются, Majorana — нет.
3. **Технические барьеры**: Majorana-фермионы трудно создать и контролировать.
4. **Спорные результаты**: часть заявлений Microsoft не воспроизведена.
