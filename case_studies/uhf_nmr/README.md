# Кейс: Сверхвысокопольный ЯМР (1.2 ГГц / 28.2 Тл, HTS-вставки) — стоило ли вкладываться в 2018?

> **Калибровочный кейс (2018 → 2026).** Гипотеза: ✅ СТОИЛО.
> Вопрос: стоило ли инвестировать в сверхвысокопольный ЯМР (1+ ГГц, HTS-вставки) в 2018?
> Статус факт-чекинга: предварительный (Crossref/OpenAlex, ).

---

## 1. Суть технологии

**Сверхвысокопольный ЯМР** — спектрометры 1+ ГГц (23.5+ Тл). LTS-магниты (Nb3Sn) ограничены ~23.5 Тл (1 ГГц). HTS-вставки (REBCO, Bi-2223) позволяют перешагнуть: 1.1-1.3 ГГц (25.9-30.5 Тл). Ключевая задача — суперпроводящие соединения HTS (persistent mode).

## 2. Сигнал 2018

- Bascunan 2013 — 700-MHz HTS insert for 1.3 GHz (50 цит.) — MIT/FBML
- Японская программа 1.02 ГГц (RIKEN, RIKEN/BRUKER)
- Гонка за 1.2 ГГц (Bruker) и 1.3 ГГц (MIT, Япония JST-Mirai)
- **Выглядело**: технологическая гонка, HTS-вставки — путь за LTS-предел

## 3. Вердикт 2018

**✅ ИНВЕСТИРОВАТЬ** — HTS-вставки позволяют за LTS-предел, рынок ЯМР ждёт.

## 5. Почему стоило (анализ)

1. **За LTS-предел**: только HTS-вставки дают >1 ГГц — монопольная технология.
2. **Гонка идёт**: Bruker, RIKEN, MIT, Япония (JST-Mirai) — конкуренция подтверждает ценность.
3. **Научная ценность**: разрешение для биомолекул (структурная биология).
4. **Реализация к 2026**: 1.2 ГГц (28.2 Тл) — работающий продукт.

## 7. Урок для калибровки

**«Технология, открывающая новый предел (за LTS) + гонка гигантов = стоило»**:
- HTS-вставки — единственный путь за 1 ГГц (монопольная ниша)
- Гонка Bruker/RIKEN/MIT — рыночное подтверждение
- Прогресс к 2026 (1.2 ГГц, 1.3 ГГц в разработке) — не «вечно в R&D»
- Урок: «предел существующей технологии = точка входа» (как REBCO-магниты)
