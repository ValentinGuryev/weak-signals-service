# 02_benchmark_dataset.md — Собственный эталонный датасет: бэктест 2018 → 2026 (Шаг 2)

> ⚠️ Черновик v0.2. Данные — из ретро-кейсов проекта (домен: сверхпроводящие технологии),
> сводка по реестру калибровочных кейсов.

## 1. Зачем этот шаг

Надёжного и достаточного для ML-обучения датасета нет (шаг 1). Методологию нельзя строить «в пустоту»:
нужна **проверяемая почва** — набор примеров, где известны и «сигнал», и «исход». Мы построили его
сами, в экспертной области автора (сверхпроводимость), где исход по каждому кейсу можно
**задокументировать**.

## 2. Устройство эталона: бэктест, а не мнение

| Элемент | Как устроено |
|---|---|
| **Точка отсчёта** | 2018 год — по каждому кейсу используются ТОЛЬКО данные до 2018 (публикации, гранты, патенты, конференции, дорожные карты, новости рынка). Исключает «подглядывание в будущее» (look-ahead bias) |
| **Точка валидации** | 2026 год — известно, состоялся ли тренд (коммерческий выпуск, внедрение, рынок) или «сдулся» |
| **Документальность** | каждый вердикт «состоялся/не состоялся» подкреплён документами (релизы, установки, закрытия программ, финансовые результаты) — это **диагноз по уликам, а не мнение эксперта** |
| **Объём** | ~30 кейсов (калибровочных); баланс позитивных/негативных исходов примерно паритетный |
| **Экспертиза** | формулировки и докaзательсвта валидированы экспертом в области (сверхпроводимость) |

## 4. Что этот эталон даёт (и не даёт)

**Даёт:**
1. **Проверяемые исходы**, а не мнения: каждый ✅/❌ в таблице — это документируемое состояние
   технологии к 2026 (установки, рынок, закрытия);
2. **Паритет по классам** (~14 ✅ / ~12 ❌ / ~5 🔶): достаточный для проверки гипотез «что отличает
   взлетевших от не-взлетевших»;
3. **Информационный разрез 2018** — честная почва для backward-looking калибровки предикторов.

**НЕ даёт (честно):**
- Домен — сверхпроводимость (экспертная область автора), кодирование в произвольных областях
  проверяется отдельно (шаг 5);
- ~30 кейсов — мало для больших ML-моделей (см. шаг 3): отсюда решение «не ML, а синтез
  литературных гипотез, проверенных на этом эталоне»;
- Это калибровочный эталон, а не «обучающий датасет промышленного масштаба».
