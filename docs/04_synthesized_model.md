# 04_synthesized_model.md — Синтез собственной модели (Шаг 4)

## 1. Идея шага

У нас есть:
- **эталонный датасет** с известными исходами 2018→2026 (шаг 2) — калибровочная база №1;
- **корпус литературных гипотез** H1-H29 и ~90 источников (шаг 3).

Мы прогоняем каждую литературную гипотезу через эталон и смотрим, **какие отделяют «взлетевших»
от «не-взлетевших»**. Сильные стороны синтезируем в собственную модель, слабые — используем как
контр-сигналы или исключаем.

## 2. Таблица: литературный подход → поведение на эталоне → роль в нашей модели

| Литературный подход | Поведение на эталоне (СП-кейсы 2018→2026) | Роль в нашей модели |
|---|---|---|
| **Публикационный рост, абсолют** | слабо разделяет: растёт почти всё (SMES и «живые» темы показывают плато 20-40/год) | вспомогательный, не ядро |
| **Прирост ДОЛИ темы в классе (нормировка)** | **хорошо разделяет:** абсолют смещён к большим темам, доля ловит маленький взрывной тренд (урок BESS-он-долларе из кейса 005) | ⭐ **ядро этапа 1** → `growth_n` |
| **Новизна с birth-калибровкой** (возраст, затишье) | работает: возраст ≥20 лет без прорыва → гейт отсекает; «затишье >1 года сбрасывает birth» (кейс 011 SRF) | ⭐ ядро → `novelty_n` |
| **Цитируемость якорных работ** (impact) | работает: даже «старые-внедрённые» (IBAD) проходят через сильный цитатный якорь | ⭐ ядро → `impact_n` |
| **S2: семантическое смещение «открытие→инженерия»** | ⚠️ НЕ подтвердилось как универсальный сдвиг: инженерные темы «инженерные с рождения» (NI-coils); для IBAD сдвиг не в лексике «фундамент/прикладное», а в «уходе специфичной лексики» при созревании | флаг `s2_engineering_born`; переопределение «уход фокуса» — кандидат |
| **S3: кластеры цитирований «из ниоткуда»** | работает для `explosive` тем (flux pump), НЕ для `gradual` (NI-coils — устойчивое плато). Триплеты/глубина фундамента кодируют ТИП инновации | классифицировать профиль: explosive / gradual / burst_fade; «состоялся» = explosive ИЛИ gradual-с-плато |
| **S4: снятие физического/экономического предела** | **главный разделяющий принцип:** взлетают те, кто снимает предел, который конкурент не может (fusion-HTS, кубиты, SNSPD); не взлетают, когда конкурент дешевеет (SMES-BESS, RSFQ-CMOS, СП-машины) | ⭐ ядро этапа 2 (принцип S4/S5) |
| **S5: конкуренты от проблемы / взаимная цитируемость** | работает: конкуренция с дешевеющими альтернативами объясняет провалы | ⭐ ядро этапа 2 |
| **Конференционный сигнал** (не дубль pubs) | **ценен в другом слое:** conf отражает «живое сообщество»; показывает угасание на ~10 лет раньше публикаций (SMES: пик conf 2007→спад 2008, pubs «живы»); ловит смену школ (RCE→TLAG) и каналы провалов (закрытия докладов) | прокси «живого сообщества» в этапе 2 |
| **Гранты** | НЕ самостоятельный сигнал: гранты есть и у «сдувшихся» (EcoSwing €10.6M → 0 коммерции) | связка с S1-пересечением, не ядро |
| **Роадмапы (предсказания «что/когда»)** | **систематически переоценивают сроки в 2-3 раза** (Japan 2008, IEA 2017, SCENET 2006) | ИСТОЧНИК мотивации + конективный слой; не предиктор «когда» |
| **Простой vs сложный ML** | простые признаки ≈ сложные модели (Science4Cast baseline = 2-е место из 14) | обоснование лёгкого этапа 1 |

## 3. Синтезированная модель (двухэтапная)

### Этап 1 — Скрининг (быстрый, автоматизируемый, ~20 минут на область)

**Скор этапа 1 = `novelty_n × growth_n × impact_n`** (нормировки), где:
- `novelty_n` — новизна с birth-калибровкой (возраст + «затишье сбрасывает birth»); гейт возраста ≥20 лет;
- `growth_n` — **прирост ДОЛИ темы в классе**, а не абсолют (нормировка по классу/S5);
- `impact_n = 1 − exp(−x/40)` — цитируемость якорных работ (насыщение).

Порог t=0.10 (калибровка на 9 кейсах): **ошибка II рода = 0** (ни один реальный тренд не потерян),
**ошибка I рода = 2** (авиадвигатели, flux-pump-joint — ложные, их отбракует этап 2). Это
**доказательство замысла**, а не дефект: этап 1 сознательно широк (recall-first), этап 2 точечный.

### Этап 2 — Верификация (глубокий, дни, эксперт)

Для каждого кандидата из ТОП-15:
1. **Какую проблему решает** (формулировка потребности);
2. **Конкуренты, найденные от проблемы** (а не через перекрёстные ссылки) — S5;
3. **Взаимная цитируемость альтернатив**;
4. **S4-анализ:** снимает ли тема физический/экономический предел, который конкурент не может?
5. **Грантовый сигнал** (связка, не ядро);
6. **Сигнал IPO/M&A** (капитал, конверсия);
7. **Конференционный сигнал** (живое сообщество / смена школ / каналы провалов).

Даёт вердикт «состоялся / в развитии / не состоялся». Не автоматизируется полностью — требует эксперта для вынесения суждения.

## 4. Схема

```
┌─ Этап 1 (20 мин) ──────────────────────────────┐
│ запрос области → тематические кластеры        │
│ → novelty × growth(доля) × impact              │
│ → ТОП-15 кандидатов + объяснение + источники   │   ← лёгкий, ML-осн., recall-first
└────────────────────────────────────────────────┘
                   ↓
┌─ Этап 2 (дни, эксперт) ───────────────────────┐
│ проблема → S5-конкуренты → взаимная цитируем. │
│ → S4 (снят ли предел) → гранты → IPO/M&A → conf│
│ → вердикт «состоялся / в развитии / не состоялся│  ← тяжёлый, отсев хайпа/зрелого/шума
└────────────────────────────────────────────────┘
```

## 5. Что этой моделью доказываем

1. **Не изобрели формулу с нуля** — синтез литературных гипотез (шаг 3), проверенных на эталоне (шаг 2);
2. **Двухэтапность** — прямое следствие: то, что нельзя решить наукометрикой (отличить «снимает
   предел» от «проигрывает конкуренту»), решается верификацией;
3. **Проверяемость** — калибровка порога на известных исходах 2018→2026 с цифрами (ошибки I/II рода);
4. **Объяснимость** — каждый кандидат несёт предикторы (новизна/рост доли/импакт) + вердикт с
   обоснованием (что требует ТЗ §8.3 — интерпретируемость, отсев шума/хайпа/зрелого).
