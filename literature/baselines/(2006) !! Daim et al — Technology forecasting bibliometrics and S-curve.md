# (2006) Daim, Rueda, Martin — Technology Forecasting Using Bibliometric Analysis and System Dynamics

**Библиография:** T.U. Daim, G.R. Rueda, H.T. Martin. «Technology Forecasting Using Bibliometric Analysis and System Dynamics». PICMET 2006 / IEEE. Portland State University / Intel Corp.
**Релевантность:** 4/5 — методология библиометрии + **Fisher-Pry S-кривая подгонка** + патентные данные для прогноза. Прямой инструмент для фичи «стадия S-кривой» и для прогноза «когда взлёт».

---

## Суть работы
Прогноз технологий (кейсы: fuel cells, optical storage, RFID) через: (1) **библиометрию** (Science Citation Index + Business Elite, рост публикаций), (2) **S-кривую Fisher-Pry** подгонку к данным роста, (3) **патенты** как доп. индикатор, (4) **system dynamics** для сценариев. Ключевой вызов — определить **точку перегиба и асимптоту** S-кривой.

## Ключевые концепции
1. **Fisher-Pry:** `f(t) = 1/(1 + c·e^(−b·t))` — логистическая S-кривая; b — форма (скорость), c — положение (сдвиг по времени);
2. **Библиометрия = прокси роста технологии:** число публикаций по годам подгоняется S-кривой;
3. **Точка перегиба** (середина роста) и **асимптота** (насыщение) — главные неизвестные;
4. **Патентные данные** комбинируются с публикациями (наш S1-перекрёст!);
5. **System dynamics** — моделирование сценариев (не только экстраполяция).

## Значимость для проекта (фичи + гипотезы)

### Фичи для предиктивной модели
| Фича | Что даёт | Наш аналог |
|---|---|---|
| **Fisher-Pry fit (b, c)** | Количественная стадия S-кривой: b (скорость) и c (сдвиг) по публикациям | Формализация S1a/S3-фаз: вместо ручного «взлёт/плато» — параметры кривой |
| **Inflection point** | Год перегиба = «середина роста»; до перегиба = ранняя стадия | Ключ для «зарождающийся ли в 2018?» |
| **Publications × patents** | Комбинирование баз (перекрёстный сигнал) | Наш S1-принцип (пересечение баз) — статья даёт формальный метод |

### Гипотезы для проверки на кейсах
- **H-D06-1 (перегиб = маркер):** если публикации кейса в 2018 были ДО точки перегиба Fisher-Pry (ранняя половина S-кривой) — «зарождающийся»; после — зрелый/поздний. Проверка: подогнать Fisher-Pry к S1a-данным кейсов 003-006 → сравнить позицию 2018 относительно перегиба с меткой 2026;
- **H-D06-2 (b = скорость):** высокий b (крутая S-кривая) = быстрая диффузия = выше шанс «состоялся к 2026». SNSPD (крутой рост) vs SMES (пологое плато) — предсказание согласуется;
- **H-D06-3 (публикации vs патенты расхождение):** если публикации на S-кривой, а патенты отстают/опережают — диагностика стадии (академия vs индустрия). Проверка: кейс 006 (патенты с пиком 2019-20 vs публикации с ростом до 2025) — расхождение указывает на фазу.

## Замечания
- PICMET (инженерный менеджмент), кейсы не-физика;
- Fisher-Pry проще Bass (нет аналога-параметров), но требует выбора окна;
- Перекликается с нашим наблюдением: SMES = «насыщение/плато» S-кривой ещё в 2000-е (задним числом), SNSPD = «ранний взлёт» в 2018.
