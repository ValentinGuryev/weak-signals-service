# (2009) Daim & Suntharasaj — Technology diffusion: forecasting with bibliometric analysis and Bass model

**Файл:** `(2009) !! Daim, Suntharasaj — Technology diffusion bibliometric and Bass model.pdf`
**Библиография:** T. Daim, P. Suntharasaj. «Technology diffusion: forecasting with bibliometric analysis and Bass model». Foresight 11 (2009). DOI: 10.1108/14636680910963936. Portland State University.
**Релевантность:** 4/5 — **Bass model диффузии** для прогноза внедрения технологии по библиометрии + аналоги. Прямой инструмент для фичи «стадия диффузии» и проверки «сколько лет до внедрения».

---

## Суть работы
Прогноз внедрения **RFID** в US-ритейле через: (1) **библиометрический анализ** (публикации), (2) **Bass model диффузии** на основе **аналога** (внедрение barcode-сканера как модель для RFID). Вывод: ритейлерам нужно 7-8 лет на внедрение RFID.

## Ключевые концепции
1. **Bass model:** диффузия инновации описывается S-кривой: `n(t) = p·[m - N(t)] + q·(N(t)/m)·[m - N(t)]`, где p = коэффициент инновации (ранние последователи), q = коэффициент имитации (подражание), m = рынок;
2. **Библиометрия как прокси стадии:** число публикаций по годам → где на S-кривой технология;
3. **Аналоговый подход:** для новой технологии (нет данных о внедрении) берут диффузию АНАЛОГА (barcode ~ RFID) — переносят p/q;
4. Сравнение результатов библиометрии и Bass — «новая дискуссия».

## Значимость для проекта (фичи + гипотезы)

### Фичи для предиктивной модели
| Фича | Что даёт | Наш аналог |
|---|---|---|
| **S-curve position (по публикациям)** | Публикации как прокси: где технология на S-кривой (ранняя/взлёт/насыщение) | Согласуется с S1a/S3 (фазы) |
| **Bass p/q (по аналогу)** | Оценка скорости диффузии ДО данных о внедрении | Новая фича: «скорость диффузии по аналогу» |
| **Time-to-adoption** | Прогноз «сколько лет до рынка» | Для верификации «состоялся к 2026?» |

### Гипотезы для проверки на кейсах
- **H-D1 (S-кривая по публикациям):** технология, чьи публикации в 2018 были на «раннем взлёте» S-кривой (растущая вторая производная), состоялась к 2026; «насыщение/плато» — нет. Проверка: наши кейсы с фазами (004 NI, 006 SNSPD — взлёт; 005 SMES — плато) — уже согласуется, формализовать через Bass-подгонку;
- **H-D2 (аналог):** можно предсказать диффузию SNSPD по аналогу (InGaAs SPAD? PMT?) — но аналог надо выбирать осторожно (наш урок: Li-ion для SMES был неверным аналогом в 2000-е, никто не ждал падения цены ×97%);
- **H-D3 (данные о внедрении):** библиометрия отражает НАУЧНУЮ диффузию, Bass — РЫНОЧНУЮ; расхождение = где технология буксует (SMES: наука была, рынка нет) — двухкривая диагностика.

## Замечания
- Кейс RFID/ритейл (не наука), но метод переносим;
- Аналоговый подход — сила И слабость (наш контрпример: Li-ion для SMES);
- 7-8 лет на внедрение — согласуется с нашим наблюдением «роадмапы переоценивают скорость в 2-3 раза» (Bass-оценка реалистичнее экспертной).
