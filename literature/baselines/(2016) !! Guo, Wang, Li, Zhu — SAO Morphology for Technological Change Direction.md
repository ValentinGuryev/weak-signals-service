# (2016) !! Guo, Wang, Li, Zhu — SAO Morphology for Technological Change Direction

## Метаданные
- **Авторы:** Junfang Guo, Xuefeng Wang, Qianrui Li, Donghua Zhu
- **Год:** 2016
- **Источник:** Technological Forecasting & Social Change 105, 27–40
- **DOI:** 10.1016/j.techfore.2016.01.028
- **Тип:** SAO-морфология для определения направления технологических изменений

## Резюме (релевантность 4/5)
Работа предлагает **морфологический анализ на основе структур «субъект–действие–объект» (SAO)**
для определения **направления технологических изменений**. SAO-структуры извлекаются из текстов
(патентов/публикаций) и рассматриваются как функциональные триплеты.

Ключевые идеи:
- **SAO-триплет:** субъект (Subject) выполняет действие (Action) над объектом (Object) — структурно
  кодирует технологическую функцию/взаимодействие.
- **Морфология SAO** = анализ набора SAO-структур во времени → выявление направлений, в которых
  технология развивается (какие функции добавляются/меняются).
- В отличие от «мешка слов» (co-word/частот), SAO учитывает **структуру/семантику** связи, а не просто
  совместную встречаемость.
- Применяется для определения направления технологического изменения (direction of change) —
  куда движется технология.

## Ценность для нашего проекта
- **Структурная семантика = аналог/усиление нашего S2 (wordshift):** SAO-подход — более богатый вариант
  семантического анализа направления изменений (наши термин-сдвиги — упрощение SAO).
- Потенциальная фича для S2: вместо простых wordshift использовать SAO-структуры для детекции смены
  функций технологии (кейс 011: поверхностное сопротивление → покрытие/плёнка).
- Сравнение «структурная vs статистическая семантика» — для related work.

## Связь с другими работами
- Семантика: наш wordshift (S2), Leydesdorff-Nerghes 2016 (co-word vs topic modeling).
- Технологическое изменение: Strumsky-Lobo 2015 (патентная новизна), Cozzens 2010.

## Итоговая оценка
**4/5** — структурно-семантический метод определения направления изменений; усиление нашего S2.
