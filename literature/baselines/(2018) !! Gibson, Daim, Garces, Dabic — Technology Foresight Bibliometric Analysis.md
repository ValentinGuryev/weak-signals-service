## Суть работы

Закрытие пробела: нет фреймворка выбора методов форсайта в зависимости от целей исследования. Авторы анализируют школы мысли и обновляют список инструментов форсайта.

Метод: text/data mining + **Social Network Analysis (SNA)** — выявление ведущих журналов, статей, исследователей; поиск по 3 индексам (SCI-Expanded, SSCI, Conference Proceedings). Построен **трёхфазный фреймворк** выбора методов; для карты методов — 5 критериев.

## Ключевые результаты

1. **Three-phase framework** (по Horton 1999): pre-foresight → foresight → post-foresight; в каждую фазу — релевантные методы/инструменты;
2. Карта ведущих журналов/авторов поля форсайта (SNA-картирование);
3. Пять критериев для выбора методов (включая цель исследования, доступные данные, ресурсы);
4. Обновлённый список «самых современных» методов (2018): библиометрия, scientometrics, text mining, roadmapping, экспертные методы и т.д.;
5. Прямой вывод: выбор метода зависит от фазы и целей, единого «лучшего» метода нет.

## Выводы авторов

- Фреймворк — практическое руководство для policy makers и исследователей при планировании форсайт-исследования;
- Поле форсайта фрагментировано: методы живут в разных школах/журналах.

## Значимость для кейса/проекта

- **Обоснование нашего выбора методов в статье:** мы можем позиционировать наш пайплайн внутри их трёхфазной схемы (инпут — библиометрия/текст-майнинг, аутпут — ранжированные кандидаты);
- В related work: систематический обзор методов форсайта (2018) — связка с wishlist-задачей «замена Glass et al.»;
- Критерии выбора (данные/ресурсы/цель) — полезны при формулировке нашего метода.
