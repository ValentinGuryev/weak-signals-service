## Суть работы (2–3 предложения)

Обзорная глава, описывающая **инновационный фреймворк** для детекции, анализа и прогнозирования научных тем на основе **Scientific Knowledge Graphs (SKG)** и **Computer Science Ontology (CSO)**. Показано, как аннотировать статьи темами CSO через CSO Classifier, строить граф AIDA (академия/индустрия), и как на нём работают инструменты анализа (ResearchFlow, AIDA Dashboard, EDAM) и прогнозирования (Augur — возникновение тем; ResearchFlow forecaster — влияние тем на индустрию; Technology-Topic Framework — какие технологии будут приняты).

## 1. Введение

- Анализ исследовательских трендов и прогноз их влияния на академию/индустрию критически важен для понимания развития полей и решений о финансировании и внедрении технологий.
- Появление больших публичных **Scientific Knowledge Graphs (SKG)** стимулировало data-driven подходы к количественному анализу трендов.
- **Три задачи:** (i) детекция тем, (ii) наукометрический анализ, (iii) прогноз трендов.
- Фреймворк: классификация статей по темам CSO (тематические модели или классификаторы); анализ библиометрик во времени; supervised/unsupervised форкастеры.

## 3. Фреймворк: SKG, CSO, CSO Classifier, AIDA

### 3.1 Computer Science Ontology (CSO)
- Крупномасштабная онтология исследовательских областей CS, **автоматически сгенерированная Klink-2** на датасете **16 млн публикаций** (в основном CS).
- По сравнению с ACM CCS: гораздо больше тем, гранулярнее, легко обновляется (перезапуск Klink-2 на новых корпусах).
- **Текущая версия: 14 тысяч семантических тем и 159 тысяч отношений.** Главный корень — Computer Science; доп. корни: Linguistics, Geometry, Semantics и др.
- **Модель данных — расширение SKOS**, 4 главных отношения:
  - **superTopicOf** — тема является супер-областью другой (Semantic Web ⊃ Linked Data);
  - **relatedEquivalent** — темы эквивалентны для исследовательских данных (Ontology Matching ≡ Ontology Mapping);
  - **contributesTo** — исследовательский выход одной темы вносит вклад в другую;
  - **owl:sameAs** — концепт идентичен внешнему ресурсу (DBpedia).
- Доступ: **CSO Portal** (cso.kmi.open.ac.uk) — скачивание, исследование, визуализация, обратная связь (рейтинги тем/отношений, предложение отсутствующих связей).
- Принята Springer Nature (Smart Topic Miner для классификации proceedings, Smart Book Recommender). Поддерживает: ontology-driven topic models (CoCoNoW), рекомендательные системы (SBR, видео-уроки), детекцию исследовательских сообществ (TST, RCMB), визуализации (ScholarLensViz, ConceptScope), temporal KGs (TGK), NLP entity extraction, KG embeddings (Trans4E), поиск экспертов (VeTo), прогноз импакта (ArtSim), прогноз тем (Augur), прогноз концептов (SIM, POE), прогноз технологий (TTF, TechMiner). Крупномасштабные анализы: Cloud Computing, Software Engineering, эквадорские публикации.

### 3.2 CSO Classifier
- Инструмент автоматической классификации статей по CSO. Вход: title, abstract, keywords → набор концептов CSO.
- **Три шага:**
  1. **Синтаксический модуль:** поиск всех тем, явно упомянутых в статье; разбиение текста на униграммы/биграммы/триграммы; сравнение с метками CSO через **Levenshtein similarity**; возврат тем со схожестью ≥ порога.
  2. **Семантический модуль:** part-of-speech tagging (кандидаты: комбинации существительных и прилагательных), **Word2Vec** (обучен на title+abstract **4.6 млн англоязычных публикаций CS из MAG**; параметры: skipgram, embedding-size 128, window-size 10, min-count-cutoff 10, max-iterations 5). n-граммы «склеиваются» подчёркиванием («semantic_web»); если слова нет в словаре — среднее эмбеддингов токенов. **Relevance score = frequency × diversity** (число идентификаций × число уникальных n-грамм, приведших к теме). Отбор тем — **elbow method**.
  3. **Пост-обработка:** обогащение супер-темами CSO (статья «neural network» → также «machine learning», «artificial intelligence»).
- Установка: `pip install cso-classifier`; GitHub: angelosalatino/cso-classifier.

### 3.3 AIDA Knowledge Graph (Academia/Industry DynAmics)
- **21 млн публикаций и 8 млн патентов**, описанных темами CSO. **5.1 млн публикаций и 5.6 млн патентов** — по типу аффилиации (academia/industry) и **66 промышленным секторам** (двухуровневая таксономия).
- **Пайплайн из 3 фаз:** (i) извлечение тем (CSO Classifier); (ii) извлечение типов аффилиаций; (iii) классификация промышленных секторов.
- **Типы аффилиаций:** через **GRID** (открытая БД, >90 тыс. организаций; типы: education, company, government и др.). Документ = «academic», если ВСЕ авторы имеют образовательную аффилиацию; «industrial», если все промышленную; смешанные — «collaborative».
- **INDUSO (Industrial Sectors Ontology):** 66 секторов в двухуровневой иерархии (27 первого уровня, 39 второго). Построена из GRID → Wikipedia → DBpedia (свойства About:Purpose, About:Industry) → маппинг на INDUSO.
- **Таблица 1 (распределение):** всего публикаций 20 850 710, с GRID ID 5 133 171; Academia 3 585 060 (69.8% с GRID), Industry 787 151 (15.3%), Collaborative 133 781 (2.6%). Патенты: всего 7 940 034, с GRID ID 5 639 252; Academia 133 604 (2.3%), Industry 4 741 695 (**84%**), Collaborative 16 335 (0.2%).
- **Семантические отношения:** hasTopic (темы CSO), hasAffiliationType/hasAssigneeType (academia/industry/collaborative), hasIndustrialSector (INDUSO).
- Data model: http://aida.kmi.open.ac.uk/ontology; дамп в Turtle: http://aida.kmi.open.ac.uk/downloads.

## 4. Анализ трендов

### 4.1 EDAM (Expert-Driven Automatic Methodology) для систематических обзоров
- Методология создания систематических обзоров: (i) характеристика области онтологией тем; (ii) уточнение онтологии экспертами; (iii) классификация статей и аналитика.
- Авторы обзора контролируют онтологическую схему.
- **Workflow:** определение research questions → выбор источников → создание/переиспользование онтологии (методы: статистические таксономии из ключевых слов; NLP — FRED, LODifier, Text2Onto; deep learning — RNN; специфические — Klink-2) → уточнение экспертами → критерии включения (по онтологии + метаданные: год, площадка, язык) → аналитика.
- **Пример 1 — Semantic Web:** сравнение главных веню (ISWC, ESWC, SEMANTiCS, SWJ, JWS) и 32 431 публикаций Scopus. Аннотация по CSO; ассоциация статей с темой, если title/abstract/keywords содержат: метку темы, relatedEquivalent, skos:broaderGeneric, или relatedEquivalent broaderGeneric. Результат: **угасание Semantic Web Services, быстрый рост Linked Data после релиза DBpedia (2007)** — подтверждено экспертами.
- **Пример 2 — IJHCS 50 лет:** сравнение с CHI; анализ растущих тем по числу статей 2009–2013 vs 2014–2018; география тем (Япония 7-я в CHI в целом, но 3-я в Robotics; Южная Корея 12-я/10-я в IJHCS/CHI, но 4-я/6-я в Computer Security).

### 4.2 ResearchFlow (анализ трендов академия/индустрия)
- Эволюция тем CSO через **4 временных ряда:** (i) статьи академии, (ii) статьи индустрии, (iii) патенты академии, (iv) патенты индустрии.
- Возможности: (i) диахронное поведение тем (траектория академия/индустрия); (ii) сравнение пар сигналов (кто обычно раньше); (iii) корреляция сигналов с учётом временной задержки.
- **Рис. 7:** распределение 5 000 частых тем по индексам academia-industry (x) и papers-patents (y). Темы тесно вокруг биссектрисы: академические → публикации (верхний правый квадрант); индустриальные → патенты (нижний левый).
- **Временные задержки (важно):** тема «появилась» = ≥10 документов. **89.8% тем впервые появляются в академических публикациях; 3.0% — в индустриальных публикациях; 7.2% — в индустриальных патентах; 0% — в академических патентах.** В среднем: академические публикации опережают индустриальные на **5.6 ± 5.6 лет**; индустриальные публикации опережают индустриальные патенты на **1.0 ± 5.8 лет**; академические публикации опережают индустриальные патенты на **6.7 ± 7.4 лет**.

### 4.3 AIDA Dashboard
- Веб-приложение для анализа конференций (совместно со Springer Nature). Три новые фичи: (1) сравнение конференций в полях (Digital Libraries) и временных окнах (5 лет); (2) характеристика по 14K темам CSO; (3) вовлечённость индустрии (66 секторов INDUSO; коммерческие организации; соотношение академия/индустрия/коллаборации).
- **8 вкладок:** Overview, Citation Analysis, Organisations, Countries, Authors, Topics, Related Conferences, Industry.
- Пример: Overview ISWC — производительность, главные авторы/организации, ранг в полях по средним цитированиям за 5 лет.

## 5. Прогноз трендов

### 5.1 Augur (прогноз возникновения тем)
- Метод на основе **сетей тем**: fully weighted граф; узлы = темы, рёбра = ко-встречаемость в ≥1 статье; веса узлов = число статей с темой; веса рёбер = число статей с парой тем. Оригинал — на Rexplore dataset через CSO.
- **Вход:** 5 сетей тем за 5 последовательных лет. **Advanced Clique Percolation Method (ACPM)** — кластеризация групп тем, интенсифицирующих темп коллаборации. Кластеры = участки, «вынашивающие» темы следующих лет.
- **Золотой стандарт:** 1 408 emerging-трендов (2000–2011); каждый связан со списком тем-«предков». Оценка: можно ли сопоставить кластеры Augur с «предками» emerging-трендов.
- **Таблица 2 (precision/recall по годам, 5 подходов: FG, LE, FCM, CPM, ACPM):** Augur (ACPM) превосходит альтернативы по precision и recall во все годы (например, 1999: P 0.86/R 0.76; 2000: 0.78/0.70; 2001: 0.77/0.72; 2002: 0.82/0.80; 2003: 0.83/0.79; 2004: 0.84/0.68; 2005: 0.71/0.66; 2006: 0.43/0.51; 2007: 0.28/0.44; 2008: 0.15/0.33; 2009: 0.09/0.76). Альтернативы — в основном ~0.

### 5.2 ResearchFlow forecaster (влияние тем на индустрию)
- Мера влияния: число **патентов, выданных компаниям**. Гипотеза: AIDA (публикации+патенты+происхождение) даёт более богатые фичи, чем только патенты.
- **Золотой стандарт:** для каждой темы CSO — все 5-летние окна, в которых тема ещё не возникла (<10 патентов). Метка True, если тема произвела >50 промышленных патентов в следующие 10 лет. **9 776 размеченных образцов**, 4 временных ряда: RA (статьи академии), RI (статьи индустрии), PA (патенты академии), PI (патенты индустрии).
- **5 классификаторов** (LR, RF, AB, CNN, LSTM) на 17 комбинациях рядов; 10-fold CV; метрики P/R/F1.
- **Таблица 3 (ключевые результаты):** LSTM лучший — высший F1 для 12/17 комбинаций, высший средний F1 (73.7%); CNN (72.8%), AB (72.3%).
  - RA: LR 55.2, RF 59.2, AB 61.9, CNN 65.0, **LSTM 64.6** F1.
  - RI: 74.4 / 74.0 / 76.4 / 77.0 / **76.9**.
  - PA: 24.2 / 24.5 / 25.2 / 24.9 / 24.8 (низко — редкие академические патенты).
  - PI: 72.5 / 71.0 / 73.6 / 75.0 / **75.2**.
  - RA-RI: 77.6 / 78.2 / 79.5 / 76.8 / **80.7**.
  - RA-RI-PI: 82.5 / 82.4 / 82.9 / **84.2** / 84.7.
  - RA-RI-PA-PI: 82.5 / 81.8 / 82.9 / 82.9 / **84.6** (лучший).
- **Выводы:** полный набор фич AIDA (разбитый на ряды) значительно превосходит только число патентов компаний (F1 **84.6% vs 75.2%**). Учёт происхождения (академия/индустрия) повышает: RA-RI (80.7%) > R (68.2%); PA-PI (75.2%) > P (74.8%).

### 5.3 Technology-Topic Framework (TTF) — прогноз распространения технологий
- Гипотеза: технологии со схожими паттернами распространения по темам будут приняты схожими темами.
- **Вход:** (i) 16 млн статей (1990–2013, CS; title/abstract/keywords); (ii) **1 118 технологий** (автоизвлечение из аннотаций + KB (DBpedia), ручная курация; ≥10 релевантных публикаций); (iii) **173 темы CSO**.
- **3D матрица ко-встречаемости** технология×тема×год → обучение классификатора на недавней истории технологии → прогноз будущего курса.
- **Random Forest лучший:** precision **74.4%**, recall **47.7%** (лучше LR, Decision Tree, Gradient Boosting, SVM, простой NN).
- **Таблица 4 (RF на топ-24 темах, F1):** information retrieval 77.6, database systems 73.3, world wide web 68.7, artificial intelligence 66.5, computer architecture 65.7, computer networks 65.2, image coding 63.2, P2P networks 61.9, telecom traffic 57.3, wireless telecom systems 57.1, sensors 56.2, web services 56.0, wireless networks 55.0, sensor networks 54.3, software engineering 54.2, distributed comp systems 54.0, quality of service 53.5, imaging systems 52.8, data mining 52.0, computer vision 51.8, programming languages 51.2, problem solving 50.4, semantic web 50.2, image quality 50.0.
- Лучшие результаты — на темах с большим числом публикаций/технологий (IR, Databases) и когерентным набором технологий (Computer Networks, Sensors, P2P).

## Релевантность проекту

**5/5** — самая близкая работа к нашему проекту:
- **AIDA/CSO** — готовая альтернатива BERTopic для этапа 2 (онтологическая классификация вместо вероятностной). CSO Classifier доступен через pip.
- **Augur** — прямое продолжение идеи Salatino 2018: сеть тем + темп коллаборации как предиктор возникновения. Обоснование для нашего **графа связей на этапе 5** и потенциального расширения Score.
- **ResearchFlow forecaster (LSTM, F1 84.6%)** — образец, как прогнозировать влияние тем (для нас — этап 3+).
- **Временные задержки (5.6 лет академия→индустрия)** — для нашей методологии: фокус на arXiv (академия) достаточен для раннего выявления; индустриальные патентные сигналы приходят с лагом ~6 лет.
- **TTF (RF 74.4/47.7)** — образец прогноза распространения технологий.
- **EDAM + эксперты** — методология систематических обзоров; релевантна нашему этапу 4 (карточки с экспертной валидацией).
