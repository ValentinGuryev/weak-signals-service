## Суть работы

Многослойный количественный подход для выявления **слабых сигналов зарождающихся технологий** по научным публикациям, с использованием **BERT-экстракции ключевых слов** и **weak signal analysis**. Кейс: гиперзвук (hypersonics), 21 590 публикаций Scopus за 1985–2020.

## Ключевые результаты

### Концепция слабого сигнала
- Слабое определение Ansoff (1970-е), Coffman (1997): слабый сигнал = новый, трудно отслеживаемый, требует времени до зрелости, угроза ИЛИ возможность.
- **Hiltunen (2008) — 3 измерения future signs:** signal (видимость), issue (диффузия), interpretation (смысл). Слабый сигнал = низкие все три → может стать сильным.
- **Yoon (2012) — количественная операционализация:** слабый сигнал = **низкая частота термина + высокая скорость роста**; сильный = высокая частота + высокий рост.

### Методика (пайплайн)
1. **Данные:** Scopus, запрос «hypersonic*», 1985–2020, n=21 590 после дедупликации. Окна по **3 года** (t1–t12) — оптимальный интервал.
2. **Ключевые слова:** BERT (трансформер) для документ-представлений, косинусная близость n-граммов → 500 ключевых слов на окно (6 000 всего), после чистки 4 366 уникальных.
3. **Degree of Visibility (DoV):** `DoV = (TF/N) * (1 - w*(n-j))`, w=0.05 — частотная формула с временным весом.
4. **Degree of Diffusion (DoD):** то же на document frequency.
5. **Карты KEM (Keyword Emergence Map) и KIM (Keyword Issue Map):** оси «частота × рост»; 4 квадранта: сильные (выс/выс), **слабые (низ/выс)**, латентные (низ/низ), известные-но-не-сильные (выс/низ).
6. **Пересечение KEM∩KIM:** сигнал = термин в одном квадранте на обеих картах.
7. **Экспертная валидация:** 442 сигнала проверены сеньор-учёными, разбиты на 5 категорий (аэротермодинамика, материалы и структуры, наведение/управление, моделирование, движители/топлива).

### Эволюция сигналов
- Бipartite-граф «время × ключевые слова» + **Louvain-модулярность** → 8 сообществ = подтверждение временной эволюции.
- Категории слабых vs сильных сигналов меняются по периодам; слабые сигналы «моделирования/анализа» росли от P1 к P3.

## Выводы авторов
- Подход end-to-end, модульный, переносимый на другие домены и источники данных.
- BERT-ключевые слова лучше статистических (TF/TF-IDF) — меньше шума.
- Weak signal analysis + DL = быстрые масштабные количественные оценки, дополняющие экспертов.

## Значимость для кейса/проекта
- **Прямой аналог нашей задачи** (слабые сигналы зарождающихся технологий по публикациям).
- Операционализация: **«слабый сигнал = низкая частота + высокий рост»** — готовая фича для нашего пайплайна (GrowthRate + Novelty).
- 3-летние окна — референс для агрегации по кварталам/годам.
- KEM/KIM-квадранты — готовая визуализация «слабый/сильный/латентный» для дашборда.
- Ограничение: один источник (Scopus), без пересечения баз — наш мульти-базовый подход (S1) строже.
