## Суть работы (2–3 предложения)
Статья предлагает метод выявления и прогнозирования трендов «разрушающих» (disruptive) технологий на основе **патентных данных**: улучшенная модель **LDA2Vec** (комбинация LDA-тем и Word2Vec-эмбеддингов с TF-IDF-взвешиванием и K-means кластеризацией) идентифицирует технологические темы, три индикатора (новизна, технологический прорыв, потенциальный научный вклад) ранжируют их по «разрушающему» потенциалу, а **ARIMA** прогнозирует тренд каждой темы. Применено к энергетическим технологиям Китая (патенты 2012–2021), выделено 10 разрушающих технологий; результаты подтверждены экспертами и документальной проверкой.

## Ключевые результаты (все значимые числа)

### Метод (5 шагов)
1. **Сбор данных:** патентные аннотации, 2012–2021, энергетический сектор Китая (China Intellectual Property Network). Поисковый запрос SU=(energy + варианты) → **124 129 патентов**.
2. **Очистка:** токенизация (NLTK), стоп-слова, стемминг, спецсловарь для терминов энергетики («smart grid», «integrated energy service»), стоп-слова типа «the present invention».
3. **LDA2Vec:** LDA-темы (Gensim) + Word2Vec (Skip-gram) + TF-IDF-взвешивание → конкатенация → **fused feature vector** → K-means кластеризация. Оптимум числа тем: **30** (пик coherence, низкая perplexity).
4. **Индикаторы разрушающей технологии** (нормализованы, формула DT = α·NI + β·B + χ·R):
   - **Новизна (NI):** NI = 1/(t − FY + 1), где FY — первый год появления темы; убывает со временем.
   - **Технологический прорыв (B):** разнообразие патентных цитирований (по OECD): B = Σ(CTi/np), где CTi — число разных IPC-классов, цитирующих патент i, np — число IPC в backward-ссылках.
   - **Потенциальный научный вклад (R):** взвешенная экспертная оценка R = Σ(sij·rij)/Σ(sij).
   - **Веса:** α=0.25, β=0.40, χ=0.35 (подобраны экспериментально, минимум шума). Порог **DT > 0.9** → разрушающая технология.
5. **ARIMA-прогноз:** тренд темы (годовая вероятность темы) → стационаризация (d=1) → ACF/PACF → BIC для (p,q). Для Topic 4 оптимум ARIMA(0,1,1).

### Сравнение моделей (10-fold cross-validation)
| Модель | Precision | Recall | **F1** |
|---|---|---|---|
| LDA | 72.3 | 75.9 | **74.1** |
| LDA2Vec | 82.1 | 85.3 | **83.7** |
| **Improved LDA2Vec** (предложенная) | **87.4** | **89.6** | **88.5** |

Улучшенная модель LDA2Vec даёт **+14.4 п.п. F1** над чистым LDA.

## Инсайты и выводы авторов
1. **Тренд = тема + временной ряд.** Стабильный временной ряд темы (годовая вероятность из LDA) — ключ к применимости ARIMA; метод извлекает «объективный» ряд из модели, а не из частоты ключевых слов.
2. **Пересечение индикаторов важнее одного.** Три индикатора (новизна + прорыв + вклад) вместе дают меньше шума, чем по отдельности.
3. **Политика/рынок влияют на тренды.** Solar PV, offshore wind растут из-за гос. политики; nuclear и biomass сдерживаются политикой/рынком — прогноз не должен игнорировать внешние факторы.
4. **Ограничения:** только ARIMA (ML/DL/ансамбли — будущее), тема-модель чувствительна к параметрам, прогноз — не гарантия (реальность зависит от политики/рынка/прорывов).
5. **Будущее:** ML/DL/ансамблевые прогнозы, эволюционные механизмы тем (связи между темами, эволюционные пути).

## Релевантность проекту: **4/5**

**Почему полезна (сильные стороны):**
- **Прямо по теме хакатона:** выявление зарождающихся/разрушающих технологий + прогноз тренда — ровно наша задача (мы: emergence Score; они: disruptive DT + ARIMA).
- **Патентная база:** наш проект сейчас расширяется на мульти-базу (Google Patents) — эта статья показывает рабочий патентный пайплайн (LDA2Vec + индикаторы + ARIMA).
- **Индикатор «технологический прорыв» (B)** — разнообразие IPC-классов в цитированиях — совпадает с нашим подходом по патентам (рекомбинация IPC-классов, Dahlin 2005 / Grashof 2023). Это внешнее подтверждение.
- **Числа сравнения моделей** (LDA 74.1 → LDA2Vec 88.5 F1) — аргумент, что гибрид темы+эмбеддинги работает лучше чистого LDA (наш BERTopic-путь аналогичен).
- **Совпадение DT-порога с нашим Score:** они используют взвешенную сумму 3 индикаторов (α·NI + β·B + χ·R) с порогом — структура как у нашего EmergenceScore (α·Growth + β·Novelty + γ·Acceleration).

**Ограничения (почему не 5/5):**
- **Другая область** (энергетика, не сверхпроводимость) — методология общая, но результаты не переносимы напрямую.
- **ARIMA — простой прогноз**, наш подход (Score + бэктест) методологически глубже.
- **Экспертная оценка (R)** требует экспертов — у нас экспертный контур тоже есть (автор).
- Нет открытого кода/данных (в отличие от Impact4Cast) — только метод.

**Что можно переиспользовать:**
- Концепцию «временной ряд темы из модели + ARIMA/прогноз» как **дополнительный бейзлайн** к нашему Score (прогноз на будущее, а не только ранжирование).
- Индикатор B (IPC-разнообразие цитирований) — уже учтён в патентном слое.
- Числа сравнения моделей — для методологического обоснования в отчёте/README.

**Связь с нашей методологией:** статья подтверждает триаду «новизна + рост + влияние» (Rotolo et al. 2015), которую реализует наш Score. Их DT-формула — аналог нашего EmergenceScore, но на патентах и с прогнозом ARIMA вместо бэктеста.
