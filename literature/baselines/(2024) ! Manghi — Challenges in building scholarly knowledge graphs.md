## Суть работы (2–3 предложения)

Работа описывает **препятствия при построении научных графов знаний (Scholarly Knowledge Graphs, SKG)** для оценки исследований в условиях открытой науки, на основе опыта **OpenAIRE Graph**. Показано, что открытая наука вводит новые типы продуктов (данные, ПО) как «полноправных граждан», но текущие паблишерские процессы не гарантируют аутентичность и качество метаданных, необходимых для оценки. Цель — идентифицировать барьеры и предложить рекомендации, где SKG становится «осью» обмена информацией.

---

## Ключевые результаты

### Проблемы (источники вызовов)
1. **«Какие продукты считать»** — открытая наука: публикации, данные, ПО, препринты. Нет единого стандарта.
2. **Метаданные низкого качества** — паблишерские процессы не поддерживают аутентичность продуктов и качество метаданных (обязательно для оценки).
3. **Гетерогенность** — тысячи источников (OpenDOAR registry), разные форматы метаданных → нужны кроссволки (crosswalks) между форматами.
4. **Идентификация** — учёные не всегда используют авторитетные идентификаторы (требуется «human in the loop»).
5. **Интероперабельность** — разные словари типов ресурсов, сложность поддержки эволюции графа (особенно кросс-дисциплинарно).
6. **Юридические/технические барьеры** — при сборе метаданных.

### Рекомендации
- SKG как **центр обмена информацией** между стейкхолдерами (учёные, организации, провайдеры данных, провайдеры SKG).
- Рекомендации по метаданным для разных типов продуктов (например, codemeta/CFF файлы в репозиториях ПО для атрибуции).

## Релевантность проекту

**3/5** — справочно, по инфраструктуре данных:
- **Полезно для нашего этапа 1 (данные):** понимание проблем качества метаданных и гетерогенности источников — предостережение при работе с arXiv API (нужна чистка, дедупликация).
- **SKG (OpenAIRE Graph)** — потенциальный дополнительный источник данных для будущих итераций (цитирования, исследовательское ПО, данные).
- Не про «зарождаемость» напрямую — про инфраструктуру.
