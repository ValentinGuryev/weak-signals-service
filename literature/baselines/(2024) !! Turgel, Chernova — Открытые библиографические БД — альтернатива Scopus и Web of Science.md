## Суть работы

В условиях потери российскими учёными доступа к Scopus и WoS авторы оценивают, могут ли открытые библиографические базы заменить их для задач научно-образовательной политики и исследований.

Методология: контент-анализ литературы о базах + сравнительный анализ РИНЦ, AMiner, **The Lens**, **Dimensions**, **OpenAlex** по критериям: объём контента, охватываемый период, фильтры, визуализация, выгрузка данных, доп. возможности.

## Ключевые результаты

1. Открытые базы проанализированы по единым критериям; даны характеристики каждой (включая две, которыми пользуемся мы: Lens и OpenAlex);
2. **Вывод: открытые базы могут полностью заменить Scopus/WoS** для задач «определения фронтиров мировой науки» и для самих исследований;
3. **Исключение:** для стадии **оценки научных результатов государством** альтернативы Scopus/WoS пока нет;
4. Предложен план формирования программы исследования предметной области на открытых базах.

## Выводы авторов

- Для исследовательских и фронтирных задач открытые базы достаточны;
- Ограничение — наукометрическая оценка (гос. решения) требует аккуратности с любым аналогом.

## Значимость для кейса/проекта

- **Внешнее подтверждение нашего стека:** OpenAlex и Lens признаются полноценной заменой коммерческих индексов для задач типа нашей (frontier detection);
