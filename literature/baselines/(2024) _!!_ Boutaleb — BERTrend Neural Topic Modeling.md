## Суть работы
**BERTrend** — метод выявления зарождающихся трендов и слабых сигналов в больших эволюционирующих текстовых корпусах через **нейронное тематическое моделирование в онлайн-режиме** (BERTopic по временным окнам). Новая метрика популярности темы учитывает **и число документов, и частоту обновления**. Классифицирует темы как **шум / слабый сигнал / сильный сигнал**.

## Ключевые результаты (метод)
1. **Онлайн-тематическое моделирование:** BERTopic применяется к скользящим временным окнам (не статично) — темы отслеживаются в динамике;
2. **Метрика популярности темы = f(число документов, частота обновления)** — тема «растёт», если в неё попадает много новых документов ЧАСТО;
3. **Классификация:** шум (нестабильные/случайные темы) vs слабый сигнал (растущие, редкие) vs сильный сигнал (устойчиво частые);
4. **LLM-интерпретация:** LLM объясняет смысл тем — для интерпретируемости трендов (пересекается с нашим LLM-фильтром оборотов речи, GLOSSARY).

## Значимость для проекта (фичи + гипотезы)

### Фичи для предиктивной модели
| Фича | Что даёт | Наш аналог |
|---|---|---|
| **Topic popularity = f(docs, update_freq)** | «Тема растёт» не только по числу, но и по ЧАСТОТЕ появления новых работ | Уточнение S1a: GrowthRate с учётом регулярности |
| **Noise filter (темы-шум)** | Отсев случайных/нестабильных тем до анализа | Аналог LLM-фильтра (Amedvedev) на уровне тем, не слов |
| **Online topic tracking** | Тема «живёт» в скользящих окнах, а не в фиксированных периодах | Уточнение S2: периоды должны перекрываться |

### Гипотезы для проверки на кейсах
- **H-BERT1:** «Слабый сигнал» по BERTrend (редкая, но часто обновляемая тема в 2018) предсказывает «состоялся к 2026» лучше, чем просто рост частоты. Проверка: построить BERTrend-метрику для тем наших кейсов (SNSPD, flux pump) по окнам 2015-2018 → сравнить с меткой.
- **H-BERT2:** Часть «тем-шум» (нестабильных) в наших wordshift-результатах — это и есть обороты речи, которые отсекает LLM-фильтр. Проверка: сравнить темы-шум BERTrend с отсечёнными словами wordshift_snspd.
