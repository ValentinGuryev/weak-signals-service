## Суть работы (2–3 предложения)

Представлен **SciMuse** — система генерации **персонализированных научных идей** для исследователей и коллабораций, использующая **58 млн статей** и **GPT-4**. Проведена **крупнейшая оценка AI-генерированных идей**: >100 руководителей исследовательских групп Макса Планка (от естественных наук до гуманитарных) оценили **>4 400 персонализированных идей**. На данных оценок предсказывается интерес исследователей: (1) supervised нейросети и (2) zero-shot ранжирование LLM.

---

## Ключевые результаты

### Knowledge graph
- Узлы = научные концепты из **2.44 млн статей** (arXiv, bioRxiv, ChemRxiv, medRxiv, cutoff февраль 2023): RAKE → NLP-очистка → GPT/Wikipedia/ручная проверка → **123 128 концептов** (естественные и социальные науки).
- Рёбра = ко-встречаемость концептов в title/abstract **более 58 млн статей OpenAlex** + данные о цитированиях (прокси влияния). Эволюционирующий граф с 1665 (текст Роберта Гука) по апрель 2023.

### Персонализированные предложения
- Интересы исследователя: концепты из его публикаций за **последние 2 года**, уточнённые GPT-4 → персональный суб-граф.
- Промпт для GPT-4: до 7 названий статей каждого исследователя + **2 выбранных концепта** (случайная пара, пара с наибольшим предсказанным влиянием [по методу 12], или без пары — sanity check). Самокоррекция: GPT-4 генерирует 3 идеи, дважды итеративно уточняет, выбирает лучшую.

### Крупномасштабная оценка
- **110 руководителей групп из 54 институтов Макса Планка** (104 — естественные науки, 6 — социальные); средний опыт: 59.7 опубликованных статей (диапазон 9–402), 3 759.7 цитирований (20–85 778). Каждый оценил до 48 проектов по шкале 1–5.
- **4 451 ответ.** **1 107 проектов (~25%) получили 4 или 5; 394 — «очень интересно» (5).**

### Свойства интересных предложений
- Нет значимой разницы между случайными парами, высоко-влиятельными парами и без пары → можно анализировать фичи графа.
- **Фичи графа (8), коррелирующие с интересом (рис. 3):**
  - **Степень и PageRank первого концепта — сильно отрицательно коррелируют** с интересом (чем более связан концепт, тем менее привлекателен проект).
  - **Цитируемость концепта — отрицательно** (чем чаще цитировался, тем менее интересно).
  - **Семантическое расстояние — отрицательно** (проекты из похожих полей интереснее, чем из далёких) — согласуется с тем, что внутри-институтские предложения оценены выше.

### Предсказание интереса
- **Метод 1 — supervised NN:** 25 KG-фич, 50 нейронов в 1 скрытом слое, dropout, Monte Carlo cross-validation. Предсказание «высокий интерес (4–5)» vs ниже.
- **Метод 2 — GPT zero-shot:** GPT-3.5 и GPT-4o ранжируют 2 996 предложений (22 000–45 000 попарных сравнений, ELO-система, старт 1400).
- **Результаты (рис. 4):**
  - AUC ~**2/3** для обоих методов (NN 64.5%, GPT-4o 67.3%).
  - **Precision top-1: NN 70%**, GPT-4o 51.0%, GPT-3.5 52.9%; **top-5: NN 60.4%**, GPT-4o 46.7%, GPT-3.5 43.7%; **top-3: NN 66.4%**, GPT-4o 45.0%, GPT-3.5 47.2% (случайный выбор — 23%).
  - **Вероятность ≥1 интересного в top-N** — значительно выше случайной для NN; GPT (без человеческих оценок) тоже ранжирует интересное выше случайного.
  - **Более новые модели (GPT-4o) лучше предсказывают человеческий интерес, чем GPT-3.5.**

## Релевантность проекту

**4/5** — методологически релевантен нашему этапу 4 (мотивация/карточки) и v2 Score:
- **KG + LLM для генерации идей** — образец, как автоматически предлагать перспективные направления (для наших карточек трендов).
- **Предсказание человеческого интереса** (NN по KG-фичам, zero-shot LLM) — методология валидации «что интересно» (для нашего этапа 4).
- **Инсайты о фичах:** концепты с высокой степенью/цитируемостью менее интересны → наш GrowthRate/Score может недооценивать «новые» концепты; семантическая близость важна → для графа связей.
- **Крупномасштабная оценка экспертами** — образец для жюри (методология подтверждается руководителями групп).
- **Ограничение для нас:** требует GPT-4 (ключи), 58 млн статей — для пилота это ориентир на будущее, не текущая реализация.
