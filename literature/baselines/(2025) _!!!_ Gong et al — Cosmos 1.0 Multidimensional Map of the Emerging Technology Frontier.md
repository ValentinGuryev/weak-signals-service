## Суть работы (2–3 предложения)

**Cosmos 1.0** — открытый датасет и методология «снизу вверх» для построения карты вселенной технологий, смежных концептов и сущностей. Из корпуса Wikipedia отбираются **technology-adjacent entities (TA23k = 23 544 сущности)**, для них строятся контекстные эмбеддинги (100 измерений), кластеризацией выделяются **7 тематических (TC7) и 3 мета-кластера (TC3)**; вручную верифицированы **100 emerging технологий (ET100)**. Датасет обогащён восемью категориями внешних индексов оценки технологического ландшафта.

---

## Метод и состав датасета

1. **Отбор сущностей:** «bottom-up» подход — из корпуса Wikipedia через эмбеддинги статей (в отличие от общеязыковых word-эмбеддингов) выделяется вселенная технологически-смежных сущностей; статьи-кандидаты фильтруются по косинусному сходству.
2. **Структура:** dimensionality reduction + кластеризация → иерархия TC7/TC3; каждый entity — вектор 100d.
3. **Индексы (8 категорий):** **Technology Awareness Index, Generality Index, Deeptech, Age of Tech Index** и др. — метрики зрелости/распространённости/новизны технологий.
4. **Золотой набор:** **ET100** — 100 emerging technologies, проверенных вручную.
5. **Внешние источники-обогащения и валидации:** Wikipedia, **OpenAlex**, Crunchbase, Google Books, Google Scholar — используются для проверки релевантности и точности индексов (метаданные по компаниям, публикациям).
6. **Прочие числа датасета:** промежуточные наборы 54 864 / 29 030 сущностей, упоминание 181 компании и пр. (разные стадии конвейера).

## Ключевые результаты

- Работающий **открытый артефакт**: датасет целиком на Figshare + GitHub (фичи + код экспериментов) — можно скачать и переиспользовать без API-квот.
- Карта технологического рубежа с иерархией кластеров и индексами зрелости; ручная верификация ET100 даёт готовый mini-набор для калибровки.
- Валидация индексов перекрёстными источниками (OpenAlex/Crunchbase/Wikipedia) — мульти-базовый принцип, совпадающий с нашим S1.

---

## Выводы для проекта

- **Прямой конкурент/дополнение Этапа 1 нашего алгоритма:** их подход — тоже скрининг рубежа emerging tech по открытым метаданным, но по сущностям Wikipedia, а не по публикационной динамике; полезно как **внешний валидатор** (пересечение ET100/кластеров с нашими темами OpenAlex/LaBSE).
- **Фичи-идеи:** Age of Tech Index ≈ наш Novelty (возраст), Technology Awareness ≈ adoption-компонент impact×adoption×conversion, Generality ≈ рекомбинация/охват (близко к патентной IPC-рекомбинации).
- Использует **OpenAlex** — проверяемость и отсутствие конфликта с нашим стеком; код на GitHub можно прогнать (правило подчёркивания в имени).
- **Релевантность: 5/5** — тема (карта emerging technology frontier), открытые данные, ручной золотой набор ET100, мульти-базовая валидация и готовый код.
