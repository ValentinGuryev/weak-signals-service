## Суть работы (2–3 предложения)

Работа предсказывает **влияние (impact) НОВЫХ, ещё не исследованных связей между научными концептами** (идей, которые никогда не были опубликованы). Построен большой эволюционирующий knowledge graph из **более чем 21 млн научных статей** (1709 — апрель 2023), сочетающий семантическую сеть (концепты из контента статей) и сеть влияния (исторические цитирования). Нейросеть предсказывает динамику сети в будущее с **AUC > 0.9** для большинства экспериментов, то есть — влияние новых направлений исследований.

---

## 1. Введение и мотивация

- Взрыв числа публикаций заставляет исследователей сужать фокус на поддисциплины; сложно находить новые влиятельные идеи вне своей области. Инструмент, читающий и интеллектуально действующий по литературе, мог бы помочь учёному выбрать следующее высоко-влиятельное направление — и в глобальном масштабе ускорить науку.
- **LLM (GPT-4, Gemini, LLaMA-2) часто не справляются с научными рассуждениями**; неясно, как надёжно они могут предлагать научные идеи и оценивать их влияние в ближней перспективе.
- **Альтернатива — семантические knowledge graphs:** узлы = научные концепты, рёбра = совместное исследование двух концептов в статье. Из каждого документа извлекается мало информации, но при большом корпусе получаются нетривиальные выводы.
- Ранний пример (биохимия [9]): семантическая сеть (узлы = биомолекулы) для поиска более эффективных стратегий исследования. Рёбра создаются в момент публикации → **эволюционирующая семантическая сеть**.
- Вопрос «что будут исследовать» — **link prediction** (продемонстрировано для квантовой физики [11] и AI [4]). Эта работа добавляет измерение **impact**: «какие из новых тем будут влиятельными».
- Импакт в науке часто аппроксимируется цитированиями (за отсутствием лучших метрик).
- **Новизна:** предсказание влияния «зародышей идей» (onsets of ideas), никогда не опубликованных, на уровне концептов, до завершения работы.

## 2. Методы

### 2.1 Knowledge graph
- **Концепты:** НЕ использовались готовые списки (APS, CS-онтологии) — они могут пропускать новейшие концепты; генерация собственного списка даёт гранулярный контроль.
- **Исходные данные:** 2 444 442 препринта (arXiv, bioRxiv, ChemRxiv, medRxiv), включая 78 084 из arXiv physics.optics и quant-ph (для доменных концептов).
- **Извлечение (RAKE, приложение B):** RAKE предлагает кандидатные ключевые фразы, разбивая предложение по пунктуации и стоп-словам. Пример: «Recurrent neural networks have significantly improved the accuracy of image recognition in large-scale scientific collaboration networks» → кандидаты: Recurrent neural networks, improved, accuracy, image recognition, large-scale scientific collaboration networks. Каждое слово получает балл по частоте и степени (число ко-встречаемостей в кандидатных фразах). Итоговые фразы ранжируются по сумме баллов слов.
- **Фильтрация:** 2-словные концепты — ≥9 статей; 3+-словные — ≥6 статей → **726 439 концептов**; автоинструменты (удаление не-концептуальных фраз, глаголов, порядковых числительных, союзов, наречий) + ручная проверка → **368 825 концептов**.
- **Синонимия:** похожие/синонимичные концепты остаются раздельными; синонимия выявляется структурно (сетевая косинусная схожесть соседств) — используется для отбора пар с достаточно разными смыслами (порог косинусной схожести при рекомендациях).
- **Доменные концепты:** фокус на физике.optics + quant-ph → 87 741 релевантный концепт → автофильтр + ручная проверка → **37 960 доменных концептов**.
- **Примеры извлечения (4 статьи, рис. 1):**
  1. BGnet (single-molecule localization microscopy, deep NN): super resolution reconstruction, neural network, single molecule tracking, deep neural net, deep neural network, localization microscopy, biological structure, point source, point spread function, single molecule localization microscopy, optical microscopy, neural net.
  2. ML для кластерного анализа localization microscopy: neural network, supervised machine learning, spatial relation, localization microscopy, single molecule localization microscopy, neural net, machine learning.
  3. Constraints on cosmic strings (Advanced LIGO): phase transition, cosmic string, gravitational wave, cosmic microwave, cosmic microwave background, topological defect, string theory, ring theory.
  4. Learning phase transitions from dynamics: neural network, recurrent network, time crystalline phase, phase transition, localization transition, spin chain, recurrent neural net, ct model, recurrent neural network, phase diagram, crystalline phase, neural net, recurrent net.
- **Рёбра:** из **92 764 635 статей OpenAlex** (датасет ~330 ГБ сжатый, ~1.6 ТБ распакованный; отфильтрован до 68 ГБ gzip: научные статьи с временем публикации, title, abstract, цитированиями). **21 165 421 статья** содержит ≥2 концептов → **193 977 096 пар концептов** (с мульти-рёбрами) → **26 010 946 уникальных рёбер** после слияния.
- **Временные метки:** дни с 1 января 1990; **цитатная информация: годовые цитирования 2012–2023 + общее с публикации** (OpenAlex не даёт годовых цитирований старше 10 лет → фокус на 2012+). Для рёбер из нескольких статей — агрегированные годовые и общие цитирования.
- **Пример ребра** «single molecule localization microscopy»–«neural net»: p1 (7 января 2020, 38 цитирований, годовые {5,8,16,9} для 2023–2020), p2 (20 марта 2020, 43 цитирования, {6,16,14,7}) → агрегат: 81 цитирование, годовая последовательность {11,24,30,16,0,...}.
- **Полный граф:** ~23.12 ГБ на диске; обработан на Intel Xeon Gold 6130, 1 TiB RAM (для эффективности; 1 TiB не обязателен при малом списке концептов).

### 2.2 Задача предсказания
- **Формулировка:** для пары вершин, не имеющей связи в 2016, предсказать, наберёт ли она ≥ IR цитирований через 3 года.
- **Impact Range (IR):** порог минимального числа цитирований пары концептов за заданный период (IR = 1...200). Бинарная классификация вместо точных цитирований (снижает шум стохастики цитирования).
- **Фичи (141):** 41 сетевая (20 узловых: число соседей, PageRank за 3 года; 21 реберная: косинусная, геометрическая, Simpson-подобия) + 100 импакт-фич (58 узловых цитатных: суммарные и годовые цитирования за 3 года; 42 парных: цитатное отношение и др.). Сетевые фичи вдохновлены победителем Science4Cast; цитатные — эмпирические. Полный список — таблицы 1–2 приложения D и GitHub.
- **Модель (основная):** полносвязная feed-forward сеть с **4 скрытыми слоями по 600 нейронов** (всего 6 полносвязных слоёв), вход — 141 фича.
- **Обучение (приложение C):** датасет 2016 → предсказание импакта 2019: ~689 млн не связанных пар; все положительные (3-летние цитирования ≥ IR) + равное число случайных отрицательных; 85% train / 15% test. Eval-датасет 2019→2022: 10 млн случайных пар. Adam, lr 3×10⁻⁵, mini-batch 1000, равные положительные/отрицательные в батче. Обучение на 1 GPU (Nvidia Quadro RTX 6000), ~1.5 ч на IR.

### 2.3 Бенчмарк (модели и интервалы)
- Набор из 1 млн пар: **FF NN (3 скрытых слоя × 600 нейронов, ReLU, ~800k параметров; Adam, batch 2048, lr 1e-4)**, **Transformer (4 слоя, hidden 128, 4 attention heads, feedforward 512, ~800k параметров, positional encodings; Adam, batch 2048, lr 1e-4)**, **Random Forest (300 деревьев, min 25 на разбиение, 10 на лист)**, **XGBoost (до 2000 раундов, lr 0.01, max depth 10)**. Гиперпараметры — через поиск на одной задаче (2016–2019, IR=10), константны для всех.
- Обучение на 2/3/4-летних интервалах, оценка на 1–5 лет; модели предсказывают, получит ли пара ≥ IR цитирований (IR=10 или 50).
- **AUC > 90% во всех этих задачах** (рис. 6).
- **Без переобучения в будущее (2014–2017 → 2018–2022):** качество падает с увеличением горизонта (рис. 7) — ожидаемо.
- **Малые IR учат предсказывать большие IR:** модель, обученная на IR=10, предсказывает IR=50 слегка лучше, чем обученная на IR=50 (рис. 8) — из-за более разнообразных данных (примеров IR=10 намного больше) и/или систематического дрейфа паттернов цитирования (рост общего числа цитирований).

## 3. Результаты (AUC)

- **Основная задача (2016→2019 train; 2019→2022 eval):** AUC > 0.8 для всех IR, в большинстве случаев > 0.9 (тест и eval; рис. 4a). Пример: IR=100, eval-датасет 2019→2022, полный набор фич — **AUC 0.948**.
- **Рис. 4b:** сортировка пар eval по предсказанию (IR=100) — точность на уровне отдельных пар (20 бинов).
- **Рис. 4c:** топ-предсказанные пары получают **>3 порядков больше цитирований**, чем средние по 10 млн пар (0.029 цитирований).
- **Подлинный impact (вне link prediction, рис. 4d):** обучение на парах, не связанных в 2016, но связанных в 2019; предсказание «0–5 vs >100 цитирований»: **AUC > 0.7 (тест), > 0.67 (eval)** — модель учит имманентные цитатные фичи, не просто новые связи.

### Индивидуальные фичи (приложение D, рис. 12)
- Топ-4 фичи (AUC): **Simpson similarity для пары (u,v) за годы y, y−1, y−2 — 0.8880, 0.8795, 0.8720; cosine similarity пары (u,v) в году y — 0.8683**.
- Худшие 3 (AUC ~0.52): среднее общее число цитирований узла v до года y; общее цитирование пары до y−1 и y−2.
- **Все 141 фича вместе — AUC 0.948** (комбинация работает лучше).

### Полная сводка 141 фичи (приложения D, таблицы 1–2)
**Узловые фичи (индексы 0–19):**
- 0–5: число соседей узла (u или v) до года y, y−1, y−2 (N_u,y, N_v,y, ...).
- 6–7: число новых соседей между y−1 и y (N_u,y − N_u,y−1 и т.д.).
- 8–9: число новых соседей между y−2 и y.
- 10–11: ранг числа новых соседей (y−1→y).
- 12–13: ранг числа новых соседей (y−2→y).
- 14–19: PageRank узла до y, y−1, y−2.

**Узловые цитатные фичи (индексы 20–77):**
- 20–25: годовые цитирования узла в y, y−1, y−2.
- 26–31: общие цитирования с первой публикации до y, y−1, y−2.
- 32–37: общие цитирования за последние 3 года, оканчивающиеся в y, y−1, y−2.
- 38–43: число статей, упоминающих узел, до y, y−1, y−2.
- 44–49: средние годовые цитирования (C_m = C/Pn).
- 50–55: средние общие цитирования (Ct_m = Ct/Pn).
- 56–61: средние общие цитирования за последние 3 года (CtΔ3_m).
- 62–63: новые цитирования между y−1 и y (Ct_u,y − Ct_u,y−1).
- 64–65: новые цитирования между y−2 и y.
- 66–67: ранг новых цитирований (y−1→y).
- 68–69: ранг новых цитирований (y−2→y).
- 70–71: число статей, упоминающих узел, между y−1 и y.
- 72–73: то же между y−2 и y.
- 74–75: ранг числа статей (y−1→y).
- 76–77: ранг числа статей (y−2→y).

**Парные фичи (индексы 78–98):**
- 78–80: число общих соседей до y, y−1, y−2 (Ns = N_u ∩ N_v).
- 81–83: geometric similarity (Geo = Ns²/(N_u × N_v)).
- 84–86: cosine similarity (Cos = √Geo).
- 87–89: Simpson similarity (Sim = Ns/min(N_u, N_v)).
- 90–92: Jaccard index (J = Ns/(N_u ∪ N_v)).
- 93–95: Adamic-Adar index.
- 96–98: resource allocation index.

**Парные цитатные фичи (индексы 99–140):**
- 99–101: сумма годовых цитирований пары (s_y = C_u,y + C_v,y).
- 102–104: сумма общих цитирований пары (st_y = Ct_u,y + Ct_v,y).
- 105–107: сумма средних общих цитирований.
- 108–110: сумма общих цитирований за последние 3 года (stΔ3).
- 111–113: сумма средних общих за последние 3 года (stmΔ3).
- 114–116: минимум годовых цитирований пары (minC).
- 117–119: максимум годовых цитирований (maxC).
- 120–122: минимум общих цитирований (minCt).
- 123–125: максимум общих (maxCt).
- 126–128: минимум общих за последние 3 года (minCtΔ3).
- 129–131: максимум общих за последние 3 года (maxCtΔ3).
- 132–134: минимум числа статей с узлом (minPn).
- 135–137: максимум числа статей (maxPn).
- 138–140: отношение цитирований узлов (цитатное отношение между u и v).

**Наблюдения:** фичи узлов (степень, новые соседи, ранги) захватывают популярность и её динамику; парные подобия (cosine/Simpson/geometric/Jaccard) — близость в сети; цитатные фичи (суммы, мин/макс, отношения) — импакт и его динамику. Полный список и код — GitHub Impact4Cast.

## 4. Применения

- **Топ-предсказанная пара** (все ~694 млн не связанных пар до января 2023): **«renewable energy» × «cancer cell»** — высокорисковый прогноз.
- **Персонализированные коллаборации:** ограничение пар концептами интересов учёных. Пример (экспериментальная квантовая оптика + биофизика): «microfluidic channel» × «Kerr resonator», «SARS CoV» × «quantum enhanced sensitivity», «electron microscopy» × «quantum vacuum field».
- **Рис. 5:** 100 000 пар по свойствам (косинусная схожесть, средняя степень, темп роста сети — новые соседи, цитатная плотность, прошлые цитирования) → редкие выбросы с высоким предсказанным влиянием (яркие жёлтые пятна).
- Практика: регулярно обновлять knowledge graph и переобучать модели на свежих данных.

## 5. Обсуждение и будущее

- **Ограничение:** модели используют 141 ручную фичу и не обращаются напрямую к полному графу. Перспективы: гипер-графы (больше информации из каждой статьи), настоящие динамические фичи (вне снимков сети), динамические word embeddings, предсказание НОВЫХ концептов и их влияния.
- **Метрики влияния:** выйти за пределы цитирований (computational sociology, science of science); метрики «удивления» (surprise) как дополнение к предсказанию цитирований.
- **Связь с научным интересом работающих исследователей** — ключевой компонент будущих AI-ассистентов (см. SciMuse [67]).
- Данные открыты (Zenodo), код — GitHub (Impact4Cast).

## Релевантность проекту

**5/5** — прямо релевантен нашему этапу 3 (Score):
- **Метод:** предсказание влияния НОВЫХ концепт-связей (ещё не исследованных) — это «зарождающиеся тренды» на уровне пар концептов, а не готовых тем. Идея для v2 Score.
- **AUC > 0.9 (0.948 с полным набором фич)** — сильное доказательство, что ML на эволюционирующих графах предсказывает будущий импакт научных идей.
- **Фичи (сетевые + цитатные)** — рецепт для нашего графа связей на этапе 5; топ-фичи (Simpson/cosine similarity) — прямое обоснование метрики связей.
- **Impact Range (бинарный порог)** — аналог нашего порога Score; методология валидации (test vs никогда-не-виданный eval) — образец для нашего бэктеста (внутренний контракт 4.5).
- **Инсайт «малые IR учат большие IR»** — намёк, что обучение на разнообразных данных улучшает предсказание; для калибровки порога.
- **Значимость для жюри:** показывает, что предсказание «что станет влиятельным» в науке — решаемая задача с количественной точностью (AUC, precision на 3 порядка выше среднего).

## Ограничения работы

- Фокус на оптике/квантовой физике (37 960 доменных концептов из 368 825); метод переносим, но проверен не везде.
- Предсказание влияния по цитированиям — прокси (сами авторы признают несовершенство метрик цитирования).
- Цитатные фичи эмпирические; формального анализа важности всех фич нет (частично есть — приложение D).
- Требует большого корпуса (21 млн статей) и вычислительных ресурсов (1 TiB RAM для полного графа, GPU для обучения).
- Задача «подлинного impact» имеет более низкий AUC (0.67–0.7) — сложнее.
