# (2026) Burmaoglu, Saritas, Kara — LLM-Augmented Innovation Regime Classification (preprint)

- **Библиография:** Burmaoglu Serhat¹, Saritas Ozcan², Kara Karahan¹ — «LLM-Augmented Innovation Regime
  Classification: A Hybrid Framework for Patentometric Foresight», Research Square preprint (2026-03-31).
  ¹ Izmir Kâtip Çelebi University; ² Rochester Institute of Technology - Dubai.
- **DOI:** 10.21203/rs.3.rs-9166858/v1
- **Релевантность:** 4/5 (!!). **LLM + патентометрия для технологического форсайта** — прямое
  пересечение с нашим патентным сигналом + LLM-обработкой.

## Суть
Представлен **трёхслойный гибридный фреймворк**, интегрирующий:
1. **Количественные патентометрические индикаторы** (longitudinal);
2. **Целевую онтологическую схему классификации** (Minimal Foresight Ontology);
3. **LLM-семантическую калибровку**.

**Проблема:** существующие rule-based классификаторы инновационных режимов дают много
неклассифицируемых наблюдений и игнорируют семантику текста патентов.

**Ключевая идея:** LLM используется НЕ как самостоятельный классификатор, а как **структурированный
калибровочный агент** внутри индикаторной scientometric-схемы (semantic calibration).

## Метод
- Патентные индикаторы → вектор;
- Онтология (Minimal Foresight Ontology) → категории инновационных режимов;
- LLM калибрует/интерпретирует семантику → режим;
- Упомянуты Markov chain, semantic drift.

## Значение для нашего проекта
1. **LLM как калибратор, а не классификатор** — подтверждает наш подход (LLM-фильтр оборотов в S2,
   а не замена метрик);
2. Патентометрия + форсайт — как наш S1b (патенты);
3. Innovation regime classification — аналог нашей задачи «тренд состоялся/нет» (режимы развития);
4. Preprint (Research Square) — свежая, но не рецензированная.
