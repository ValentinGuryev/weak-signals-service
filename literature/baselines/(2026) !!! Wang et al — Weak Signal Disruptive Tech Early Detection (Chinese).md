## 1. Аннотация (суть)

С ускорением научно-технической революции раннее выявление **разрушающих (дизруптивных) технологий** стало ключом для стран к захвату стратегического преимущества и перестройке конкурентного ландшафта. Авторы опираются на ключевые сегменты **инновационной цепочки (frontier research → basic research → applied research)** и строят **тематические сети цитирования** на основе ссылочных связей между документами. Отслеживая изменения **триплетных (тройных) структур** в сети за последовательные периоды, выявляют **слабые сигналы** потенциально разрушающих технологий. Затем строят **систему индикаторов мониторинга**, считают **индекс разрушающего потенциала** seed-технологий и вводят **LLM (большие языковые модели)** для семантического усиления и шум-фильтрации.

**Кейс:** водородные топливные элементы (hydrogen fuel cells). Идентифицированы **5 главных разрушающих направлений**, включая технологии электролитов и мембран. Метод валидирован ретроспективным анализом литературы. Результат: фреймворк **значительно улучшает разрешение слабых сигналов**, выявляет больше направлений с потенциальным социальным влиянием.

**Ключевые слова:** disruptive technology; weak signal detection; complex networks; indicator system; large language model.

## 2. Введение (полный разбор)

- **Разрушающая технология** определяется как технология, которая «меняет устоявшуюся технологическую парадигму иным путём», оказывает разрушительное/дизруптивное воздействие на традиционную магистральную технологическую траекторию, отраслевую рыночную структуру и даже правила международной конкуренции;
- Такие технологии часто зарождаются в **не-мейнстримных инновационных нишах** и через **экспоненциальный рост** совершают переход «от периферии к ядру», вызывая **разрыв (непрерывность) технологической траектории**;
- В зародышевой стадии разрушающие технологии существуют как **слабые связи между тематическими направлениями** — и слабые сигналы являются эффективной точкой входа для их выявления. Слабые сигналы и разрушающие технологии разделяют черты: **ранность, неопределённость, нечёткость, потенциал влияния на будущее**;
- Слабый сигнал в контексте раннего выявления = **тематическое направление в зародыше, но с заметным трендом роста**;
- **Проблемы существующих подходов:**
  1. Фокус на «post-hoc оценке» уже проявивших себя технологий, нехватка «предварительных (pre-hoc)» фреймворков для неизвестных технологий;
  2. Традиционные методы переоценивают **сильные сигналы** (высокочастотные термины, высокоцитируемые работы) и не улавливают слабые изменения на стадии зарождения;
  3. Существующий weak signal анализ — в основном **статический**, без динамического отслеживания **многостадийной когнитивной эволюции** инновационной цепочки → слабое восприятие ключевых точек перехода.

## 3. Связанные работы (полный разбор)

### 3.1 Разрушающие технологии и их раннее выявление
- 4 класса методов идентификации: (1) **экспертный отбор** (качественный); (2) **текстовый майнинг** (количественный); (3) **наукометрия/библиометрия** (количественный); (4) **технологические дорожные карты** (качественный + количественный);
- Признаки для оценки: новизна, неопределённость, фронтирность, лидирующая роль, прорывность, влияние;
- **Пробелы:** (а) нехватка анализа **временной динамики** технологических сетей, особенно ключевых точек перехода и механизмов смены форм; (б) нет полного фреймворка, объясняющего **постепенную эволюцию** технологии «от периферии (зародыш) к ядру (зрелость)».

### 3.2 Слабые сигналы разрушающих технологий
- Weak signal метод — важный вход для раннего выявления; (детали раздела не полностью разобраны — китайский текст, далее по смыслу) авторы связывают слабые сигналы с мониторингом зарождающихся тематических связей.

## 4. Метод (по абстракту + тексту)

**Новизна:** «модель совместной эволюции трёх стадий инновационной цепочки» + отслеживание структурной динамики **временных сетей цитирования**:
1. **Построение тематических сетей цитирования** по трём сегментам цепочки (frontier → basic → applied) на основе ссылок между документами;
2. **Отслеживание изменений триплетных структур** (тройных связей) в сети за последовательные периоды → выявление слабых сигналов потенциально разрушающих технологий (триплетные изменения — индикатор перестройки тематических связей);
3. **Система индикаторов мониторинга** ранних сигналов разрушающих технологий;
4. **Индекс разрушающего потенциала** (disruptive potential index) для seed-технологий;
5. **LLM** (большая языковая модель) — семантическое усиление + шум-фильтрация → точное выделение и отсев ранних слабых сигналов в домене;
6. **Валидация:** ретроспективный анализ литературы (подтверждает, что выявленные направления действительно стали значимыми).

## 5. Кейс и результаты

- **Домен:** водородные топливные элементы;
- **Результат:** выявлены **5 главных разрушающих направлений**, включая **технологии электролитов и мембран**;
- Валидация через литературную ретроспективу подтвердила эффективность;
- Авторы: фреймворк обеспечивает **динамический мониторинг слабых сигналов разрушающих технологий на всей цепочке от фундаментальных до прикладных исследований**;
- Ключевой результат: **разрешающая способность по слабым сигналам значительно выше**, выявляется больше направлений с потенциальным социальным влиянием.

## 6. Значимость для нашего проекта

- **Прямой китайский аналог** нашей задачи (калибровка emerging/disruptive трендов по слабым сигналам). Подтверждает: weak signal detection — **глобальный признанный тренд** (Канада — WISDOM/Ebadi, Китай — эта работа, грант Госфонда соц. наук);
- **Отличия от нашего подхода:**
  | Аспект | Wang 2026 (Китай) | Наш проект |
  |---|---|---|
  | Объект | Disruptive технологии (водород) | Emerging тренды в прикладной СП |
  | Данные | Сети цитирования (статьи) | Мульти-база (статьи ∩ патенты ∩ гранты ∩ рынок ∩ конференции) |
  | Метод | Триплеты в темпоральных сетях + LLM | Калибровка на 58 ретро-кейсах + ML (метка «состоялся/нет») |
  | LLM | Шум-фильтрация сигналов | Не центральный (экспертная верификация) |
- **Наше преимущество:** калибровка на истории (метка «состоялся к 2026») — у Wang только ретроспективная валидация в одном домене, нет обучающего набора прошлых кейсов;
- **Их идея, которую стоит взять:** триплетные структуры в темпоральных сетях цитирования = потенциальная фича для S3 (кластеры цитирований «из ниоткуда»); LLM-шум-фильтрация — для автоматизации S2;
- **Методологический урок:** разрушающие технологии = наш «ложный/состоявшийся тренд» на краю; отслеживание «периферия → ядро» совпадает с нашей идеей (S3: новый кластер из ниоткуда).
