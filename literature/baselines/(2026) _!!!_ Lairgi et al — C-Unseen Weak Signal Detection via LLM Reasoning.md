## Суть (1 абзац)
Weak signals — ранние, малозаметные индикаторы грядущих изменений. Существующие методы (частотность ключевых слов, тематическое моделирование, топология графов без типов) теряют **семантико-реляционную структуру**, через которую сигнал проявляется. Авторы определяют weak signal как **редкий, семантически связный подграф, proliferирующий через последовательные снимки динамического темпорального графа знаний (DTKG)**. Фреймворк C-Unseen из двух модулей:
1. **Rare Subgraphs Extractor** — LLM (через chain-of-thought) читает снимок TKG, строит «базовый нарратив» и находит редкие подграфы, **конфликтующие с доминирующим нарративом**; строится «связующий подграф» (кратчайшие пути между сущностями).
2. **Weak Signal Alerter** — сравнивает текущий связующий подграф с прошлыми: подграф помечается weak signal'ом, если **продолжает напряжение** («tension»), уже присутствовавшее ранее (корроборация во времени).

## Ключевые результаты
- **Первый бенчмарк weak signal detection**: Wiki-OpenAI — 773 атомарных факта из истории правок Wikipedia страницы OpenAI (2015–2025), 11 годовых снимков, 5 аннотированных strong signals (роли: background / weak_signal / corroboration / strong_signal). Анонимизированный вариант Wiki-OpenAI-Anon — контроль утечки из претрейнинга LLM.
- **Базлайны:** Yoon (keyword DoV/DoD), BERTrend (нейро-тематический), BEAM (graphlets). LLM: gpt-5.4-mini.
- Метрики: precision/recall/F1 (3 уровня строгости сопоставления), **lead time** (насколько рано сигнал пойман до strong signal — операционная ценность).
- **Вывод:** C-Unseen **превосходит** keyword-, topic- и graph-базлайны; даёт интерпретируемые объяснения (self-interpretable) — важное преимущество перед «чёрными ящиками».
- LLM-выводы устойчивы к анонимизации (не просто утечка памяти модели).

## Что это даёт нашему проекту
1. **Методологический ориентир**: weak signal = редкий + корроборированный во времени подграф (два свойства: rarity + corroboration). Это операционализация «слабого сигнала», которую можно сопоставить с нашими S1–S5.
2. **Сдвиг от «частоты терминов» к «структуре знаний»**: наши методы (wordshift, BERTopic) — «плоские»; C-Unseen показывает, как добавить реляционный слой (сущности-связи).
3. **Инструмент**: LLM + TKG для детекции emerging-событий — потенциально применим к нашим корпусам (SNF, конференции) для авто-детекции зарождающихся тем.
4. **Бенчмарк-идея**: наш features_table/кейсы — тоже своего рода «золотой стандарт» (метка 2026); идея lead time (как рано сигнал до исхода) прямо переносится на наши ретро-кейсы (сигнал 2018 → исход 2026).
5. **GitHub-репо** — кандидат в клоны-бейзлайны (как BERTrend/WSM/Huang): есть код, можно прогнать на наших кейсах.

## Заметки
- Датасет построен на **Wikipedia-истории OpenAI** (кейс «снятие бана ChatGPT в США» как пример weak→strong сигнала, Рис.1) — интересный реальный пример эволюции сигнала.
- Ограничение: домен корпоративный (Wikipedia), один объект (OpenAI); перенос на науку/технологии требует адаптации.
- Созвучно нашему принципу «0 в базе ≠ 0 в реальности»: weak signals по определению «не видны» в стандартных агрегатах — их ловит только структурная корроборация.
