# База 1: Слабые сигналы 2026 (валидационная)

> **Назначение:** множество текущих (2026) зарождающихся трендов — «то, что похоже на слабые тренды
> в 2026 году». На эту базу смотрим при оценке выдачи модели: набрать >80% = выдать сигналы из этой
> базы и НЕ выдать исключённые (база 3).
> ⚠️ **Порядок строк — строго по глобальному № официального датасета** (решение автора 2026-09-16).
> Скоринг модели заполняется при прогоне.
> 🆕 2026-09-17: добавлены записи Индустриального ИИ (№26-30, 53-55, 78-79, 81-82) по возрастанию №;
> №80 (нейроморфные edge-чипы) исключён → база 3 (зрелая категория, не слабый сигнал).

## Схема строки
| Поле | Описание |
|---|---|
| id | SS-NN внутренний (по порядку №) |
| № / область | глобальный № из официального датасета / домен |
| Название | технология-кандидат |
| Почему слабый сигнал | слой(-и): внимание/наука/инженерия/рынок/регуляторика + факты (почему НЕ хайп/НЕ состоявшееся/НЕ стандарт) |
| Стадия / балл | из официального датасета (стадия развития / балл стадия+тренд) |
| Риски | маркеры для верификации (хайп/плато/внедрённость и т.п.) |
| Скоринг модели | заполняется при прогоне (0–100%) |
| Источники | наименование, ссылка, дата, тип, язык, доверенность (паспорт) |
| Статус | 🔶 кандидат / ✅ подтверждено |
