## 1. Постановка (внешний позитивный контроль для S2)

**Утверждение (Kastrin & Hristovski 2020, LBD):** в области literature-based discovery магистральный
подход сместился от co-occurrence (рубеж 2000-х) к семантическим методам (данные 2010+), затем к
сетевым идеям. Замысел: если «сдвиг методологии» — реальный маркер созревания области, то наш вывод
«в СП сдвиг лексики открытие→инжиниринг НЕ работает» (S2, 8/8 кейсов) мог быть артефактом домена —
а Kastrin показывает, что сдвиг в другом виде существует.

**Операционализация по плану:** wordshift-стиль по абстрактам, периоды ≤1999 / 2000-09 / 2010-14 /
2015-19 / 2020-26; семейства лексики: `old_cooc` (co-occurrence, co-word, co-citation, bibliographic
coupling, association rule, dictionary-based, thesaurus), `semantic` (semantic, embedding, word2vec,
sentence-transformer, semantic similarity, topic model), `llm` (LLM, transformer, BERT, GPT, deep
learning, neural network, machine learning — слой 2020+); нормировка на 1000 абстрактов.

## 3. Интерпретация

### 3.1. Kastrin-тест НЕ применим к абстрактам физико-технологического корпуса

- **Мета-лексика методов ≈ 0 во всех периодах** (0 в ~6600 абстрактах суммарно): статьи по SRF-физике
  **не описывают в абстрактах свои библиометрические/семантические методы**. Это принципиальное
  отличие типа поля:
  - **LBD** (источник Kastrin) — «мета-поле»: сам предмет исследований = методы анализа литературы →
  метод-лексика плотна в абстрактах → сдвиг виден;
  - **физика/технология (SRF)** — «поле-предмет»: методы живут в полных текстах/обзорах/грантах,
  абстракты описывают результат, а не инструмент.
- ⇒ **H32 в исходной операционализации (абстракты) — «неприменимо», а не «опровергнута»**.
  Позитивный контроль должен ставиться там, где сдвиг заведомо наличествует: обзорные статьи поля,
  полные тексты, или сам LBD-корпус как контрольная область.
- **Следствие для S2:** наш вывод «сдвиг лексики (открытие→инжиниринг) не работает в СП» не является
  следствием отсутствия метод-сдвига по Kastrin — это два разных слоя лексики; в абстрактах СП
  отсутствуют ОБА. Для строгой аргументации в related work: S2-провал — свойство среза «абстракты»,
  а не только домена; маркеры зрелости искать в других слоях (патенты/SNF/лексика-специфика —
  работает «убывание технологии-специфичной лексики», см. п.3.2).

### 3.2. Ценная побочная находка: ML-волна прокатывается по SRF (2020+)

- `llm`-семейство: 2→11→4→16→**104** сырых вхождений; на 1000 абстрактов: 3.7→7.7→3.3→10.0→**58.5**
  (≈0.4% абстрактов ≤2014 → **5.8% в 2020-26**). Рост ~15× за десятилетие-полтора, резкий скачок 2020+.
- Это **экспериментальное подтверждение наблюдения §2г п.8 (Ebadi 2026)**: «DL-волна прокатывается
  по всем доменам» — теперь и в ускорительной физике (ML для commissioning/обработки SRF-кавитетов).
- **Практическое следствие для кейсов:** при корпусных анализах SRF/Nb3Sn (и любых 2015+/2020+)
  ML-статьи — реальная примесь, растёт со временем → применять термин-фильтры в цензе (как уже
  предписано в 00_SUMMARY §2г п.8), иначе «рост публикаций 2020+» частично = ML-волна, а не
  технология-предмет. Для кейса 011 (пик публикаций 2023) проверить долю ML-примеси в пиковом
  росте — TODO.

## 4. Правило-вывод

1. **В features_table / модель H32-колонок НЕ добавляем** — тест для абстрактов неработоспособен.
2. **Фиксируем типологию полей для лексических тестов:** «мета-поля» (LBD, наукометрия, футурология) —
  метод-лексика в абстрактах; «поля-предметы» (физика, инженерия, материиаловедение) — только в
  полных текстах/обзорах. Это правило учитывать при планировании любых семантических проверок.
3. **ML-ценз — обязательный шаг в корпусном анализе тем с активностью 2020+** (дополнено к цензу
  из CASE_BUILDING_GUIDE ШАГ 1 п.4) — проверка «пик публикаций ≠ ML-волна».
4. S2-статус не меняется: гипотеза «семантический сдвиг в абстрактах СП» остаётся неподтверждённой,
  теперь с обоснованием «слой абстрактов» (а не только «домен СП»).

## 5. Ограничения

- Один корпус (SRF), поле-физика; вывод про «тип области» на n=1 — рабочая гипотеза для планирования,
  не статистика.
- Словари семейств — узкие, авторские; «semantic» в P5 = 5 вхождений/2.8 на 1k (уровень шума).
- Полные тексты/обзоры SRF не проверялись (нет локального корпуса) — логичный следующий шаг, если
  захотим добить позитивный контроль строго.
