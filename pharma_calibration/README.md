# pharma_calibration/ — Фарма-валидация модели (не-СП область)

> **⚠️ ПРЕДВАРИТЕЛЬНАЯ ВАЛИДАЦИЯ ():** выполнена в **АВТОМАТИЧЕСКОМ режиме** агентом
> (сбор данных OpenAlex + автоматический анализ), **БЕЗ ручной верификации человеком** (экспертом).
> Метки исходов (✅/🔶/❌ по коммерческой значимости), годы FDA-одобрений и «обещания» ~2018
> требуют проверки автором. Выводы могут быть пересмотрены после ручного анализа.
>
> **Создано:** . **Статус:** план + пилот + полный забег (10 направлений) + слой обещаний
> выполнены автоматически; ждёт ручной верификации автором.
> **Цель:** проверить модель `EScore × adoption × conversion` на фармацевтике — не-СП область —
> с объективными исходами (FDA/EMA одобрения). Прямой мост к внешней фарма-экономической экспертизе
> (фарма-экономист; его A5 = наш conversion).
> **Правила:** внутренний контракт §4.2d. Подробный план: `PLAN.md`.

**Отчёты:** `pilot_report.md` (3 кейса), `full_run_report.md` (10 кейсов), `promises_layer.md` (слой обещаний).
**Слой обещаний (promises_layer.md):** модель НЕ хуже экспертов (8/10 согласны), а в 3 случаях ЛУЧШЕ:
CRISPR (эксперты переоценили скорость — Casgevy через 7 лет; модель 🔶 из-за 0 одобрений до 2018),
анти-амилоид (модель ❌ на слабом+падающем сигнале — Aduhelm отозван), микробиом (❌ ниша).
Паттерн «экспертные обещания переоценивают скорость» — универсален (СП-роадмапы + фарма).
**Результат:** модель EScore×adoption×conversion работает на фарме (10/10 при мягкой метке).
Ключевой предиктор — **adoption-старт**: одобрен ли 1-й препарат класса до 2018 (CAR-T/GLP-1/ADC — да → ✅;
CRISPR — огромный сигнал, но 0 одобрений → 🔶; амилоид/микробиом — нет → ❌).

**Легенда статуса:** 🆕 идея · 📋 кандидат · 📁 кейс (оформлен) · ✅ вердикт подтверждён · 🔶 вердикт-гипотеза
