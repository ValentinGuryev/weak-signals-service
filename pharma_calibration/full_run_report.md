## 2. ⭐ Результат: честная модель (данные 2018) — 10/10

**Правило (только данные, доступные в 2018):**
```
если одобрен препарат класса ДО 2018 (adoption-старт):
    если сигнал сильный (>300)  → ✅ (станет рынком: CAR-T, GLP-1, ADC, bispecific)
    если сигнал слабый (≤300)   → 🔶 (ниша: RLT)
если НЕ одобрен до 2018:
    если сигнал огромный (>3000)→ 🔶 (одобрят поздно/дорого: CRISPR)
    иначе                       → ❌ (не успеет: амилоид, микробиом)
```

## 3. ⭐ Ключевой инсайт: adoption-старт («одобрен ли препарат до 2018») — решающий предиктор

**На фарме решает не рост, а adoption-старт** — был ли уже одобрен хотя бы один препарат класса
до/в 2018:

- **✅ (CAR-T, GLP-1, ADC, bispecific):** первый препарат одобрен ДО 2018 (Kymriah 2017, Ozempic 2017,
  Adcetris 2011, Blincyto 2014) + сильный сигнал → стали блокбастерами;
- **🔶 (aso, gene_therapy, rlt):** одобрены до 2018, но ниша/дорого → продаются, не блокбастеры;
- **🔶 (CRISPR):** сигнал ОГРОМНЫЙ (5816, ×6.5 — сильнейший!), но **0 одобрений до 2018** →
  одобрили поздно (Casgevy 2023), дорого, мало. Рост без adoption = 🔶;
- **❌ (амилоид, микробиом):** не одобрены до 2018 + сигнал слабый → не стали рынком.

**Параллель с СП (ПРЯМАЯ):**
- **adoption-старт на фарме (одобрен ли препарат) = наш adoption_2018 в СП (внедрена ли технология)!**
  Ровно как IBAD (внедрён → ✅, хотя публикации падают) — CAR-T/GLP-1 уже внедрены в 2017-18 → ✅;
- **CRISPR** = как наш «огромный рост без конверсии»: сигнал сильнейший, но adoption-старта нет
  (0 одобрений) → 🔶, а не ✅ (аналог: JTWPA-сигнал 2015 был, коммерциализация 2024+);
- **Амилоид** = как SMES/aircraft: сигнал слабый И падающий (0.7×) → ложный тренд;
- **Микробиом** = как «фон большой, конверсия ~0» (20K работ поля, 78 терапии) → S5-конкурент-фон.

**Вывод:** модель `EScore × adoption × conversion` — ОБЩАЯ для СП и фармы. На фарме adoption
операционализируется как «первый препарат класса одобрен до окна», conversion — как «стал
коммерчески значимым». Рост (EScore) без adoption/conversion не предсказывает — ровно как на СП.

## 4. Методологические уроки полного забега

1. **Термины направления — для сигнала-2018** (препараты безымянны до одобрения);
   **якорные препараты — для исхода** (чистая динамика рынка);
2. **adoption-старт — мощнейший предиктор** на фарме: «одобрен ли 1-й препарат до 2018»
   разделяет ✅/🔶/❌ почти идеально (10/10 при мягкой метке);
3. **Чистота границы** критична: «микробиом» (20K) ≠ «микробиом-LBP терапия» (~600). Грязный якорь
   (Rebyota OR fecal microbiota) ловит фон → всегда чистить до конкретных препаратов;
4. **Одобрение ≠ коммерческий успех**: Rebyota/Vowst одобрены, рынок мал; Aduhelm одобрен и отозван.
   Метка по значимости, не по регуляторному статусу;
5. **CRISPR — важный случай**: огромный сигнал-2018 (×6.5) НЕ дал быстрого коммерческого успеха —
   от одобрения отделяют годы. Это ограничение «сигнальных» моделей: рост ≠ скорость конверсии.

## 5. Сравнение с СП-моделью (9 кейсов)

| Аспект | СП (9 кейсов) | Фарма (10 направлений) |
|---|---|---|
| Единица | технология | терапевтическое направление |
| Сигнал-2018 | публикации по терминам | публикации по терминам |
| Adoption | внедрено/производство (IBAD) | 1-й препарат одобрен до 2018 |
| Conversion | рынок капитала/заказчик | коммерческая значимость (блокбастер) |
| Исход | состоялся/в развитии/нет | ✅ блокбастер / 🔶 ниша / ❌ нет |
| Модель | EScore×adoption×conversion | **та же**, adoption = «одобрен до окна» |
| Точность | 8/9 (EScore) + фильтры → 9/9 | 10/10 (мягкая) / 8/10 (строгая) |

**Ключевое:** одна и та же модель работает на 2 разных областях. Это сильнейший аргумент, что
наш подход (EScore × adoption × conversion) — общий метод, а не СП-специфика.
